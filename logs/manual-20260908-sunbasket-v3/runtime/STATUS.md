# 햇살 바구니 v3 런타임 완료

농가 현관·판매대 곡면 어닝·비대칭 과수·새 작물 GLB와 함께, 길과 지면의 큰 면을 개선했다. 길에는 흙 가장자리와 바퀴 자국, 과수 아래에는 부드럽게 섞이는 흙/잔디, 길 주변에는 곡면 잎 군락을 배치했다. 원경 지형과 부드러운 낮빛을 더했다. 기존 하드코딩 창가 꽃상자와 어닝 장식을 제거하고 모델이 소유한 세부와 이름 있는 현관 앵커를 사용한다.

당근은 새싹·어린잎·성숙 모델을 같은 실제 칸에 표시하며 기존1.14초 성장 시간을 유지한다. 카메라/입력/넓이/수확판정/점수/목숨/저장 계약은 바꾸지 않았다.

- `final-visual.json`:320/390/820/1280 실제 첫주문 심기·쓸기·배송 성공, 넘침0, 콘솔오류0.
- 최대144칸: 실제↑키/심기/쓸기 성공, crop DOM가림0. `max144-390.png` 직접 확인해 새 나무/군락이 밭을 덮지 않음을 확인했다. 단기 렌더 표본60.55fps.
- `planning-390.png` / `harvest-390.png` / `title-390.png`: 최종 실제 화면.820/1280도 동일한 기존 카메라로 기록했다.
- `growth-sprout-390.png` / `growth-young-390.png`: 실제 성장 중 blur로 프레임을 잠시 멈춰 확인한 단계 화면.
- `logic-preserved.json`: math SHA불변,19함수 바이트동일, planning은 PNG캐시URL만 변경.
- `README.md`: 재사용 경로/배치 옵션 및 명명 앵커 API 설명.

생산 소스 동결 후 자산 담당에게 ZIP동기화를 요청했다. 모든 브라우저와 own8793서버 종료, GPU슬롯 반환. 공식QA·9주문 오답회복/저장 통합회귀·독립리뷰는 부모/리뷰어 후속이다.
