# 시각 비교 준비 기록

전 카탈로그51개게임의 meta/mechanic/tech/art_direction을 읽고 가장 가까운 후보3개를 골랐다. 아래 썸네일은 이미지뷰어로 직접 열었다. twin-forts의 실제 경기 화면과 타이틀은 아직 브라우저 검증 대기이므로 최종 동일계열 판정은 보류.

| 후보 | 직접 본 파일 | 비교할 축 |
|---|---|---|
| multiply-siege | public/g/multiply-siege/thumb.png | 요새+공격 소재는 가까움. 기존작은 모래사막·회화의 거친석벽·큰 캐스트 인물, 신작커버는 조감 미니어처 섬·단순 원목/플라스틱형 건물·작은 부대. 실제 정답사건(포격vs양방향 부대진격)도 최종비교 필요. |
| roll-bot | public/g/roll-bot/thumb.png | 오토배틀·로봇 소재는 가까움. 기존작은 크림작업대·큰 황동원통 로봇과 회전체제작, 신작은 청록섬 경기장·여러 작은 병력·비례배분. |
| orbit-courier | public/g/orbit-courier/thumb.png | 실제Blender 3D 장난감물성이라는 기술/재질공통점. 기존작은 검은우주공허·행성·빨간로켓·비행도킹, 신작은 밝은조감섬·두길요새·진격붕괴. |

공식레퍼런스 관찰과 연결되는 신작표지 요소: 넓고단순한 경기장, 같은역할의 반복부품, 팀색대비, 인형보다오브젝트중심 덩어리감, 실제3D로모델링한 작은 세계. 원작과 같은캐릭터·문장·로고는보이지않음. 커버만으로 조작/재미/모바일실가독성을판정하지않음.
