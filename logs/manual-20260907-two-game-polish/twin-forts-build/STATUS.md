# 쌍둥이 요새 v3 세부 보정 완료

기존 모델, 카메라, 병력 배치와 조작은 그대로 두고 런타임 환경을 다듬었다.

- 지면 체크무늬를 자연스러운 잔디색 변화와 작은 결로 교체하고 광원의 색/세기와 부드러운 그림자를 조율했다.
- 다리에 얇은 철띠, 작은 못과 널판 결, 밝은 기둥 마감을 더했다.
- 수로에 물에 젖은 돌 띠, 밝은 둑돌, 소량의 이끼와 휜 잔물결을 더했다.
- 성 기단, 성벽 일부의 작은 마모, 이동 동선 밖 낮은 잎/꽃 군락을 더했다. 대부분3개 instancing 묶음이다.
- UI 크기/간격을 유지하며 안쪽 테두리와 숫자 폭만 정리했다.
