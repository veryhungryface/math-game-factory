### 성공/실패를 가르는 4개 축

1. **답 공간 = 조작 공간.** 성공작에는 하단 4지선다 버튼이 없다. 자르는 궤적, 붓는 양,
   감는 띠, 미는 경계 자체가 답이다. 실패작 6개는 전부 "캔버스 연출 + 하단 선택지 버튼"으로 수렴했다.
2. **무작위 성공률이 낮다.** wrap-pop 18%, tide-checkpoint 0%(봇 실측). 실패작은 100%·96.9%·99.95%.
3. **실패에 이빨이 있다.** 성공작도 관용적이지만(목숨 3, 콤보만 끊김) **끝나기는 한다.**
   실패작은 목숨을 즉시 회복시키거나 결과 문구가 항상 승리다.
4. **기획서의 핵심 루프가 코드에 실재한다.** 성공작 리뷰는 기획 문장을 코드 줄번호로 짚는다.
   실패작 리뷰는 "기획의 ○○이 구현되지 않았다"가 매번 나온다.

### 대칭 단원 고유 함정 (6회 전부 같은 슬롯이었으므로 기록)

「합동과 대칭」은 `mirror()` 한 줄로 정답을 만들 수 있어 **코드가 학생 대신 대칭을 수행하는
유혹이 구조적으로 강하다.** 이 단원(및 유사한 변환 단원)에서는 다음을 지켜라:

- 대칭짝·대응점을 코드가 자동 생성해 배치하면 안 된다. **학생이 놓은 위치를 코드가 판정만** 한다.
- 판정은 윤곽 일치가 아니라 **대응점 라벨까지** 비교한다(대응점이 뒤바뀐 회전·반사는 오답).
- 「대칭이동의 결과」와 「주어진 축·중심에 대해 자기 자신과 포개지는 대칭도형」을 용어상 구분한다.
- 5학년은 좌표평면·순서쌍·직선 방정식(x=2)이 아니라 **모눈에서 "축에서 몇 칸"** 표현을 쓴다.
