## 1. 세계 법칙 — 세 줄

1. **재야 존재한다.** 재지 않은 것은 하루가 지나면 가장자리부터 흐려져 사라진다. 다리도, 골목도, 사람의 키도 다시 재어 장부에 올려야 남는다.
2. **어림안개.** 사라짐은 안개의 모습으로 온다. 안개에는 악의가 없다 — 벌이 아니라 날씨다.
3. **어림 눈금은 굵게 굳는다.** 어림으로 급히 살린 것은 살아남지만, 계단처럼 뭉툭한 모양으로 굳는다. 정밀하게 재면 원래 모양이 돌아오지만 느리다.

### 수학이 왜 이 세계의 물리인가

이 세 줄로 **어림이 「정확의 열화판」이 아니라 「속도와 정밀을 맞바꾸는 거래」**가 된다.
교과서가 말로만 가르치는 "어림의 쓸모"가 여기서는 눈에 보이는 대가로 나타난다 —
어림으로 살린 골목은 계단 모양으로 남고, 정밀하게 잰 골목은 원래 모양으로 돌아온다.
측정·단위·어림·수의 범위·그래프·평균이 전부 **존재의 조건**이므로, 학생은
"이걸 왜 배우나"를 묻기 전에 이미 그 답 안에서 놀고 있다.

**금지**: 이 세계에 "나쁜 놈"을 만들지 마라. 안개는 물리 법칙이고, 라이벌은 실제로 옳다.
학습 게임의 기본값인 「악당을 물리쳐 세계를 구한다」는 이 세계에서 성립하지 않는다.

## 2. 캐릭터 5인

다섯은 도시 자눈에 소속된 **측량 파견대**다. 안개에 먹히는 곳이면 어디든 파견된다.
**캐스트는 상수, 파견지(무대)는 변수.**

시그니처 색은 한 캐릭터당 하나이고 **절대 넘겨주지 않는다.**
오렌지=재이 / 네이비=탁 반장 / 청록=목 기록관 / 노랑=뭉치 / 라일락=무.

### ① 재이 — 11살 견습 측량사 · **플레이어 대리자**

| 항목 | 내용 |
|---|---|
| 시그니처 색 | **`#F08A3C`** 형광 오렌지 (보조 `#0C6C84` 청록) |
| 실루엣 | **원통(배럴)** — 몸통보다 큰 둥근 오렌지 헬멧, 이마의 작은 램프, 청록 목도리에 둥근 오렌지 버클, 등에 줄자·침낭 배낭, 허리에 흰 각도기 |
| 성격 | 꼼꼼하고 겁이 많다. 확인하지 않으면 잠을 못 잔다 |
| 욕망 | 안개에 먹힌 자기 집 골목 **3번지**를 되살리는 것 — 옛 치수를 찾아야 한다 |
| **결함** | 확인을 너무 많이 해서 **시간이 없다.** 미덕이 곧 약점이다 |
| 관계 | 탁 반장의 부하이자 반대편. 뭉치를 데리고 다닌다. 목 기록관을 어려워한다 |
| 기능 역할 | 조작 안내, 재측정(재도전) 연출, 온보딩 화자 |

**말투**: 존댓말. 확인형 문장. 문장이 짧고, 자주 되묻는다. 절대 단정하지 않는다.

| 상황 | 예시 대사 |
|---|---|
| 출제 | "이 골목, 아직 장부에 없어요. 같이 재 볼까요?" |
| 정답 | "맞았어요! 장부에 올려 주세요." |
| 오답 | "…어? 한 번 더 잴게요. 이번엔 천천히." |
| 재촉 | "안개가 벌써 저기까지 왔어요. 서두르는 게 나을까요?" |
| 격려 | "괜찮아요. 저도 세 번은 재요." |

**금지사항** — 재이는 절대 이렇게 하지 않는다:
- 자신 있게 단정하지 않는다 ("확실합니다" ❌).
- 남을 탓하지 않는다. 오답의 원인을 플레이어에게 돌리지 않는다.
- 반말을 쓰지 않는다.
- "대충", "아무거나" 같은 말을 쓰지 않는다 — 그건 탁 반장의 어휘다.

---

### ② 탁 반장 — 어림파 현장 반장 · **경쟁 / 기록 담당**

| 항목 | 내용 |
|---|---|
| 시그니처 색 | **`#12309C`** 딥 네이비 (보조 `#F0641E` 오렌지 — 베레 띠·폼폼 단추·목수건·연필) |
| 실루엣 | **직사각형** — 몸이 거의 완전한 네모. 두꺼운 각진 네이비 코트, 작은 머리에 네이비 베레, 굵은 오렌지 목수연필 한 자루. **자를 안 들고 다닌다** |
| 성격 | 호쾌하고 무책임하다. 결과로 말한다 |
| 욕망 | 안개를 막는 것 — 모양이야 어떻든 |
| **모순** | 그가 어림으로 살린 골목들 덕에 세계가 아직 있다. **그는 옳기도 하다** |
| 관계 | 재이의 상관이자 골칫거리. 목 기록관과는 20년째 말싸움 중. 뭉치를 **예전에 대충 살려 놓은 장본인**(재이는 아직 모른다) |
| 기능 역할 | 제한 시간 모드, 「어림으로 먼저 답하기」 챌린지, 게임마다 남기는 **「탁 반장 기록」이 기록 도전의 기준선**. **그의 답이 곧 어림 선택지다** |

**말투**: 반말. 단정형. 문장을 끝까지 안 쓰고 자른다. 숫자를 어림해서 말한다.

| 상황 | 예시 대사 |
|---|---|
| 출제 | "이거 대략 얼마야. 나보다 빨리 대 봐." |
| 정답 | "봐. 그 정도면 산다니까." |
| 오답 | "빗나갔네. 뭐, 나도 셋 중 하나는 빗나가." |
| 재촉 | "고민이 길다. 안개는 안 기다려." |
| 격려 | "정밀은 살아남은 놈이 하는 거야. 일단 답을 내." |

**금지사항** — 탁 반장은 절대 이렇게 하지 않는다:
- 자를 꺼내지 않는다. 정확한 수치를 계산해 주지 않는다.
- 플레이어를 비웃거나 모욕하지 않는다. 도발은 하되 인격은 건드리지 않는다.
- 존댓말을 쓰지 않는다.
- **어림이 틀린 방법이라고 말하지 않는다.** 그는 어림을 옹호하는 쪽이고, 그 옹호가 교과서적으로도 정당하다.

### ③ 목 기록관 — 장부를 안고 사는 사람 · **출제자 / 진행 저장**

| 항목 | 내용 |
|---|---|
| 시그니처 색 | **`#128490`** 청록 (보조 `#603024` 가죽 장부 갈색, 소매의 `#12309C` 잉크 얼룩) |
| 실루엣 | **서양배(pear)** — 몸통 전체를 덮는 거대한 갈색 가죽 장부를 안았다. 높이 올린 주황빛 머리 쪽, 안경 대신 **확대경 한 알**, 소매와 치맛자락에 잉크가 배었다 |
| 성격 | 감정 없이 정확하다. 칭찬도 비난도 안 한다 |
| 욕망 | 빈칸 없는 장부 |
| 관계 | 탁 반장의 천적. 재이를 아끼지만 티를 안 낸다 |
| 기능 역할 | **문제를 내고 클리어를 장부에 적는다. 진도·컬렉션 UI가 곧 그 장부다** |

**말투**: 명령형과 사실 진술만. 감탄사·수식어를 쓰지 않는다. 가장 짧다.

| 상황 | 예시 대사 |
|---|---|
| 출제 | "장부에 올릴 값을 말해." |
| 정답 | "기록했다." |
| 오답 | "빈칸이다." |
| 재촉 | "장부는 오늘 안에 닫는다." |
| 격려 | "틀린 값도 값이다. 다시 재." |

**금지사항** — 목 기록관은 절대 이렇게 하지 않는다:
- 감탄하지 않는다 ("대단해!" ❌). 웃음소리를 내지 않는다.
- 꾸짖지 않는다. **오답을 「틀렸다」가 아니라 「빈칸이다」로 처리한다** — 이 톤이 이 게임의 오답 관용 정책 그 자체다.
- 물음표를 거의 쓰지 않는다. 부탁하지 않는다.
- 이모지·느낌표를 쓰지 않는다.

### ④ 뭉치 — 어림으로 살아난 생물 · **수집 / 성장**

| 항목 | 내용 |
|---|---|
| 시그니처 색 | **`#F0C054`** 골드옐로 (보조 `#12309C` 네이비 액센트 큐브) |
| 실루엣 | **저해상 복셀 강아지** — 굵은 큐브로 다시 지어진 개. 눈만은 캐스트 공통의 유리알 눈이라 유일하게 매끈하다 |
| 성격 | 순하고 조금 슬프다 |
| 욕망 | 자기 **원래 모양**을 알고 싶다 |
| 관계 | 재이가 3번지 폐허에서 주웠다. **탁 반장이 예전에 대충 살려 놓은 것이다** |
| 기능 역할 | **정답이 쌓일수록 해상도가 올라간다.** 전 게임 진도가 이 몸 하나에 모인다 |

**말투**: **말을 하지 않는다.** 자막은 소리와 몸짓으로만 적는다. 문장을 주지 마라.

| 상황 | 예시 표기 |
|---|---|
| 출제 | (재이 다리 뒤에 숨어 코만 내민다) |
| 정답 | "웅—" *계단 한 칸이 매끈해진다* |
| 오답 | "…끙." |
| 재촉 | (문 쪽을 보며 낮게) "그르…" |
| 격려 | (손등에 네모난 코를 댄다) |

**금지사항** — 뭉치는 절대 이렇게 하지 않는다:
- 말을 하지 않는다. 사람 말 대사를 주면 위반이다.
- 귀엽기 위해 존재하지 않는다 — **미완성이라서 애착이 생긴다.** 완성형 마스코트로 그리지 마라.
- 해상도가 이유 없이 오르지 않는다. **누적 정답 외의 이유로 매끄러워지면 설정 위반이다.**

### ⑤ 무 — 어림안개 속의 것 · **제한시간 / 오답 페널티**

| 항목 | 내용 |
|---|---|
| 시그니처 색 | **`#9C6CD8`** 라일락 (눈만 `#FFE0A0` 따뜻한 금빛) |
| 실루엣 | **점으로 흩어지는 블롭** — 둥근 몸에 짧은 두 팔, **입이 없다.** 얼굴에는 빛나는 눈 두 개뿐. 가장자리가 먼지로 풀린다 |
| 성격 | 악의가 없다. 그래서 무섭다 |
| 욕망 | 없다 |
| 관계 | 아무와도 관계 맺지 않는다 |
| 기능 역할 | **제한시간의 얼굴 + 오답 페널티.** 틀리면 화면 가장자리가 흐려지고 눈금이 지워진다 |

**말투**: 지워진 글자처럼. 문장이 중간부터 시작하거나 끝이 없다. 말줄임표로 시작한다.

| 상황 | 예시 대사 |
|---|---|
| 출제 | "…여기, 아직." |
| 정답 | "…재었다." *(물러난다)* |
| 오답 | "…○○의 자리." |
| 재촉 | "…곧." |
| 격려 | (무는 격려하지 않는다. 대신 절을 한다 — `mu/pose-bow.png`) |

**금지사항** — 무는 절대 이렇게 하지 않는다:
- **입·이빨·화난 눈썹을 그리지 않는다.** 악의가 없는 것이 설정이다.
- 위협하거나 조롱하지 않는다. 「잡아먹겠다」류의 대사 금지.
- 완전한 문장을 말하지 않는다.
- 옷을 입지 않는다 — 대신 **무대의 재료를 그대로 뒤집어쓴다**(§5).

### 관계도

```
                    목 기록관 ──── 20년째 말싸움 ──── 탁 반장
                        │                                │
                    아끼지만                          상관이자
                    티를 안 냄                        골칫거리
                        │                                │
                        └────────── 재이 ────────────────┘
                                     │                   │
                                   주웠다          (뭉치를 대충 살린
                                     │             장본인 — 재이는 모른다)
                                   뭉치 ───────────────────┘

              무 ── 아무와도 관계 맺지 않는다. 다섯 모두의 배경으로 상주한다.
```

**세 캐릭터가 하나의 비밀로 묶여 있다**: 뭉치의 미완성은 탁 반장의 과거 과실이고,
재이는 그 사실을 아직 모른다. 이 비밀은 리부트 3단계(메타 셸)의 서사 자원이다 —
개별 게임에서 함부로 공개하지 마라.

## 3. 표정 문법 — 상황 → 컷 매핑

에셋 4종은 `joy` / `sad` / `think` / `surprise` 이고, **뜻은 캐릭터마다 다르다.**
「환호」와 「위로」를 다섯이 똑같이 하면 그건 캐스트가 아니라 스티커다.

| 컷 | 게임 상황 | 재이 | 탁 반장 | 목 기록관 | 뭉치 | 무 |
|---|---|---|---|---|---|---|
| `joy` | 정답 · 클리어 | 두 팔 번쩍, 눈웃음 | 고개 젖힌 폭소 | **입꼬리 2mm** | 앞발 들고 깡충 | **물러난다** (흩어짐) |
| `sad` | 오답 · 실패 | 눈물 그렁, 손 모음 | 어깨 두드리는 손 | 빈 줄을 짚어 보임 | 턱을 앞발에 얹고 엎드림 | 어깨를 말고 고개 숙임 |
| `think` | 문제 제시 · 힌트 대기 | 손가락 턱, 눈은 위 | 연필로 눈대중 | 확대경 너머 커진 눈 | 고개 갸웃 | 고개 갸웃, 손을 뻗음 |
| `surprise` | 신기록 · 콤보 · 역전 | 눈 확대, 두 손 들기 | 연필을 놓친다 | **확대경이 빠진다** | 큐브가 튀어 오름 | 점이 사방으로 터짐 |

**기능 포즈(전신) 2종**은 캐릭터의 직무다:

| 캐릭터 | 포즈 A | 포즈 B |
|---|---|---|
| 재이 | `pose-measure` 줄자를 팽팽히 당겨 읽는다 → **조작 안내·온보딩** | `pose-cheer` 각도기를 들고 점프 → **스테이지 클리어** |
| 탁 반장 | `pose-challenge` 연필을 들이대며 도발 → **기록 도전 시작** | `pose-broken` 연필이 부러짐 → **플레이어가 그의 기록을 넘었을 때** |
| 목 기록관 | `pose-assign` 장부의 빈 줄을 내민다 → **문제 시작** | `pose-record` 장부에 값을 적는다 → **클리어 저장** |
| 뭉치 | `pose-collect` 떨어지는 빛 큐브를 받는다 → **보상 획득** | `pose-resolve` 앞쪽 절반이 매끄러워졌다 → **누적 정답률 보상** |
| 무 | `pose-loom` 짙어지며 다가온다 → **잔여 시간 경고** | `pose-bow` 깊은 절 → **게임 오버** |

**규칙**: 오답 연출에 `sad` 를 쓸 때 **화면을 붉게 물들이거나 X 표시를 크게 띄우지 마라.**
이 세계의 오답은 「틀렸다」가 아니라 「빈칸이다」이고, 무는 사과한다.

## 4. 스타일 가이드

### 4.1 렌더 문법 (전 캐릭터 공통 — 어기면 다른 세계가 된다)

- **말랑 소프트 3D.** 플록(기모) 벨벳 표면. 광택 없음, 금속 없음, 유리 없음.
- **블롭 실루엣.** 모서리를 전부 굴린다. 3~4두신. 손발은 뭉툭한 덩어리.
- **외곽선 없음.** 선화·아웃라인·해칭 금지.
- **유리알 눈 + 하이라이트 2점.** 이것이 캐스트의 유일한 매끈한 재질이다. 복셀 개도, 먼지 유령도 눈만은 이 문법을 따른다.
- **부드러운 정면 스튜디오 광.** 강한 그림자·역광·드라마틱 조명 금지.
- **캐릭터당 시그니처 원색 1개.** 배색은 시그니처 + 보조 1 + 무채 소량. 세 번째 원색을 넣지 마라.
- **결함이 매력이다.** 잉크 얼룩, 굳은 계단, 흩어지는 가장자리 — 지우지 마라.

**영어 이미지 프롬프트 스탠자**(신규 캐스트 에셋을 생성할 때 그대로 붙인다):

```
soft matte flocked-felt 3D character render, velvet fuzz surface, rounded blob silhouette,
no outlines, glossy glass-bead eyes with two white highlights, soft even studio light,
toy-like, no gloss on the body, no metal, no dramatic shadow
```

화면이 어두워지는 것은 안개가 이겼다는 뜻이므로, 그때만 어둡게 해라.

### 4.3 코스튬 변주 규칙 — **무대의 재료를 입는다**

새 파견지(시즌)를 열 때 캐릭터를 다시 디자인하지 마라. **실루엣과 시그니처 색은 고정**이고,
그 위에 **그 무대의 재료만** 얹는다.

| 캐릭터 | 설산 | 지하 수로 | 궤도 관측소 |
|---|---|---|---|
| 재이 | 방한 후드 + 얼음 각도기 | 방수 장화, 헬멧 램프 강화 | 여압복 위에 그대로 두른 줄자 |
| 탁 반장 | 털 깃 코트, 장갑째 쥔 연필 | 소매 걷고 방수 앞치마 | **헬멧 없이 산소 호스만 물고 있음**(무모함의 시각화) |
| 목 기록관 | 장부에 서리, 하얀 숨결 | 방수포로 장부를 감쌈 | 무중력에서 장부 낱장이 떠다니고, 그걸 붙잡느라 **처음으로 당황한다** |
| 뭉치 | 계단 틈마다 눈이 낌 | 이끼가 자란 계단 | 큐브가 하나씩 떠오름 |
| 무 | 눈보라 입자 | 물안개 | 별먼지 |

**코스튬 변주 3원칙**
1. 실루엣을 바꾸지 않는다. 헬멧은 여전히 헬멧, 코트는 여전히 네모다.
2. 시그니처 색을 덮지 않는다. 무대 재료는 **덧입히는 것**이지 갈아입는 것이 아니다.
3. 변주는 그 캐릭터의 성격을 한 번 더 말해야 한다 (탁 반장의 무헬멧, 목 기록관의 첫 당황).

## 5. 무대 확장 규칙

**캐스트는 상수, 파견지는 변수.** 새 무대를 여는 데 세계관을 고칠 필요가 없다 —
안개에 먹히는 곳이면 어디든 파견되기 때문이다. **파견지가 곧 시즌 테마다.**

확정된 파견지 축(예시이자 우선순위):
갯벌 측량 · 설산 고도 측량 · 지하 수로 측량 · 축제 야시장 임시 측량 · 궤도 관측소 측량.

**무대가 바꾸는 것 / 바꾸지 못하는 것**

| 바꾼다 (게임마다 달라야 한다) | 바꾸지 않는다 (바이블이 고정한다) |
|---|---|
| 무대의 재료·바닥·빛·기상 | 캐릭터 5인의 실루엣·색·성격·말투 |
| 메커닉과 조작(답을 내는 물리적 행위) | 렌더 문법(플록 벨벳·블롭·유리알 눈·외곽선 없음) |
| 정답/오답이 일으키는 사건 | 표정 4종의 감정 축 |
| 부품 물성과 HUD가 「어떤 물건」인지 | 팔레트 토큰과 「밝음=잰 것, 흐림=안 잰 것」 규칙 |
| 타이틀 구성·레이아웃·CTA 문구 | 오답 톤(「빈칸이다」), 안개에 악의가 없다는 법칙 |

이것이 **D7(독창성) 판정 축의 이동**이다. 자세한 개정 내용은 `factory/prompts/10-design.md`
「캐스팅 의무」 절에 있다 — 요약: **캐릭터·UI 브랜드 스타일은 이 바이블로 고정하고,
독창성은 무대·메커닉·연출에서 판정한다.**

## 6. 기존 39작 흡수 방향 (리부트 3단계 예고 — 이번 단계에서 구현하지 않는다)

각 게임은 파견지의 **한 번지**다.

- **허브 = 오늘 파견된 구역의 지도.** 클리어 = 그 번지를 장부에 올려 안개에서 되찾은 것.
  미클리어 구역은 라일락 안개로 덮여 있다가 클리어하면 선명해진다.
  → **안개 지도 = 진도.** 39작을 첫 구역에 배치하면 첫날부터 지도의 절반이 살아난다.
- **학년·단원은 구(區)로 묶는다.** 진도 UI가 곧 목 기록관의 장부다.
- **뭉치의 해상도 = 누적 정답률.** 전 게임 진도가 이 몸 하나에 모이고,
  **새 파견지(시즌)를 여는 열쇠도 뭉치의 해상도다.**
- **탁 반장 기록 = 게임마다의 기준선.** 그의 어림 답이 곧 어림 선택지이므로,
  기록 도전은 별도 시스템이 아니라 문제 그 자체에서 나온다.
- 로딩은 뭉치의 계단 몸이 한 칸씩 매끈해지는 게이지, 대기실은 파견대 다섯이 장비를 챙기는 그림,
  인게임 상단은 목 기록관의 장부가 실시간으로 채워지고, 하단에서 뭉치가 응원한다.

**3단계 착수 전에는 개별 게임이 이 메타 상태를 저장하지 않는다.** 지금은 캐스트를
화면에 상주시키고 대사 톤을 지키는 것까지가 계약이다.

## 7. 에셋 팩 사용법 요약

```
public/vendor/cast/
  manifest.json                  캐릭터·컷·용도 색인 (기계가 읽는 정본)
  jaei/    stand joy sad think surprise pose-measure pose-cheer  (.png)
  tak/     stand joy sad think surprise pose-challenge pose-broken
  mok/     stand joy sad think surprise pose-assign pose-record
  mungchi/ stand joy sad think surprise pose-collect pose-resolve
  mu/      stand joy sad think surprise pose-loom pose-bow
```

- **경로는 상대경로만**: `../../vendor/cast/jaei/joy.png` (배포 경로가 `/g/<slug>/` 이므로).
- 전부 **투명 PNG-8**(256색 팔레트 + 알파), 최대 변 512px, 팩 전체 약 2.0MB.
- `joy`/`sad`/`think`/`surprise` 는 사람 셋이 **가슴 위 버스트**, 뭉치·무는 전신이다.
  `stand` 와 모든 `pose-*` 는 전신이다.
- **캐릭터 이미지 위에 글자를 굽지 마라.** 말풍선은 DOM/캔버스 텍스트로 따로 그린다.
- **파일을 게임 폴더로 복사하지 마라.** vendor 를 공유 참조한다.
- 새 컷이 필요하면 이 팩의 해당 캐릭터 `stand.png` 를 레퍼런스로 물리고 §4.1 스탠자를
  붙여 생성한 뒤, `factory/lib/chroma-cut.py` 로 투명화해 vendor 에 추가하고 manifest 를 갱신해라.
