# 쌍둥이 요새 아트 v2 검증

사용자가 제공한 Clash Royale 화면과 비교해 v1의 경기장 구성·모델 형태·재질·인터페이스 밀도 차이를 인정하고 실제 게임 화면을 다시 제작했다. 공장 점수를 상용 아트 완성도의 근거로 사용하지 않는다. 독립 시각 비교는 [별도 검수](twin-forts-art-v2-review.md)에 기록한다.

## 변경

- 기존 평판 전장을 낮은 외곽 성벽, 석재 기단, 수로, 실제 다리 구조, 포장길과 잔디 타일로 구성했다. 명령판이 먼 요새를 가리지 않게 렌더 영역을 예약했다.
- Blender 원본 7종을 수정했다. 포구·치성·석재 벽으로 요새 역할을 강조하고 병사는 헬멧·견갑·방패·몸체가 구별되도록 했다. 계획 중에는 앞면이 보이며 출격할 때 목표로 돌아선다.
- 상하단 정보대를 압축하고 전장 비중을 늘렸다. 390px 설명문 12px, 320px 설명문 11px를 유지하고 배분 손잡이와 한 명 이동 버튼을 보존했다.
- 접지 음영, 조명, 출격 먼지와 타격 잔해를 수정했다. 시작 화면은 실제 3D 경기장을 배경으로 사용한다.
- 공개 자산의 장기 캐시를 고려해 변경된 GLB·CSS·JS에 `?v=2`를 적용했다. 원본 ZIP에는 실제 사용한 GLB·Blender 파일·독립 실행 가능한 생성 스크립트가 들어 있다.

## 최종 파일과 검증

증거: `logs/manual-20260907-twin-forts-art-v2/`. `artifact-manifest.json`은 게시 과정에서 QA 메타데이터가 바뀌는 `meta.json`을 제외한 게임 20파일의 정렬된 상대경로/해시를 고정한다.

- 산출물 SHA-256: `feb6dc3f534f7f0756fc06bb65d2d9658635071c1e1a37595fef8704ead2123e`.
- 수학 모듈 SHA-256: `0820163ea9543938ade05d00ffbd94f1c52dd33697846f310e50c81620907e36`. v1과 동일하며 독립 검수에서 최종 QA 110표본을 다시 계산해 오류 0. 13개 핵심 상태/정답 처리 함수도 v1과 동일하다. 이전 33,341배분 상태·40,000문항 오라클 결과와 이번 좁은 회귀 검사를 구분한다.
- 최종 QA **44/44**, 치명 0. Apple M4 실 GPU에서 모바일 뷰포트와 1280px 중앙값 각각 60FPS. 15초 뒤 61FPS로 성능 저하 없음. 실제 저가 휴대전화 측정은 아니다.
- 실제 입력 스모크: 320/390/820/1280px에서 시작→12/18 배분→출격 성공, 오류와 가로 넘침 0. 계획·전투·결과 실제 화면 보존.
- ZIP CRC와 원본 패키지 내부 7개 GLB의 공개 게임 파일 바이트 일치 확인. ZIP SHA-256: `47542df220359ef8e5f318a3ed9e7440579c6093ce9c408a712a3bace1f0b093`.

- 실제 오답 복구: 터치 드래그·정밀 버튼·키보드 각각 중간 재배치 버튼 없이 바로 수정→출격 성공. 터치 캠페인은 일반 문항 1오답 후 9/9 완주, 970점·목숨2·일반 첫시도7/8. 새로고침 후 승리1·실제 장식1 보존. `recovery/results.json`, 입력 로그와 화면에 기록. 오류0.
- 첫 플레이: 기본 SwiftShader 탐침은 t33 이후 멈춰 부분 증거로 보존하고 종료했다. 동일 무작위 정책의 실제 GPU 재실행은 13프레임·페이지/콘솔 오류0으로 종료했다. 단 frame00~05만 이 게임이며 frame06부터 홈→다른 게임으로 이동했다. 따라서 유효6장만 평가하고 나머지는 제외했다. 45초 전체를 이 게임에서 플레이했거나 아동이 설명을 이해했다고 주장하지 않는다.

독립 게시 회귀 검수 **87점·passed=true·must_fix 없음**. 이 점수는 상용 아트 완성도 비교 점수가 아니다. `publish-game.mjs`의 기본 80점 게이트로 version2를 재게시했고 카탈로그 정합성 **52/52**를 확인했다. 공개 배포 검증은 아래에 별도로 기록한다.

## 판단의 한계

전장 구조와 형태 구분은 개선했으나 다양한 캐릭터 실루엣, 관절과 표정의 세밀한 연기, 질감/광원 조율에서는 상용 레퍼런스와 차이가 남는다. 독립 QA 통과는 상용 게임과 동급이라는 뜻이 아니다. 실제 아동 조사나 온라인 대전은 수행·구현하지 않았다.
