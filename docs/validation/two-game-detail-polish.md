# 쌍둥이 요새·햇살 바구니 세부 디자인 보정

사용자는 두 작품의 현재3D 스타일을 좋아하며 디자인을 조금 더 섬세하게 다듬어 달라고 요청했다. 같은 게임과 화면 구성을 유지하고 실제 플레이 환경의 재질·접점·장식·빛을 보정한다. 대상은 `twin-forts` v2→v3, `sunbasket-farm` v1→v2이며 신규 게임 생산이 아니다.

## 변경과 비교 기준

요새는 체크무늬가 도드라지던 잔디를 미세한 색 변화로 바꾸고, 물가의 밝은 돌 턱·젖은 띠·이끼, 다리의 나뭇결·철띠·못, 요새 기단과 낮은 잎·꽃 군락을 추가했다. 정면 구조와 두 부대/길의 구분을 유지하며 조명과 UI 가장자리도 조율했다. 기존 GLB7종은 보존했고 이번 환경 세부는 `environment.mjs`에 구현했다. 같은12/18배치의390px 전후 화면에서 부모와 독립 검수자가 변화를 직접 확인했다.

농장은 균일하게 솟은 작은 풀을 줄이고 넓은 잎·데이지 군락으로 교체했다. 흙길의 테두리·징검돌, 농가의 창가 꽃상자·화분, 판매대 바구니와 어닝 매듭을 붙였고 조명의 대비와 UI 종이 가장자리를 조율했다. 기존 GLB10종과 카메라/밭 위치를 유지하며 `assets/farm-polish.mjs`에서 환경 세부를 추가한다. 부모가 같은390px 계획 전후와 수확 확대 화면을 직접 열어 새 디테일과 비어 있는 조작 영역을 확인했다.

새 장식은 정답 단서나 충돌체가 아니며 수학 문제와 판정을 바꾸지 않는다. 원본 ZIP에는 기존 Blender/GLB와 현재 런타임 참고 소스를 구분해 포함한다. 모델을 새로 만들거나 기존 대량 수학 검산을 다시 실행한 것으로 쓰지 않는다.

## 검증

증거와 재현 스크립트는 `logs/manual-20260907-two-game-polish/`에 둔다. 게임별 제작자 검증, 부모 검증, 독립 검증의 출처를 구분한다. 기존 단위 정수 검산은 math SHA와 핵심 함수의 불변성을 확인해 재사용하고, 최종 QA가 실제 생성한 표본은 별도 정수 연산으로 재계산한다.

요새 제작자는320/390/820/1280px 실제12/18슬라이더 배치와 출격, 정상 출제의90명72/18배치와 출격을 검증했다. 오류·넘침0, 조작44px 이상. 부모는 동일 전후 화면과90명 화면을 직접 열었다. 부모의 추가 터치 정밀버튼/작은320×720화면 검사는 다른 경로와 작은 높이를 확인한다.

농장 제작자는 최종 환경에서 실제 손잡이·터치·키보드 수확과 일반1오답 후9주문을 완주했다(810점·621코인·목숨2·첫시도7/8). 최대144작물은320/390/820/1280px 모두 가림·넘침0. 실패/재시작·저장 재로드도 통과했다. 부모는 두 게임의390px 터치 정밀버튼과320×720px 작은 높이에서 첫 주문을 완료했고 오류·실패요청·넘침0을 확인했다.

두 게임 모두 공식 QA **44/44·치명0**. Apple M4 실제 GPU에서390px·1280px 중앙값60FPS,15초 유지비율 요새1.00/농장1.02. 이는 개발용 GPU와 모바일 화면 크기의 결과이며 실제 저가 휴대전화 측정은 아니다. 기존 수학/게임 함수 불변과 연결한 최종 QA 표본은 요새111개·농장81개다.

원본 ZIP의 CRC, 요새GLB7+런타임5파일 및 농장GLB10+런타임5파일 바이트 일치를 확인했다. 검수 대상 산출물은 meta를 제외한 요새21파일 SHA `01a5f7bebe4f4d974e0a3d7158cd22e2925d7e3a61b3e14fbbebb8d52eda2287`, 농장27파일 SHA `d0aeacdcec8ff0ec088259837ce813fa4da7b8f391906e986bf4d3242ee70dd7`이다.

독립 최종 검산은 요새111개·농장81개 QA표본 모두 통과했고, 수학 소스와 요새13/농장21핵심 함수의 동일성 및 최종 매니페스트의 모든 파일 해시를 확인했다. 기존 대량 검산은 동일 소스의 과거 증거로 재사용한다.

새 첫플레이 탐침은 요새16프레임·농장15프레임, 준비 완료와 콘솔/예외0. 부모와 독립 검수자가 직접 본 최종 화면은 모두 첫 안내 주문에 머물며 오답 설명을 유지했다. 사용자 이해나 자력 완주를 증명하지 않는다. 현재 게임 외부 링크를 탐침 대상에서 제외한 범위와 실제 정밀 입력 회귀를 구분한다.

독립 검수는 **요새87점·농장88점, 둘 다 pass·high0·must_fix 없음**으로 확정했다. 작은 시각 개선은 확인했지만 점수를 자동으로 인상하지 않고 이전 종합 점수를 유지했다. 독립 실제 오답 후 터치 복구도 두 게임에서 통과했다(요새 일반 복구 후130점/목숨2, 농장110점/40코인/목숨2). 새 점수와 검수 기록으로 각각 `publish-game.mjs`의 기본80점 게이트를 통과했고 카탈로그53/53 정합성을 확인했다.

공개 배포 결과는 완료 후 기록한다. 공장 점수는 상용 아트 동등성이나 실제 학생 선호·이해의 증거가 아니다.
