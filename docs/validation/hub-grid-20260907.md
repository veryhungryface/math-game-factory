# 게임 목록 격자 리디자인 — 2026-09-07

단원마다 새 행을 만들던 목록을 학년별 연속 격자로 바꿨다. 각 학년 안에서 학기와 단원 순으로 게임을 정렬하고, 모든 카드의 이미지 위에 학기·단원 번호·단원명을 표시한다. 제목, 브라우저 탭, 공유 제목은 「이것은 게임인가 공부인가」로 통일했다.

원본은 `factory/lib/build-index.mjs`이며 `public/index.html`과 `catalog.json`은 빌드로 생성했다. 학년 바로가기와 기존 학기 앵커, 게임 링크와 제작 과정 링크를 유지했다. 카드에서 성취기준 코드 배지를 덜어내고 게임 제목과 소개를 중심으로 정리했다.

## 확인 결과

- 빌드와 카탈로그 정합성 검사 통과. 게시 게임 51개 모두 한 번씩 노출되며 누락과 중복 없음.
- 320·390px에서 2열, 820px에서 3열, 1280·1440px에서 4열 확인. 5개 화면 모두 가로 넘침·페이지 오류·실패 요청 0.
- 모든 카드의 단원 정보가 이미지 위에 있으며, 교육과정 단원명과 학년/학기/단원 순서가 일치함을 DOM으로 대조했다.
- 학년 바로가기 터치 영역 44px 이상, 5학년 이동 및 별빛 항로 카드 클릭 후 실제 게임 로딩 확인. 긴 단원명도 생략하지 않는다.
- 390px 페이지 높이 **18,683→6,962px(62.7% 감소)**, 1440px **9,808→5,277px(46.2% 감소)**. 뷰포트 높이는 900px이며 본문 전체 스크롤 높이를 측정했다.
- 화면과 DOM 측정은 `logs/hub-grid-20260907/`에 보존했다.

작업 중 다른 세션이 커밋한 게임 설명 수정 3편도 최신 meta.json에서 카탈로그에 재생성됐다. 이 작업은 게시 포함 정책이나 개별 게임을 수정하지 않았다.
