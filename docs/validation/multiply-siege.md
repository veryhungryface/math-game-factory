# 곱셈 포대 검증 기록

2026-09-07. 대상: `public/g/multiply-siege/`, 3학년 2학기 곱셈 `[4수01-04]`.

## 구현

한 묶음의 블록 수와 묶음 수를 고르면 그 곱만큼의 탄약을 발사한다. 성문의 남은 블록을 제한된 발사 횟수 안에 정확히 없애는 부분곱 퍼즐이다. 세 구역의 아홉 성문은 두 자리×한 자리 복습, 세 자리×한 자리, 두 자리×두 자리 순서다. 첫 성문만 `24 × 3`으로 고정하며 나머지는 공통 생성기에서 고른다. 구역별 선택 가능한 탄약과 발사 횟수가 다르다.

초과 발사는 수리 기회 하나만 소모하며 기존 명중을 지우지 않는다. 성문마다 명중 한 번을 되감거나, 수리 기회 하나로 다시 쌓을 수 있다. 다시 쌓기의 비용은 버튼과 첫 안내에 노출했다. 계산 중 시간 제한은 없다. 음소거, 키보드, 모바일 터치, 재시작, 최고 기록을 구현했다.

## 검산과 실제 입력

`scratchpad/multiply-siege/check.mjs`는 게임과 다른 반복 덧셈 방식으로 1,120개 표본을 검산했다. 표본 수 40 / 17 / 63 / 1,000을 각각 지켰다. 마지막 1,000개가 공통 생성기의 세 단계 × 240 인덱스 전부를 포함한다. 각 표본의 실제 탄약/묶음 선택지를 사용한 도달 가능한 합 집합을 별도로 만들어, 제한된 발사 횟수 안에 목표를 만드는 해가 존재함도 확인했다.

실제 브라우저 클릭으로 첫 실행 안내를 읽고, 고의로 `20 × 5 = 100`을 72개 성문에 쐈다. 남은 블록 72개는 유지되고 수리 기회만 5→4가 되었다. 이어서 읽기 전용 `solutionHint()`가 제시하는 선택지를 실제 DOM 클릭으로 조작하여 9개 성문 모두를 열었다. 최근 기록은 정상 발사 26회와 고의 초과 1회, 1,650점, 승리다. 완주 과정에서 `answerCorrect()` / `answerWrong()` / `start()` 훅을 사용하지 않았다.

같은 탄약 선택과 발사 키를 80번 반복해도 점수와 해결 성문은 0이었다. 키보드 선택/발사로 실제 점수가 올라갔고, 명중 되감기가 정확히 60개를 돌려주고 두 번째 되감기는 비활성화됨을 확인했다. 390×844 / 820×1180 / 1280×800에서 가로 넘침이 없고 장부 하단은 각각 839 / 1171 / 791px였다. 브라우저 예외 0건. 원시 증거는 `scratchpad/multiply-siege/evidence.json`.

## 이미지와 공식 QA

생성한 독창적인 펠트 요새 배경을 설치하고 모바일/데스크톱 타이틀을 직접 확인했다. 실제 페이지 캡처로 `thumb.png` 1200×630과 `square.png` 1080×1080을 만들었다. 캐스트는 상대 경로의 공유 정본만 참조한다. 게임 중 배경과 성문/캐스트의 정적 부분은 오프스크린 캔버스에 캐시하며 물결, 포물선, 탄약, 파편은 매 프레임 그린다.

공식 명령: `node factory/lib/qa.mjs multiply-siege --out scratchpad/multiply-siege/qa`.

최근 결과는 **41/43, 치명적 결함 0건**이다. 훅 준비, 실제 포인터 입력, 모든 수학 표본, 이미지 규격, 모바일/태블릿/와이드, 콘솔/네트워크 검사는 통과했다. 두 미통과 항목은 머신 과부하로 보류된 FPS 측정이다: 모바일 원시 중앙값 29fps, 데스크톱 21fps; 같은 브라우저 머신 벤치 2fps, 코어당 부하 최대 3.21. 하네스는 두 항목을 비치명으로 판정했다. 이를 60fps 달성 증거라고 주장하지 않는다. 부모 에이전트가 브라우저를 직렬화한 최종 확인을 수행한다.

이 문서는 게임 제작자의 검증 기록이며 독립 품질 점수를 부풀리거나 배포 승인으로 대체하지 않는다. 게시/장부/커밋/배포는 부모 에이전트 소관이다.

## 호스트 직렬 최종 QA 추가 기록

부모 에이전트가 브라우저를 직렬화하여 다시 실행한 공식 QA는 **43/43 통과, 치명적 결함 0건**이다. 원시 FPS 중앙값은 모바일 33fps, 데스크톱 46fps로 두 기본 게이트를 통과했다. 최종 증거: `scratchpad/three-games-20260907/qa/multiply-siege/report.json`. 이전 41/43 결과는 병렬 부하 상황의 이력으로 남긴다. 독립 검수 점수 77점은 그대로 보존하며, 이 자동 QA 통과를 이유로 점수를 올리지 않는다.
