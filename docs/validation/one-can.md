# 한 통 — 제작 및 검증 기록

2026-09-08. 대상은 `public/g/one-can/index.html`, `engine.js`, `meta.json`이다. 제공된 표지 및 에셋 6개를 보존했다. **제작·엔진 검증과 실제 Chromium 포인터 완주는 완료했다. 원본 공식 QA 명령은 샌드박스의 localhost 금지로 서버 생성 전에 막혔고, 동일 검사 코드를 file URL·단일 프로세스 브라우저로만 치환한 보조 실행은 치명 0이었다. `meta.qa`는 공식 게이트 미완료를 반영해 0/80/false다.**

컵 전체를 레일에서 눌러 떨어뜨리고, 정확한 정수 mL 합으로 액면을 올린다. 1000 mL를 채우면 빨간 뚜껑이 닫히고 통이 롤러를 따라 나간다. 주문의 부분 통은 출고 수에 더하지 않는다. 초반 채움·역추적, 혼합 단위, 뺄셈 뒤 남은 양, 두 양의 합 순으로 진행한다. 모든 유형이 같은 컵 드롭 입력을 사용한다. 독립 비교 통 선택 및 컵 꺼내기는 별도 조작 경로를 만들지 않도록 축소했다.

공개된 통당 컵 3개 예산으로 가장 작은 컵만 반복하는 우회를 막았다. 합법적인 적은 양 넣기는 덧셈으로 인정하고 점수를 준다. 컵 예산을 소진한 부족 상태와 용량 넘침은 별도 원인으로 기록·설명하며 각각 생명 1을 쓴다. 생명 0이나 90초 종료에서 멈추고, 재시작 버튼 외 경로로 회복하지 않는다. 안내의 500+500 통은 세션 출고에 포함하고 첫 시도 학습 통계에서는 제외한다. 안내 이후에 90초가 흐르며, 주문 완료 시 출고 8통 이상이면 성공한다.

시작 화면은 크라프트 위 스텐실 간판과 제공 키 아트의 인쇄물 구성이다. 플레이 배경은 코드로 한 번 구운 크라프트·테이프·롤러뿐이다. 흰 배경의 cup/hero/lid 이미지를 억지로 씌우지 않고 오브젝트를 직접 그렸다. 타이틀 이미지에는 onerror 폴백이 있다. 70ms 뚜껑 예비 정지, 통 눌림과 복원, 뚜껑 overshoot, 컵 잔상, 순환 레일, 타격 시점 생성음, 빛 반사를 구현했다. 정답 화면 흔들림이나 범용 파티클 묶음은 없다. 오답 뒤 목표 액면 예시를 보여 준다.
