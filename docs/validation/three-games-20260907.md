# 2026-09-07 수동 제작 3편

사용자 요청: 3·4학년의 창의적인 게임을 최소 3편 제작하고 배포. 후속 지시로 **80점 미만이어도 배포**를 명시했다.

| 게임 | 교과 범위 | 실제 구성 | 독립 검수 점수 |
|---|---|---|---|
| 곱셈 포대 (`multiply-siege`) | 3-2 곱셈 | 부분곱으로 탄약을 나누어 보내는 3구역·9성문 | 77 |
| 분수 레일 원정 (`fraction-rail`) | 4-2 분수의 덧셈과 뺄셈 | 같은 전체를 기준으로 레일을 더하고 덜어 내는 12역 | 79 |
| 소수 드리프트 (`decimal-drift`) | 4-2 소수의 덧셈과 뺄셈 | 정수 백분의 일 연료 계산·두 갈림길·3코스 9구간 | 79 |

## 검증과 범위

- 제작자 외의 에이전트가 코드·수학 모델·실제 입력 증거·스크린샷을 교차 검수했다. 전체 카탈로그의 모든 시각 비교나 실제 어린이 사용자 조사를 수행한 것은 아니다.
- 호스트가 최종 소스를 직렬 QA: 포대 43/43, 철도 42/43, 드리프트 43/43. 세 게임 모두 치명적 결함 0, 콘솔 오류 0, 미처리 예외 0, 실패 요청 0.
- 포대 원시 FPS 모바일 33 / 데스크톱 46. 철도 43 / 32. 드리프트 모바일 31 / 데스크톱 32. 별도 실제 주행은 모바일 30.75 / 데스크톱 35.95FPS이며 좌우 갈림길 이동도 확인했다. 보정 수치를 실제 기기 FPS로 주장하지 않는다.
- 철도 비통과는 와이드 검사 훅의 필드명(`stageW`와 `playW`) 불일치였다. 실제 전체 화면 폭은 1280px이며, 필드명은 이후 수정했고, 브라우저 재검사에서 playW=1280·land=true·가로 넘침 없음으로 통과했다. 사용자 화면 동작 변경 없음.
- 실제 포인터·키보드 입력으로 포대 9성문 완주 및 실수 복구, 철도 12역 완주 및 되돌리기·전망역 선택, 드리프트 9구간 완주·3회 오답 종료·재시작을 확인했다. 정답 처리 훅만 사용한 검증과 구분한다.
- 수학: 포대 공통 생성 풀 720개 조합의 곱과 발사 한도 내 해 존재 확인. 철도 생성 표본 6000개에서 정수 분수 판정·정규/전망역 해 존재 확인(6000개 모두 서로 다른 문항은 아니다). 드리프트 5000문항의 45000경로에서 정수 판정·유일해 확인.
- 호스트가 최종 QA 표본도 별도 BigInt 검산: 포대 63 / 철도 76 / 드리프트 63문항·567경로, 오류 0.
- 호스트 첫 플레이 캡처는 정답을 모르는 무작위 입력 하네스다. 이를 실제 어린이의 이해도 실험이나 첫 성공 증거로 과장하지 않는다. 별도 실제 입력 완주 증거와 함께 읽는다.

## 남는 품질 한계

세 편 모두 완결된 소형 웹게임이다. 상용 콘솔 대표작 수준의 콘텐츠 양·전략적 깊이·미술 일관성을 달성했다고 주장하지 않는다. 생성 타이틀과 직접 그린 플레이 화면 사이에는 재질 차이가 남는다.

철도는 무제한 되돌리기·다시 풀기를 허용하며, 실패는 별 보상 감소로 반영한다. 생존 게임이나 3회 실패 종료 구조가 아니다. 마지막 화면의 내부 상태는 `arrival`이고 완료 판정은 `solved=12`와 완료 제목으로 확인한다. 드리프트의 주행 조작은 실뭉치 보너스를 위한 것이며 동적 경쟁 순위는 구현하지 않았다.

## 게시 예외의 정직한 기록

`publish-game.mjs --manual-approval '<이번 사용자 지시>'`를 사용한다. 점수와 기본 게이트 80, `qa.passed=false`를 보존하고 `qa.manual_release` 및 생산 장부에 별도 승인 사유와 시각을 기록한다. 이전 파일의 승인 정보는 다음 호출을 자동 승인하지 않는다. 자동 생산 `run.sh`는 변경하지 않았다.

새 게시 옵션의 회귀 검사 `node factory/checks/manual-publish.mjs`: 10개 격리 임시 저장소 검사 통과. 기본 79점 거부·80 미만 게이트 거부·빈 사유 거부·실제 79점 게시·허브 노출·멱등성·기존 승인 재사용 거부·정상 80점 복귀를 포함한다.

## 자산

무대 3장은 이번 작업에서 OpenAI 이미지 생성 도구로 새로 생성한 오리지널 펠트 풍경이다. 캐스트는 기존 `public/vendor/cast/`를 상대 경로로 공유한다. 상용 게임 캐릭터·로고·음원은 사용하지 않았다. 음향은 사용자 입력 후 Web Audio로 합성한다. 철도 제목 서체는 게임 폴더에 포함된 Jua 서브셋이며 OFL 라이선스 파일을 동봉했다.

각 게임 상세 기록은 같은 디렉터리의 `multiply-siege.md`, `fraction-rail.md`, `decimal-drift.md`를 참고한다. 최종 게시 증거는 `logs/manual-20260907-three-games/`에 보존한다.
