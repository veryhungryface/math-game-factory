## 구현에서 바로잡은 기획의 수학적 문제

학생은 움직이는 큰 별·작은 별·반쪽 별을 직접 쏘아 접시에 담고, 접시 위 별을 눌러 되돌린다. 정수 범례와 그림그래프를 읽어 목표를 구성하는 입력 경로다. 숫자 합계와 정답 후보 표시는 실전 중 없다.

기획서의 ‘같아지는 순간 자동 제출’과 ‘전체 재고가 목표보다 크면 연타 성공 0%’는 동시에 성립하지 않는다. 예컨대 큰 별 4개·작은 별 6개를 임의 순서로 전부 쏠 때 주문 34가 중간 합에 나타날 확률은 50%다. 최종 부분집합 60/1024와도 다른 값이다. 재고에서 일정 개수만 빼는 정책과 큰 별 2개 뒤 작은 별을 차례로 더하는 정책도 문제를 읽지 않고 중간 정답을 탐색했다.

이 우회를 막기 위해 **실전 접시는 한정된 별 행렬이 모두 지나간 뒤 판정한다.** 넘침은 즉시 목숨을 잃으며, 성공 값에 잠깐 닿아도 조기 제출하거나 정답 피드백을 주지 않는다. 온보딩 21만 세 번의 실제 탭 직후 제출한다. 확인 버튼이나 추가 답 입력 경로는 없다. 목표별 재고 수와 초기 오류 접시 수를 같게 하고, 모든 실전 별은 왼쪽에서 입장한다. 그래프의 정답 행에만 반쪽 표시가 있던 단서도 제거했다. 플레이 안내와 메타데이터는 이 최종 동작을 설명한다.
