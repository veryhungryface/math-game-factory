# 분수 레일 원정 검증 기록

- 대상: `public/g/fraction-rail/`
- 학년/단원: 4학년 2학기, g4s2-u1 분수의 덧셈과 뺄셈, [4수01-15].
- 설계/검산 상세: `scratchpad/fraction-rail/PLAN.md`.

## 구현

세 구역에 걸친 열두 역을 분수 길이의 철도로 연결한다. 분모 4·5·6·8을 사용하고, 실제 레일 길이는 화면에 표시한 동일한 전체 1을 기준으로 정직하게 비례한다. 앞 구역은 덧셈, 중간은 뺄셈, 종반은 자연수·대분수의 받아내림을 다룬다. 조각마다 재고 2개와 공구 사용 한도가 있으며, 세 번째 역부터 전망역에 도전할 수 있다. 계산 결과를 출발 전에 자동으로 제시하지 않는다.

제목/온보딩/플레이/도착/완주/새 여행/이어하기를 구현했다. 사용자 제스처 뒤에만 소리를 활성화하고 음소거를 저장한다. 모바일 터치와 키보드는 같은 실제 게임 조작을 호출한다. 정적 원화는 CSS 배경으로 그려 Canvas 매 프레임의 큰 이미지 리샘플링을 제거했다.

## 실제 입력과 수학

`node scratchpad/fraction-rail/real-input.mjs`

- 실제 Chrome pointer 입력으로 12/12역 완주, trusted click 53회.
- 의도적인 잘못된 출발 1회는 진행/보상을 올리지 않았다. 잘못 놓은 레일을 되돌린 뒤 동일 여행을 완주했다.
- 서로 다른 구역의 전망역 2개를 통과했다.
- 실제 생성기 `generateStation(index, seed)`와 같은 함수를 `sampleProblems(n)`이 사용한다.
- 6,000개 생성 표본에서 정수 정답, 양의 목적지, 기본/전망 목표에 대한 재고 한도 내 해 존재를 전수 검사했다. 오류 0개.
- 페이지 JavaScript 예외 0개.
- 결과 JSON: `scratchpad/fraction-rail/real-input-results.json`.

`node scratchpad/fraction-rail/bot-audit.mjs`

실제 생성기 소스를 이용한 별도 상태 모델 검사다. 무입력·같은 조각 연타·1→2→3 순환·무작위 각 200여행 모두 완주 0/200. 무입력은 역 하나도 통과하지 않았다. 이 모델 검사를 실제 pointer 검사의 대체 증거로 사용하지 않는다.

## 자동 QA

최종 원화 적용 및 정적 배경 분리 후 호스트의 순차 QA: **42/43 통과, 치명적 실패 0건**. 보정 전 원시 FPS는 모바일 43 / 데스크톱 32였다. 보고서: `scratchpad/three-games-20260907/qa/fraction-rail/report.json`.

유일한 미통과 항목은 실제 와이드 캔버스 폭을 반환하는 훅의 키 이름이었다. `getLayout()`에 하네스가 요구하는 `playW`, `playH`, `land`를 실제 뷰포트 치수로 추가했다. UI와 플레이 동작은 바뀌지 않았다. 이 수정은 호스트의 최종 플레이에서 별도 확인을 기다린다.

독립 검수는 **79점, must-fix 없음**. 자유로운 되돌리기와 무제한 재시도는 의도된 아동 친화 설계이며, 잘못된 출발은 별과 보상을 낮춘다. 학습 가능한 공간 구성 게임을 경쟁형 생존 게임처럼 포장하지 않는다. 사용자는 80점 미만도 게시하라고 명시했으므로 실제 79점을 유지하는 수동 승인 경로를 사용한다.

원화 도착 전과 Chrome 동시 실행 중의 중간 QA에는 404/FPS 실패가 있었으며, 그것을 최종 점수나 합격 증거로 사용하지 않는다.

## 게시 예외 경로 회귀 검사

사용자의 명시적인 점수 미달 게시 요청을 기록할 수 있도록 `--manual-approval <사유>`를 publisher에 추가했다. 이 옵션은 호출별로만 유효하다. 실제 점수와 `qa.passed`를 바꾸지 않고 명시 승인 사유/시각을 메타와 장부에 보관한다. 기본 80점 게이트와 `--gate < 80` 거부는 유지한다.

`node factory/checks/manual-publish.mjs` — 10개 격리 CLI 회귀 검사 통과. 임시 저장소로 스크립트를 복사해 검사하므로 실제 장부나 카탈로그에 쓰지 않는다. 기본 79 거부, 낮은 gate 거부, 공백/누락 사유 거부, 명시적 79 게시, 실제 점수/불합격 보존, 허브 노출/검증, 재게시 중복 방지, 이전 승인 재사용 거부, 정상 80 통과와 예외 제거를 포함한다.
