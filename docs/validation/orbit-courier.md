# 별빛 항로 — Blender 에셋 기반 3D 곱셈 게임

## 구현

5개 모델은 Blender 5.2에서 제작한 원본 지오메트리와 PBR 재질이다. 런타임 GLB 합계는 약 525KB이며 외부 텍스처나 CDN이 없다. 로켓의 붉은 날개·아이보리 몸체·파란 창을 유지했다. 1200×630 및 1080×1080 표지도 같은 모델을 Blender에서 렌더링했다. ZIP에는 편집 가능한 `.blend`, 생성 스크립트, GLB와 README가 포함된다.

공용 r185 GLTFLoader가 참조하는 유틸리티 두 파일은 게임 폴더 안에 동일 버전 npm 원본과 MIT 라이선스로 포함하고 import map으로 연결했다. `public/vendor/`는 수정하지 않았다.

9미션 중 첫 문항 `112×3`은 안내 전용이며 일반 문항 첫 시도 정답률에서 제외한다. 나머지 8문항은 실제 출제 풀 767개에서 중복 없이 뽑는다. `sampleProblems()`도 같은 풀을 사용한다. 정수 화물의 합과 정수 곱을 비교하며, 배달 오답은 화물과 문제를 보존하고 목숨 1개를 줄인다. 오답 3회는 실패 화면으로 연결된다. 4미션부터 움직이는 운석과 충돌하면 마지막 화물을 잃고 자동 항로가 취소되며 4초 보호 시간을 준다.

## 검증

독립 검수 **88점 · must_fix 없음**, 최종 QA의 115문항 전수 검산도 오류 0이다. `publish-game.mjs`의 80점 기본 게이트를 통과했고, 게시 직후 카탈로그 정합성은 **51/51**이었다.

최종 QA는 **44/44 통과 · 치명 0 · 콘솔/예외/실패 요청 0**이다. Apple M4 ANGLE/Metal에서 모바일 뷰포트 390px와 데스크톱 1280px 모두 중앙값 60FPS, 15초 뒤 유지율 100%였다. 마지막 390/320px 화면을 다시 촬영해 제목·조작 영역과 실제 100 적재 상태를 확인했다.

- 독립 수학 검사: 한국어 발문의 두 피연산자를 읽어 BigInt로 검산했다. 생성 함수의 경계 포함 777조합, 실제 풀 전체를 포함하는 2,000표본, 1,000캠페인 9,000문항에서 오류 0. 요청한 표본 수 0·17·40·63·2,000을 정확히 반환했다.
- 실제 입력 완주: UI 클릭과 이동으로 정상 9미션 완주(목숨 3, 일반 문항 첫 시도 8/8), 두 번째 미션에 일부러 오배송한 뒤 9미션 완주(목숨 2, 7/8). 운석으로 화물을 잃은 뒤 재적재·재경로 지정으로 복구했다. 답을 주입하는 훅은 사용하지 않았다.
- 실제 모바일 터치: 390×844 DPR 2에서 100×3·10×3·1×6을 실어 첫 배달 성공. 별도 터치 길게 누르기·해제 후 적재 정지·되돌리기 확인.
- 조작과 실패: WASD 이동, SPACE 적재, Z 되돌리기, 마우스 길게 누르기, 탭 포커스 상실 시 키 초기화와 위치 정지, 오답 3회 후 실패 및 재시작을 실제 브라우저로 확인했다.
- 무뇌 입력: 안내를 제외하고 무작위 화물·100 반복(900)·100→10→1(111)·고정 336 네 정책을 각 4문항에 실제 적용해 모두 첫 시도 0/4. 무입력 15초는 제출 0이었다. 다음 표본으로 이동하기 위한 정답 복구 시도는 분모에서 제외했다.
- 위 4회 표본만으로 우연 수준의 확률을 추정하지 않는다. 별도 생성기 분석 10,000캠페인·80,000일반 문항에서 고정 900은 0.37375%, 고정 111은 0%, 고정 336은 0.215%였다. 균등 무작위 정수 0..999의 정확한 우연 정답률은 0.1%다. 이 분석은 브라우저 실측과 구분한다.
- 첫 플레이: 정답을 아는 성인 에이전트의 실제 터치 완주와, 답/상태를 읽지 않는 45초 입력 하네스의 14프레임을 별도로 보존했다. 실제 어린이 사용자 조사 결과로 해석하지 않는다.

## 범위와 제한

고정 사선 카메라로 수평 XZ 평면을 비행한다. 세 항로는 같은 공간 배치에 색과 운석 위험이 달라지며, 자유로운 6축 비행이나 서로 다른 지형 세 개를 구현한 것은 아니다. 후반 반복 적재 비중이 높고 손으로 조종하는 전투·경주 경쟁은 없다. 자동 QA의 FPS는 호스트의 Apple M4 GPU와 모바일 뷰포트 결과이며 실제 휴대전화 기기 성능은 측정하지 않았다.
