# 햇살 바구니 제작·검증

상태: 독립 검수88점·게시 게이트 통과·공개 배포 확인 완료.

사용자는 쌍둥이 요새의 개선을 인정하며, 다른 Supercell 게임에서 착안한 신작 한 편을 디자인에 신경 써서 만들어 달라고 요청했다. 이번 작품은 Hay Day의 재배→수확→납품→농장 성장 흐름을 참고한 오리지널 농장이다. 원작 이름·캐릭터·에셋을 게임에 사용하지 않는다. [공식 자료를 읽고 실제 화면에서 관찰한 설계](../../references/case-studies/hayday-sunbasket-20260907.md)는 별도로 기록했다.

## 게임과 수학

5학년 1학기 `g5s1-u6` 다각형의 둘레와 넓이, `[6수03-13]` 직사각형과 정사각형의 넓이에 연결한다. 주어진 가로와 주문량을 보고 밭의 세로를 직접 늘려 맞춘다. 이 게임의 밭에서는 1m²마다 1상자를 수확한다는 가정을 화면에 표시한다. 가로6m·주문42상자이면 필요한 넓이42m², 세로7m다.

길이를 고르는 행위가 수학 답 입력이다. 제출 전 현재 길이는 보이지만 계산한 넓이·수확량·정답 여부는 알려주지 않는다. 심기의 정오답과 첫 시도 성적을 확정한 뒤 작물이 자라고, 손으로 쓸어 수확한 상자는 수레로 가게에 보낸다. 수확 진도는 수학 정답률과 별개다. 오류 후 같은 주문을 고칠 수 있고, 세 번 틀리면 하루가 끝난다.

## 디자인

열린 목조 농장과 낮은 3/4 시점으로 전투 경기장과 다른 장면을 구성한다. 실제 Blender 모델은 곡선 지붕·아치 문 농가, 줄무늬 어닝 가게, 수레, 풍차, 과수, 울타리, 세 작물, 상자로 구성했다. 작물 아이콘과 간판 로고도 같은 렌더 자산을 사용한다. 표지와 실제 게임의 모델을 일치시키며 표지만으로 완성도를 판단하지 않는다.

## 초기 독립 수학 검산

`logs/manual-20260907-sunbasket-farm/validation/math-source-report.json`과 별도 BigInt 오라클에 기록했다. 생산 코드의 판정 함수를 정답 오라클로 사용하지 않는다.

- 일반99쌍·안내1개, 판정3,400회, 무작위5,000일 생성·일반40,000문항, 한국어 표본2,000개에서 오류0.
- 첫 안내 가로4m·세로3m·12상자는 일반 통계에서 제외한다. 첫 일반 주문부터 단계별 숫자 범위를 넓히는 실제 생성 분포를 사용한다.

최종 `mathcheck.json`은 같은 math 소스 SHA를 확인하고 QA의 실제 한국어 표본80개를 별도 정수 연산으로 전수 재계산했다. 오류0이며 최종26파일 산출물 해시와 연결했다. 기존40,000문항 감사를 다시 실행한 것으로 쓰지 않는다.

## 재현과 검증 범위

증거 폴더는 `logs/manual-20260907-sunbasket-farm/`, 실행 스크립트는 그 안의 `reproduce/`다. 첫 플레이 탐침은 기존 무작위 조작 정책에 실제 GPU를 사용하며, 게임 외부로 이동하는 링크를 대상에서 제외한다. 이는 게임 내부 조작을 관찰하는 범위 제한이고, 링크 이동은 별도로 검증한다. 탐침은 정답을 읽지 않으며 실제 어린이 사용자 연구를 대체하지 않는다.
