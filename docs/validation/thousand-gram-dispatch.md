# 천 그램 출고 — 빌드 검증 (2026-09-06)

`public/g/thousand-gram-dispatch/index.html` / `meta.json` 구현. 게시하지 않음, `qa.passed=false` 유지.

## 실제 구현
- 고정 300+700 g 연습 → 정수 g 두 봉투 드래그 → 실제 합 판정 → 진공 수축·롤러 배출.
- 16칸 영속 선반, 다음 주문/유입 표시, 두 번째 봉투 전 취소, 방향키/스페이스/Esc, 탭 읽기·거절 피드백.
- 90초/12출고, 실패 3회 종료, 시간 경과 유입 7→5초, 첫 봉투 유입 60% 감속, 2연속 출고 방해물 1개 제거.
- 3개 난도 밴드, 1000 g 받아올림을 자릿값부터 생성하는 유한 풀 608개, 역추적 및 목표보다 무거운 첫 봉투를 빼는 오류 수정.
- 동일 크기 라벨 봉투, 모노스페이스 감열지 HUD, 라일락 코드 배경, 실제 무게 비례 바늘, 70ms 봉합 정지/수축/열봉합 잔상/감열 잉크/구김 idle/단계별 코드 오디오.
- 정상 판은 현재 주문의 다른 짝을 고르면 다음 주문 짝의 보존 여부가 달라짐. 유입 표시는 다음 공급과 보충 짐을 표시함.

## 실행한 검증
- `node docs/validation/thousand-gram-dispatch-audit.mjs`: 실제 게임의 ENGINE 구간을 VM으로 실행, 수학 전수 608개·정수 덧셈/뺄셈·answer∈choices·중복/정답과 오답 우연 일치 0건.
- 정상 해결 정책 200/200 완주, 첫 일반 실수 1회 후 해결 정책 200/200 완주. 계산 가능한 짝이 없는 최장 대기 2.3초(정상 해결 정책).
- 무뇌 봇 각 200판: 연타/순환/무작위/무입력 완주율 모두 0%; 평균 점수 16 / 44 / 45.5 / 0.
- 봇은 튜토리얼을 통과한 본판부터 시작한다. 동일 엔진의 `take`/`tick` 호출이며 브라우저 이벤트 측정이 아니다.
- `node docs/validation/thousand-gram-dispatch-input-audit.mjs`: 전체 inline JS 구문 검증, DOM 스텁 위에서 실제 pointerdown/move/up 핸들러를 호출하여 300 g 놓기·선반 반환·700 g 출고·일반 오답 목숨 감소 확인. 표본 요청 40/17/63 각각 해당 수량과 고유성 확인. 실제 브라우저 이벤트 검증을 대신하지 않는다.
- 상대 이미지 2개 실제 파일 존재, 공유 이미지/필수 PNG 존재, 교육과정 코드 및 meta QA 초기값 확인.

## 막힌 검증과 남은 한계
- `node factory/lib/qa.mjs thousand-gram-dispatch`: 서버 bind `listen EPERM 127.0.0.1`, 브라우저 이전 종료. 치명적 결함 0건이라고 주장할 수 없음.
- `FIRSTPLAY_PLAY_MS=45000 node factory/lib/firstplay/harness.mjs thousand-gram-dispatch`: 동일 EPERM. 프레임 생성/육안 검토 없음.
- file URL 브라우저 시도: Puppeteer 기본 Chrome은 framework 누락, 설치된 Google Chrome도 프로세스 시작 실패. 실제 터치/레이아웃/FPS/콘솔/이미지 실패 폴백은 브라우저 미검증.
- 제공된 에셋 목록에 별도 로고/CTA/PC 배경이 없어 `title.png` + 코드 로고 + `hero.png` CTA를 사용했다. 생성 로고 강제 규격은 미충족이다.
- 기획의 비교 2/단위 2/계산 4/생활 2/역추적 1/오류수정 1 문항 비율은 그대로 구현하지 않았으며, 합 구성 중심 + 후반 역추적/실린 짐 고치기로 축소했다.
- '받아올리지 않은 1 kg 1200 g'은 2200 g과 동일한 무게라 수학적 오답으로 사용하지 않았다. 실제 수가 다른 kg 누락/100 g 환산/받아내림 오류를 사용한다.
- 독립 검수와 실제 첫플레이 검증 전에는 게시 불가.
- 커밋 준비(`git add` 지정 파일만)도 `.git/index.lock: Operation not permitted`로 차단됨. 기존 HANDOVER 수정은 보존하고 이번 항목만 끝에 추가했으며, 커밋/푸시하지 못함.
