검수 대상은 `manual-20260907-twin-forts-art-v2`의 최종 산출물이다. `meta.json`을 제외한 20개 파일의 경로·SHA-256 목록으로 계산한 해시는 `feb6dc3f534f7f0756fc06bb65d2d9658635071c1e1a37595fef8704ead2123e`이다. ## 실제 조작과 수학 보존

최종 [QA](../../logs/manual-20260907-twin-forts-art-v2/qa/report.json)는 **44/44, fatal 0**이다. [4개 폭 실제 입력](../../logs/manual-20260907-twin-forts-art-v2/host/visual-smoke.json)은 320/390/820/1280px에서 30명을 2:3으로 나누어 12/18 배치→출격→성공에 도달했다. 콘솔 오류와 가로 넘침은 없었다.

[오답 회복 결과](../../logs/manual-20260907-twin-forts-art-v2/recovery/results.json)와 [입력 기록](../../logs/manual-20260907-twin-forts-art-v2/recovery/input-log.json)은 실제 터치·버튼·키보드를 사용한다. 정답을 주입하는 훅을 사용하지 않았고, 화면의 문항을 독립 계산한 뒤 실제 입력으로 제출했다. 테스트 훅은 진행 상태를 읽는 용도로만 사용했다.

- 48명을 3:3으로 나눌 때 25/23으로 제출해 하트2가 됐다. 별도 재배치 버튼을 거치지 않고 손잡이를 터치해 24/24로 바꾸고 성공했다. [수정 전](../../logs/manual-20260907-twin-forts-art-v2/recovery/touch-retry-before-direct-input.png), [직접 수정](../../logs/manual-20260907-twin-forts-art-v2/recovery/touch-directly-repaired.png).
- 한 명 이동 버튼은 15명·3:2에서 10/5→9/6, 키보드는 49명·1:6에서 8/41→7/42로 같은 문항을 직접 복구했다.
- 실수한 원정을 끝까지 진행해 **9작전, 970점, 하트2, 일반 첫 시도 7/8, 전체 제출10회**로 승리했다. 재정답이 첫 실패 기록을 지우지 않는다. 새로고침 뒤 wins1과 장식1이 유지됐다. [완주 화면](../../logs/manual-20260907-twin-forts-art-v2/recovery/recovered-campaign-victory.png).

`math.mjs`의 SHA-256은 v1과 같은 `0820163ea9543938ade05d00ffbd94f1c52dd33697846f310e50c81620907e36`이다. [13개 핵심 함수 비교](../../logs/manual-20260907-twin-forts-art-v2/validation/core-logic-comparison.json)에서도 배분·제출·성공/실패·기록 함수 전체가 동일했다. [이번 독립 재검산](../../logs/manual-20260907-twin-forts-art-v2/validation/mathcheck.json)은 최종 QA의 한국어 문항 **110개**를 BigInt로 별도 계산해 모두 일치했다.

v1의 596개 풀+튜토리얼, 판정33,341회, 5,000캠페인/일반40,000문항, 정상 완주·3회 실패/재시작·단순 입력 봇 증거는 [기존 검수](../../logs/manual-20260907-twin-forts/review.json)를 상속한다. 이를 v2에서 다시 실행했다고 주장하지 않는다. 수학과 핵심 함수의 동일성만으로 바뀐 화면 조작을 보증하지 않고, 위의 최종 QA와 실제 v2 입력으로 연결을 별도 확인했다.

## 첫플레이와 성능의 판정 범위

최종 GPU 첫플레이의 13프레임을 순서대로 모두 열었다. **00–05의 6장만 쌍둥이 요새**다. 06은 홈 링크를 누른 뒤의 허브, 07–12는 다른 게임이므로 이 게임의 진행 증거에서 제외한다. [범위 기록](../../logs/manual-20260907-twin-forts-art-v2/validation/firstplay-scope.json).

유효 프레임에서 타이틀의 병력 배분 설명, 시작 직후 30명·2:3, 손잡이 안내, 출격 버튼을 볼 수 있다. 전장 탭에는 리플과 손잡이 포인팅이 보이지만 탐침은 문제를 풀지 못했다. 별도의 실제 입력 성공은 조작 경로가 작동한다는 반례다. 검수의 `comprehensible: yes`는 **화면 설명과 입력 경로를 확인한 제한된 판단**이며, 탐침의 자력 성공이나 아동 이해율을 뜻하지 않는다. 47초 전체가 이 게임의 첫플레이였다고 기록하지 않는다.

기본 하네스의 강제 소프트웨어 렌더러 실행은 기록상33초의 frame06 뒤 장시간 멈춰 종료했다. [미완료 기록](../../logs/manual-20260907-twin-forts-art-v2/firstplay-naive-software-incomplete/)은 호환성 통과로 취급하지 않는다. 완료된 GPU 재실행은 탐침 정책을 유지하고 강제 소프트웨어 플래그만 제거한 것이다.

최종 QA의 Apple M4 실 GPU에서는 모바일390·데스크톱1280 모두 약60fps, 체류 전후60→61fps, 유지율1.02였다. 이는 개발용 GPU 결과이며 저가 Android/iOS 실기기나 소프트웨어 렌더러의 성능을 보증하지 않는다. 학생의 첫 판 이해, 만족도, 자발적 재방문은 이번 검수에서 관찰하지 않았다.
