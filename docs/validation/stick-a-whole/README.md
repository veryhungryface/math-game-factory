# 붙여 한판 — 2026-09-06 빌드 검증

상태: **구현 초안, 브라우저 QA 미검증 / 게시 보류**. `meta.json.qa.passed`는 false다.

## 구현

- 두 장을 레일의 실제 시작 칸에 드래그해 배치. 합계뿐 아니라 겹침·빈틈·레일 선택도 검사한다. 탭으로 답을 제출하는 우회 버튼은 없다.
- 고정 연습(1/4, 2/4 → 3/4) 뒤 2~8방 지속 손패: 세 장 보존, 사용한 카드 ID는 한 방 쉬고 두 장 보충. 카드는 날짜 시드로 섞인다.
- 3방은 4/4, 4방부터 수동 한 판 경계, 6방부터 같은 분모 비교, 8방은 잘못된 나머지 위치의 경계를 수정한다.
- 두 정답 짝을 갖는 30개 분모 4 손패-목표 multiset을 전수 생성. 이후 방들에서도 두 선택 모두 진행 가능하며 적어도 하나는 다음 목표 짝을 남기는지 유한 역방향 탐색으로 검사한다.
- 분수는 정수쌍과 정규화한 값으로 저장하고, 화면은 3학년 범위에 맞춰 원래 분모의 세로 분수로 표시한다.
- 물밀대 이동·배접지 박리·물방울·유약 무늬·4연속 교차선, 음소거·사용자 제스처 이후 생성음, 로컬 기록, 키보드 집기/방향/놓기 제공.
- 타이틀의 `어떻게 놀아요?`로 조작 안내를 다시 열 수 있고, 재방문자는 고정 연습의 동결을 건너뛴다. QA `start()`도 타이틀과 연습 동결을 함께 건너뛴다.

## 기획 모순에 대한 변경

1. 오답으로 방을 영구 폐쇄하면 8방에서 8장을 채울 수 없다. 오답은 시험편/보호 유약을 소비하고 **같은 주문을 재시도**한다. 첫 일반 실수 뒤 승리 경로가 있다.
2. 첫 고정 손패의 서로 다른 분모와 정상 5장/2정답쌍 조건은 함께 유지할 수 없다. 첫 판은 무료 연습, 2방 진입 때 작업 손패를 지급하며 이후에는 세 장을 보존한다.
3. 분모 4·목표 4에서 목표값 카드도 금지하면 5장에 정확히 두 정답쌍을 만들 수 없다. 목표값 한 장을 허용하되 **반드시 두 장**을 사용하게 한다.
4. 150초 작업 타이머는 첫 연습에서 정지한다. 무조작 150초 종료는 별도이며 화면에 명시한다.

## 실행이 막힌 필수 검증

- `node factory/lib/qa.mjs stick-a-whole`: 두 차례 모두 `listen EPERM: operation not permitted 127.0.0.1`로 검사 시작 전 종료.
- `FIRSTPLAY_PLAY_MS=45000 node factory/lib/firstplay/harness.mjs stick-a-whole`: 같은 서버 바인딩 제한으로 종료.
- 서버 없는 file URL + Puppeteer pipe 실행: `Protocol error (Target.setDiscoverTargets): Target closed`.
