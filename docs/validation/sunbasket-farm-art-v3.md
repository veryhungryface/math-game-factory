Hay Day·FarmVille 3·Farm Together 2·Township의 공식 이미지를 비교하고 농가, 판매대, 사과나무, 당근을 자체 모델로 다시 다듬었다. [레퍼런스 조사](../../references/case-studies/farm-asset-references-20260908.md)에 실제 플레이 자료와 홍보 합성을 구분해 기록했다.

## 실제 변경

- 농가: 돌출된 박공지붕 현관, 굵은 기둥과 계단, 깊은 입구, 두꺼운 처마와 겹친 지붕. 지붕·벽·문·창·현관 등을 이름 있는 부품으로 분리했다.
- 판매대: 처지는 곡면 천막과 둥근 끝단, 나뉜 상품 진열대를 제작했다. 프레임·천막·상품·간판을 독립 부품으로 만들었다.
- 사과나무: 비대칭 수관과 가지 사이의 틈, 분리된 열매를 만들었다. 줄기·수관·열매는 각각 숨기거나 색을 바꿀 수 있다.
- 당근: 잎과 뿌리 형태를 다듬고 새싹·어린 당근을 추가했다. 기존 1.14초 성장 시간 안에 세 단계 모델을 표시한다.
- 환경: 길의 마모와 가장자리 식생, 현관 앞 디딤돌, 과수 아래의 잔디·흙 경계, 부드럽게 휘는 풀잎과 접지 표현을 조율했다. 길·배치·밭 여유 공간은 재사용 옵션으로 분리했다.
- 표지와 작물 아이콘은 수정한 실제 모델로 다시 렌더링했다. 변경된 모델과 런타임에는 `v=3` 캐시 식별자를 적용했다.

## 재사용 원본

[Sunbasket Kit](../../art/sunbasket-kit/README.md)에 Blender 원본, 생성기, 색 변형 규칙, 부품·앵커·원점 규격을 정리했다. 총12 GLB에는 기존10종과 당근 성장2종이 포함된다. 모든 GLB는 외부 텍스처 없이 정점색을 사용한다. 배포 시 필요한 파일을 각 게임 폴더에 넣어 자기완결 계약을 지킨다.

동일 원본 메시를 사용한 [작은 농장](../../logs/manual-20260908-sunbasket-v3/assets/sample-small-farm.png)과 [마을 장터](../../logs/manual-20260908-sunbasket-v3/assets/sample-village-market.png)를 렌더링했다. 장터는 현관과 한 나무의 열매를 숨기고 부품 색을 바꿔 변형 가능성을 확인했다. 이 샘플들은 완성된 별도 게임이 아니다.

최종 기하 구조: 농가19,840삼각형/8프리미티브, 판매대7,436/4, 나무4,112/3, 당근644/1, 어린당근188/1, 새싹108/1. 12종 모델 자체의 삼각형 합은47,756이며, 게임 장면에서 복제한 전체 삼각형 수를 뜻하지 않는다.
