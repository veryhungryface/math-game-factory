# 2022 개정 교육과정 성취수준 (초등 전 과목) — 구조화 추출본

교육부·한국교육과정평가원(KICE)이 발간한 **2022 개정 교육과정에 따른 학년군별 성취수준** 자료
(hwpx 3종)를 기계 판독 가능한 JSON으로 구조화한 것이다.

지금은 수학 게임 공장이 **난이도 설계 앵커**로 쓰지만, 이후 다른 과목 공장을 돌릴 때
같은 스키마를 그대로 쓸 수 있도록 **전 과목·전 학년군**을 한 번에 정리해 두었다.

## 성취수준이란

- **성취기준**: 학생이 학습을 통해 성취하기를 기대하는 능력·특성 진술. (예: `[6수01-08]`)
- **성취기준별 성취수준**: 각 성취기준에 도달한 정도를 **3수준(A/B/C)** 으로 구분해 진술한 것.
- **영역별 성취수준**: 영역 내 성취기준들을 포괄하는 전반적 특성을 3수준으로,
  **범주(지식·이해 / 과정·기능 / 가치·태도)** 별로 진술한 것.

| 수준 | 일반적 특성 |
|---|---|
| **A** | 기대하는 능력에 도달한 정도가 **우수한** 수준. 개념 이해가 깊고 지식 전이 수준이 높음 |
| **B** | 도달한 정도가 **만족스러운** 수준. 성취기준 본문 그대로의 과제를 수행 |
| **C** | 도달한 정도가 **기초적인** 수준. 안내된 절차에 따라 간단한 과제를 수행 |

※ 이 자료는 A~E 5수준이 아니라 **A~C 3수준** 체계다(초등 전 과목 공통).

## 스키마

```jsonc
{
  "subject": "수학",
  "subject_slug": "math",
  "band": "5-6",
  "levels": ["A", "B", "C"],
  "source": { "publisher": "…", "document": "…hwpx", "license": "공공누리 제1유형(출처표시)" },
  "counts": { "standards": 45, "level_statements": 135, "domains": 4 },

  // 영역별 성취수준 — 범주(지식·이해/과정·기능/가치·태도)별 진술
  "domains": [
    { "domain": "수와 연산",
      "levels": { "A": { "지식·이해": "…", "과정·기능": "…", "가치·태도": "…" },
                  "B": { … }, "C": { … } } }
  ],

  // 성취기준별 성취수준
  "standards": [
    { "code": "[6수01-08]",
      "domain": "수와 연산",
      "content_element": "분수의 덧셈과 뺄셈",   // 수학만 채워짐(문서가 수학만 내용 요소로 묶음). 그 외 과목은 null
      "text": "분모가 다른 분수의 덧셈과 뺄셈의 계산 원리를 탐구하고 그 계산을 할 수 있다.",
      "levels": { "A": "…", "B": "…", "C": "…" },
      "inquiry_activities": ["…"],   // 과학만. 원본의 「탐구 활동」 항목
      "note": "…",                   // 사회 일부. 원본의 「※ …」 각주
      "domain_as_written": "…"       // 원본 절 제목이 영역명과 달라 통일한 경우에만
    }
  ]
}
```

`standards[].domain` 은 항상 같은 파일의 `domains[].domain` 중 하나와 일치한다
(단 1건 예외, 아래 "파싱 한계" 8번 참고). 원본에서 표기가 달랐던 경우
(「이해 영역」/「이해」, 「살아갈까?」/「살아갈까」, 도덕 5-6의 「사회·공동체**과**의 관계」 오타 등)는
영역별 성취수준 표의 이름으로 통일하고 원문을 `domain_as_written` 에 남겼다.

## 파싱 한계 (알려진 것)

1. **표 안의 이미지·도형은 추출되지 않는다.** 「다. 예시 평가 도구」 절의 학습지·그림 문항이
   여기에 해당한다. 이 절은 애초에 추출 대상이 아니다(성취기준별/영역별 성취수준 표만 추출).
2. **수식 객체는 텍스트로 근사 변환한다.** hwpx 의 `<hp:script>` 를 읽어
   `div→÷`, `TIMES→×`, `{a} over {b}→a/b` 로 바꾼다. 문서 전체에서 수식 객체는 8종·17회뿐이다
   (1-2학년군 0회, 3-4학년군 7회, 5-6학년군 10회). 성취기준 본문에 걸린 것은
   `[6수01-10]`·`[6수01-14]` 의 나눗셈 기호 2건이고, 이 변환 없이는 두 문장이
   "‘(자연수)(자연수)’" 로 깨진다. 변환 결과는 수학 대조 검사에서 45개 전부 일치 확인됨.
3. **밑줄·굵기·색 같은 서식은 버린다.** 순수 텍스트만 남긴다.
4. **`content_element`(내용 요소)는 수학에만 있다.** 원본이 수학 절만
   「(1) 수와 연산 → ❶ 자연수의 혼합 계산」 2단 머리표로 묶기 때문이다. 나머지 과목은 `null`.
5. **`domains[].domain` 은 원본 문서의 절 제목을 그대로 따른다.** 과학·사회는 교육과정
   상위 영역(과학 4개 등)이 아니라 **주제 단위**로 제시되어 있어 16개·12개처럼 나온다.
   원본이 그렇게 쓰여 있는 것이지 파싱 오류가 아니다.
6. **1~2학년군 통합교과**(바른 생활/슬기로운 생활/즐거운 생활)는 각 16개 성취기준으로
   동일 코드 체계(`[2바…]` `[2슬…]` `[2즐…]`)를 쓴다.
7. **원본 자체의 표기 흔들림이 있다.** 같은 영역을 절 제목에서는 「이해 영역」, 표에서는 「이해」로
   쓰거나(영어·체육 5-6), 「우리는 누구로 살아갈까?」의 물음표가 붙었다 빠졌다 하거나(통합교과),
   도덕 5-6은 「사회·공동체**과**의 관계」로 오타가 있다. 추출본은 영역별 표 쪽 이름으로 통일하고
   원문을 `domain_as_written` 에 보존했다.
8. **단 1건, 통일하지 못한 영역명이 있다.** 5-6 실과의 성취기준 절 제목
   「생활환경과 지속가능한 **선택**」과 영역별 성취수준 표의 「생활환경과 지속가능한 **삶**」이
   서로 다르다. 어느 쪽이 오기인지 이 문서만으로 판단할 수 없어 **양쪽 다 그대로 두었다.**
   실과를 실제로 쓰게 될 때 교육과정 고시 원문(별책 10 실과)으로 한 번 확인할 것.
9. 파싱 경고는 `index.json` 의 `bands.<band>.parse_warnings` 에 기록된다. **현재 전 학년군 0건.**

## difficulty 1~5 ↔ 성취수준 A~C 앵커 제안

`meta.json` 의 `difficulty`(1~5)는 지금까지 감으로 정해졌다. 성취수준 진술문은
**같은 성취기준을 난이도별로 다시 쓴 공식 문서**이므로, 문제 생성기의 난이도 사다리를
여기에 고정하면 근거가 생긴다. 아래는 오케스트레이터가 프롬프트에 연결할 앵커 표다.

| difficulty | 앵커 수준 | 문제 생성 지침 | 진술문 표지어 |
|:--:|:--:|---|---|
| **1** | **C**(하) | 안내된 절차를 화면에 그대로 제시. 수를 가장 작게. 한 단계 연산만. 오답 선택지는 명백히 다르게 | "안내된 절차에 따라", "간단한" |
| **2** | **C→B** | 절차 힌트는 첫 1~2문제만. 수 범위 소폭 확대. 두 단계까지 | "안내된 절차에 따라" 없이 같은 과제 |
| **3** | **B**(표준) | **성취기준 본문 문장 그대로**의 과제. 힌트 없음. 대표 오개념 1개를 오답으로 배치 | 성취기준 `text` 와 거의 동일한 B 진술문 |
| **4** | **B→A** | 실생활 맥락·여러 방법 비교·역방향 문제(답에서 조건 찾기) | A 진술문의 "실생활 문제를 해결" |
| **5** | **A**(상) | 방법을 **설명·정당화**하게 만들기(선택지형이면 "왜 그런가"를 고르게). 경계값·예외 사례 포함 | A 진술문의 "설명할 수 있다", "그 방법과 관계를" |

**이 앵커가 실제로 작동하는 근거** (수학 진술문 표지어 빈도):

| 학년군 | 성취기준 수 | C에 "안내된 절차" | C에 "간단한" | A에 "설명할 수 있다" |
|---|---:|---:|---:|---:|
| 1-2 | 29 | 18 | 10 | 1 |
| 3-4 | 47 | 32 | 19 | 36 |
| 5-6 | 45 | 34 | 20 | 28 |

즉 5-6학년군 수학은 45개 중 **34개(76%)** 의 C수준이 "안내된 절차에 따라"로 시작하고,
**28개(62%)** 의 A수준이 "설명할 수 있다"로 끝난다. 난이도 1↔C, 3↔B, 5↔A 매핑은
문서의 실제 진술 패턴과 일치한다.

**사용법 (예시)** — 게임 기획·문제 생성 에이전트에 이렇게 주입한다:

```js
// standards 코드로 성취수준 3개를 뽑아 난이도 사다리로 쓴다
const al = require('./curriculum/achievement-levels/5-6/math.json');
const s  = al.standards.find(x => x.code === '[6수01-08]');
// s.levels.C  -> difficulty 1~2 문제의 상한
// s.levels.B  -> difficulty 3 문제의 기준
// s.levels.A  -> difficulty 4~5 문제의 목표
```

`meta.json` 에 `difficulty` 근거를 남기고 싶다면 `achievement_level_anchor: "B"` 같은
필드를 추가하는 것을 권한다(스키마 확장은 오케스트레이터 판단).
