# 유적 발굴단 — 설계 명세 (2026-10-03, 사용자 지시)

## 사용자 원문
> (Pressure Wash Panic 분석 후) 비슷하게, 하지만 컨셉은 다른 게임 만들어 줘.

## 레퍼런스에서 가져올 손맛 (메커닉만 — 이름·에셋·UI 복제 금지)
Pressure Wash Panic(`scratchpad/pw/` 캡처, 분석은 대화 기록): 위에서 비스듬히 내려다보는 3D 마당, 캐릭터를 걸어 다니며 도구로
**쓸면 그 자리 오염이 텍셀 단위로 지워지는 촉감**, 패널 단위 「spotless」(거의 다 닦으면 남은 얼룩이 한 번에 빠짐), 도구 2종
(넓게/세게), **건드리면 안 되는 소품이 말풍선으로 외치고 그 자리에 벌점 팝업**, 3번 실수하면 해고, 의뢰 게시판·별 3개·상점 업그레이드·
업적·일일 연속 출석, 튜토리얼 체크리스트, 두툼한 외곽선 캐주얼 UI.

## 컨셉
- 사막 유적 발굴 현장(로프로 구획된 발굴 사각형, 모래 언덕, 텐트·나무 상자·손수레·횃불·야자수). 주인공은 오리지널 발굴대원
  (탐험모·멜빵 가방·붓).
- **한 문제 = 한 발굴 구획.** 상단에 큰 문제판(접힘 없음, 협곡 사수 v3 규격: 390 본문 ≥20px·1280 ≥28px). 구획 안에 **모래에 묻힌
  석판 4개** — 석판 표면에 보기(4지선다)가 새겨져 있다.
- **붓(넓게·모래)** 으로 쓸면 모래가 지워져 새긴 글자가 드러난다. **끌(좁게·세게)** 은 굳은 흙·석회 덩어리(석판 위 일부에 붙어 있음)만
  깬다. 도구 선택 = 오염 종류 판단(레퍼런스의 FAN/JET 대응).
- **정답 확정 = 석판을 100% 깨끗이(「완전 발굴」)**: 글자를 읽을 만큼(약 40%)은 어느 석판이든 털어도 되지만, 완전히 털어 낸 첫 석판이
  답으로 확정된다(90% 넘으면 남은 모래가 한 번에 쓸려 나가는 스냅). 정답이면 석판이 들려 올라가며 빛·유물 보상, 오답이면 석판이
  쩍 갈라지고 벌점.
- **위험 소품**(레퍼런스의 차·고양이 대응): 구획 주변의 도자기 항아리·뼈·두루마리·도마뱀. 끌로 건드리면 깨지며 「내 항아리!」
  말풍선 + 그 자리 「−$10」 팝업, 3번이면 「발굴 허가 취소」. 붓은 소품에 무해(끌만 위험) → 도구 선택에 긴장.
- 시간: 구획마다 제한 시간(난도별 30~45초, 화면에 모래시계 + 「시간 초과 = 오답」 명시).

## 진행·메타 (재방문 장치)
- 한 원정 = 구획 10개(문제 10개) → 별 1~3개(첫 시도 정답 수·남은 시간) + 보수.
- **원정 게시판**: 유적지 3곳(사막 피라미드 / 정글 신전 / 얼음 동굴 — 팔레트·소품만 교체), 고객(박물관 관장 등) 의뢰문.
- **상점**: 붓 폭·끌 세기·이동 속도·모래시계(+5초). **박물관 진열장**: 정답 석판에서 나온 유물(도자기·황금 가면·화석 등 15종)을
  모으는 컬렉션 = 업적. **일일 연속 출석**(첫 메뉴 진입 시 보상 팝업).
- 튜토리얼 3레슨(걷기·붓질 / 끌·소품 주의 / 완전 발굴로 답하기) + HUD 체크리스트.

## 문제 팩
- 협곡 사수 팩 70종 6,743문항(스키마 v3, 4지선다)을 **이 게임 폴더로 복사**해 쓴다(`public/g/yujeok-balgul/packs/`, 게임 간 참조 금지).
  `packs/index.json` + `?pack=` + 타이틀 단원 선택(학교급·학년 탭, 협곡 사수와 같은 동작). 분수 `{frac:a/b}` 세로 분수, `<sup>`.
- 석판에 새길 보기는 길면(10자+) 글자 크기를 줄이거나 두 줄. 세로 분수도 석판에 렌더.

## 기술 (경량)
- **three.js**(`public/vendor/three.module.js`, import map — CLAUDE.md 규격), GLTFLoader 사용 가능. Unity·외부 CDN 금지.
- 모래 시뮬레이션: 석판·지면마다 **오염 격자(Uint8Array, 예: 64×64)** — 붓/끌 원형 브러시로 깎고, 변경된 부분만 `DataTexture`
  갱신(전체 업로드 금지). 셰이더에서 모래 텍스처와 석판 텍스처를 격자 값으로 섞는다. 성능 여유가 필요하면 격자 연산만
  작은 WASM(AssemblyScript/Rust 불가 시 JS typed array 로 충분 — 「WASM 식」은 선택).
- 모델: Blender 헤드리스 스크립트(`factory/games/yujeok-balgul/blender/*.py`)로 로우폴리 GLB(대원·석판·소품·지형), 필요 시
  Meshy(키 `~/.config/mosslight/meshy-api-key.txt`, **상한 100 크레딧**, 잔액 245)로 주인공 1체.
- 성능: 모바일 60fps 목표, 드로콜 ≤120, 게임 폴더 12MB 미만(팩 3.9MB 포함), 첫 화면까지 빠르게(DOM 타이틀 먼저).
- `window.__GAME_TEST__`(ready/start/getState/answerCorrect/answerWrong/sampleProblems) — answerCorrect 는 실제 붓질 경로로 정답
  석판 완전 발굴. QA `node factory/lib/qa.mjs yujeok-balgul` 치명 0.
