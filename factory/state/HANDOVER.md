### ① `docs/character-bible.md` §5.5 「무대 스타일 가이드」 신설 (전 게임 공통 문법)
§4 가 「캐릭터를 어떻게 그리는가」라면 §5.5 는 **「캐릭터가 서 있는 화면을 어떻게 그리는가」**다. 정본 이미지는 `v2-world`.
- **5.5.1 깊이 문법** — 지면(크림 양모) / 원경 / 어림안개(라일락) 3층. **원경은 그리지 말고 지운다**(안개는 미술이자 시선 정리 장치). 하늘은 비운다. 어둡게 하지 않는다(어두움 = 안개가 이긴 상태). 원근 격자·소실점 강요 금지 — 깊이는 안개와 크기로 낸다.
- **5.5.2 재질 배분** — **프레임·소품 = 진한 재질 / 플레이 면 = 거의 무지 / 조작물 = 밝은 링 하나**. 밝은 링은 화면에 하나뿐. 가독성은 재질보다 우선.
- **5.5.3 광원** — 좌상단 키 라이트 1개, 접지 그림자 타원 1개, **발광·네온·글로우 금지**(유일한 발광색은 무의 눈).
- **5.5.4 UI 부품 문법** — 주 버튼(오렌지 면 + 두께 그림자) / 부 버튼(크림 + 네이비 테두리) / 정보 배지(두께 그림자 없음) / 장부 카드(크림 + 시그니처 등지 띠) / 비활성. 같은 종류 행동은 같은 높이·라운드·두께.
- **5.5.5 오답 톤** — 라일락만. 마젠타·형광 레드는 이 세계에 없다.
- **5.5.6 게임별 변주 허용 범위** — 지형 정체·소품 물성·정답 사건·**팔레트 강조 1색**은 변수, 3층 문법·재질 배분·팔레트 토큰·광원·UI 문법은 상수. **블라인드 계열 판정 3축을 ①지형 정체 ②소품 물성 ③정답 사건으로 재정의**(배경 처리는 이제 공통 문법이라 판정 축이 아니다).
- **5.5.7** 무대 에셋 생성용 영어 프롬프트 스탠자 (`20-art.md` 가 그대로 붙인다).

  `run.sh` 의 `codex_reasoning_for()` 가 **모델 이름으로** 고른다(astra·sol→ultra, terra·luna→medium).
  호출부를 안 건드려도 빌드·심사·검수·검산이 ultra 로, 아트가 medium 으로 간다. 실호출 확인 완료.
- **fps 측정을 실 GPU 로 전환** (`qa.mjs`): 헤드리스 크롬을 플래그 없이 띄우면 macOS 에서
  ANGLE/Metal 실 GPU 를 잡는다(실측 벤치 58~61 vs swiftshader 44~46). GPU 면 그 수치가 **정본**이고,
  못 잡을 때만 swiftshader 로 폴백해 보정한다. `BENCH_IDLE` 55→60(GPU 기준선)으로 올려
  폴백 시 소프트웨어 손해(×1.33)가 제대로 보정된다. `report.render.mode` 로 어느 경로였는지 남긴다.
  `QA_FORCE_SWIFTSHADER=1` 로 강제 폴백 가능.
- **`perf.fpsdecay` 신설** (44번째 항목, fatal): 앞 구간 측정 → 15초 방치 → 뒤 구간.
  뒤/앞 < 60% 면 치명. 「앞 구간」은 이번 실행의 **최고 fps**(perf.fps 와 재측정 중 큰 쪽)를 쓴다 —
  안 그러면 시작 직후에만 빠른 게임이 "앞도 낮고 뒤도 낮으니 유지율 100%"로 빠져나간다.
- **인프라 버그 2건**: 깨진 puppeteer 스텁 `chrome/mac_arm-148.0.7778.97`(448KB)와 177MB zip 삭제,
  `resolveChrome()` 이 실행파일 존재로 고르도록 방어. `run.sh` 최상단에 **bash 강제 가드**
  (zsh 는 `for aid in $ASSET_IDS` 워드분리를 안 해 에셋이 조용히 누락된다) + 해당 루프에 방어 주석.
- **함정 추가**(OPERATIONS §13): **`codex exec` 는 stdin 이 열린 파이프면 argv 로 프롬프트를 줘도
  EOF 를 기다리며 0% CPU 로 영원히 블록된다.** Node `spawn` 기본값(`stdio:'pipe'`)이 그 함정 —
  `child.stdin.end()` 또는 `stdio:['ignore',...]` 필수. firstplay/judge.mjs 와 bash run.sh 는 이미 안전.
