# 참새 착지 아트 기록

- 최종 장면은 외부 모델·텍스처 없이 Unity 저폴리 프리미티브와 MGF 킷 재질로 구성한다.
- 팔레트: 젖은 적갈색 지붕 `#A94F45`, 산화 철 `#272B2C`, 서리 유리 `#D9ECE9`, 상아 `#F3E5CF`, 빗물 이끼 `#6E8578`.
- `public/g/chamsae-chakji/assets/title.png`, `thumb.png`, `square.png`는 아트 단계가 제공한 파일이며 런타임은 존재하지 않는 파일을 참조하지 않는다.
- 참새는 밤갈색 몸통·상아 가슴·삼각 날개·세 갈래 꼬리를 프리미티브로 만든 오리지널 생물이다.
