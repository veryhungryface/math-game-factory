# 조개 합창 아트 소스 기록

- 런타임 월드: Unity 프리미티브와 `MgfLook` 재질만 사용해 짙은 청록 공명 공간, 세로 절개 조가비 내벽, 한 점에서 퍼지는 방사 골, 겹친 진주 막, 석회 파편, 조개 생물 9마리를 절차적으로 구성했다.
- `public/g/jogae-hapchang/assets/hero.png`: 아트 단계가 만든 조개 생물 실루엣 참고 시트. 런타임 파일로 로드하지 않고 부채꼴 껍질·통통한 몸·작은 눈의 형태 참고에만 사용했다.
- `public/g/jogae-hapchang/assets/title.png`: 초기 아트 단계의 세로 키 아트로, 최종 런타임은 이 파일을 네트워크 요청하지 않는다.
- `public/g/jogae-hapchang/thumb.png`, `square.png`: `capture-runtime-covers.mjs`가 최종 Unity WebGL 타이틀에서 직접 캡처한 1200×630, 1080×1080 공유 이미지다. 따라서 카탈로그와 실제 게임은 같은 카메라·형상·재질을 사용한다.
- 원격 에셋·상표·기존 캐릭터·외부 폰트는 사용하지 않았다. 효과음은 킷의 런타임 합성음이다.

## 생성 프롬프트 요약

초기 생성 기준은 황색 석회암 틈의 조가비 골목이었다. 1차 수정에서 기존 중학교 Unity 작과 겹치던 따뜻한 단색 둥근 블록을 폐기하고, 짙은 청록 공명실·세로 절개 조가비·방사 골·진주층·가루 낀 파편으로 런타임 형상 언어를 재설계했다. 부채꼴 껍질과 통통한 테라코타 몸·작은 눈을 가진 오리지널 조개 생물은 유지했다.
