# 현악 네모 아트 소스

- 1차 수정 세계: 밝은 야외 햇빛 결정 협곡, 따뜻한 사암 층리, 꼰 섬유현 프레임, 청록·보랏빛 석영 군락.
- 변경 근거: 검수에서 `bitbyeon-cheolgil`과 어두운 실내 설비·흑회색 금속 블록·연쇄 점등 사건이 같은 계열로 판정되어, 배경 처리·부품 물성·정답 사건을 함께 분리했다.
- 생성 출처: 외부/생성 에셋 없음. Unity 킷 재질과 코드 프리미티브로 직접 구성했다.
- 정답 사건: 청록 바위벌레가 완성한 현을 타고 이동하고, 해당 프레임의 결정꽃이 실제로 펼쳐진다. 정답 흔들림은 쓰지 않는다.
- 캐릭터: 청록 등딱지와 여섯 짧은 다리, 구리 지휘봉을 든 오리지널 바위벌레 조율사.
- `public/g/hyeonak-nemo/assets/title.png`와 `beetle-sheet.png`는 아트 단계 생성 참고 이미지다.
- 실제 Unity 런타임은 외부 텍스처 없이 프리미티브와 공용 MGF 재질로 같은 세계를 재구성한다.
- 생성 참고 프롬프트와 크기는 `factory/work/art.json`에 기록되어 있다.
