# 현악 네모 아트 소스

- 3차 수정 세계: 하늘빛 유리창, 꿀빛 단풍나무 계단, 좌우 마림바 테라스와 아이보리 현악 공명판이 있는 낮의 기하 음악원.
- 변경 근거: `bitbyeon-cheolgil`의 어두운 설비실·발광 장치 잠금, `sil-taneun-geomi`의 야외 섬유·생물 이동·개화와 겹치지 않도록 배경, 재질, 보상 사건을 함께 바꿨다.
- 생성 출처: 외부/생성 에셋 없음. Unity 킷 재질과 코드 프리미티브로 직접 구성했다.
- 정답 사건: 황동 현을 따라 진동이 훑고, 천공 악보 타일과 원목 마림바 건반이 물리적으로 솟는다. 정답 흔들림은 쓰지 않는다.
- 캐릭터: 청록 등딱지와 여섯 짧은 다리, 황동 지휘봉을 든 오리지널 바위벌레 지휘자. 정답 때 제자리에서 지휘 자세로 반응한다.
- UI는 검은 둥근 HUD 대신 각진 아이보리 악보 카드와 황동 피아노 건반을 사용한다.
- 실제 Unity 런타임은 외부 텍스처 없이 프리미티브와 공용 MGF 재질로 재구성한다.
