# 새우 이사 아트 기록

- 정체성: 열린 울트라마린 나전 분류 골목의 산호 도자 새우 정리소
- 제공 에셋: `public/g/saeu-isa/assets/title.png`, `thumb.png`, `square.png`
- 런타임: 외부 모델·텍스처 없이 `MgfLook` 프리미티브와 코드 메시만 사용한다.
- 산호 도자 새우: 각진 갑각 5마디, 머리·부리·두 갈래 꼬리·집게·더듬이로 만든 코드 모델을 재사용한다.
- 주머니: 상아 직물 몸통, 독립된 접힘 옆면, 교차 씨실, 자개 막대 손잡이를 코드로 만든다.
- 배경: 평평한 전면 서랍벽을 쓰지 않고 양쪽 열린 선반이 사선으로 좁아지는 2.5D 분류 골목과 현수막·원근 바닥선을 사용한다.
- `thumb.png`와 `square.png`는 `capture-runtime-covers.mjs`가 최종 WebGL 타이틀을 직접 캡처한다. 생성 표지 이미지는 최종 산출물로 사용하지 않는다.
- 배경 일러스트·수조·물·기포·외부 네트워크 요청은 사용하지 않는다.
