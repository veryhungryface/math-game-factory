# 문어 사진사 아트 기록

- 런타임 세계는 Unity 기본 프리미티브와 `MgfLook` 재질로 직접 구성했다.
- 1차 수정에서 밝은 수중 장난감 계열을 폐기하고 압력선체 암실로 재설계했다. 팔레트는 hull navy `#0C1622`, smoked steel `#26384B`, aged brass `#B97732`, safelight red `#8E2F2C`, developer amber `#F0A62B`다.
- 각진 리벳 선체, 계기판, 황동 판형 카메라, 적색 안전등, 화학 현상 격자는 모두 C# 프리미티브로 생성된다. 정답 사건은 생물 이동이 아니라 현상 격자 점등으로 분리했다.
- 플레이 판정·숫자·사진 필름은 이미지에 굽지 않고 실제 학생 상태로 렌더링한다.
- 게임은 외부 네트워크, 외부 폰트, 외부 음원을 사용하지 않는다.
