# 날개 펴 — 아트 출처

- `Resources/NalgaePyeo/title.png`: 아트 단계의 `public/g/nalgae-pyeo/assets/title.png` 사본. 황금 비단 천막과 흑칠 관절 인형을 묘사한 생성 이미지.
- `Resources/NalgaePyeo/hero.png`: 아트 단계의 `public/g/nalgae-pyeo/assets/hero.png` 사본. 코드 프리미티브 인형 제작 참고 및 타이틀 보조 원화.
- 원본 생성 프롬프트와 크기·출처는 `factory/work/art.json` 및 `factory/work/chosen.json`의 `art_direction.assets_needed`에 기록되어 있다.
- 런타임은 원화가 없거나 로드되지 않아도 코드로 만든 금빛 주름극·흑칠 관절 인형을 그대로 표시한다.
