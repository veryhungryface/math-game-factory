# 별칸 관측소 아트 기록

- 최초 정체성/생성 기록: `factory/work-lanes/20261014-015549-L2/chosen.json`, `art.json`의 현무암 분화구·오팔 랙·사진풍 타이틀. 1차 검수에서 `bitbyeon-cheolgil`과 같은 어두운 기술 시설 계열이며 런타임 로우폴리와 불일치한다고 판정됐다.
- 1차 수정 정체성은 **햇빛 도자기 별마을의 접이 천막 공방**이었으나 `sil-taneun-geomi`와 같은 파스텔 중앙 디오라마·둥근 생물·세계 조각 펼침 계열이라는 2차 검수 판정을 받았다.
- 2차 수정 정체성: **계단식 테라코타 천문 마을의 황동 초점망**. 중앙 원반 없이 화면 양끝까지 이어지는 세 단 골목, 거친 모자이크, 각진 황동 랙과 일곱 관측탑, 심야 남색·테라코타·황동 팔레트만 쓴다.
- 사진풍 `title.png`는 런타임에서 제거한다. `thumb.png`·`square.png`는 수정한 실제 Unity WebGL 타이틀 프레임에서 다시 캡처한다.
- 정답 사건은 학생이 만든 접점 경로를 따라 일곱 관측탑이 차례로 회전·조준해 별빛을 한 초점에 합치는 장면이다. 정답에는 카메라 흔들림을 쓰지 않고 오답에만 남긴다.
- 외부 모델·텍스처·음원 및 새 생성 에셋 없음. 모든 월드 오브젝트와 절차적 UI 스프라이트는 `ByeolkanView.cs`가 만든다.
