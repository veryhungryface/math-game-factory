# 곱빼기 빵집 아트 기록

- 초안 `Resources/GopbaegiBbangjip/title.png`는 보라색 투명 발효탑 키아트였으나, 1차 검수에서 `prism-mobil`과 배경·물성·점등 사건이 겹치고 인게임과 재질 언어가 끊긴다는 판정을 받았다. 최종 런타임에서는 이 이미지를 로드하지 않는다.
- 1차 수정 아트 방향: 햇빛이 드는 파스텔 제빵 안뜰, 크림색 차양 간판, 무광 세이지 계량 카트, 테라코타 반죽, 버터색 정육면체 빵. 투명 관과 발광 셀 대신 실제 빵 블록이 층층이 조립된다.
- 타이틀과 플레이 월드는 모두 `GopbaegiView.cs`의 동일한 `MgfLook` 프리미티브·조명·캐릭터로 구성했다. 별효모는 무광 밀가루 생물로 바꾸고 정답에는 뛰며, 오답에는 내려앉는다. 정답 화면 흔들림은 없고 오답에만 흔들림이 있다.
- 3차 수정 검증: WebGL artifact `3cd0b3ad…acce4`에서 첫 판은 오답 회복 후 첫 시도 8/9, 독립 두 번째 판은 조기/지연 계량과 주문 교대를 섞어 첫 시도 9/9로 완주했다. 두 결과와 공식 QA·firstplay manifest가 같은 artifact hash를 기록한다.
