# 비누 썰어 아트 기록

- 기획 아트 단계 제공물: `public/g/binu-sseoreo/assets/title.png`, `forming-idle.png`, `forming-cross.png`, `thumb.png`, `square.png`.
- 런타임은 용량 중복을 피하려고 제공 PNG를 Unity Resources에 다시 넣지 않고, 같은 정체성을 포도빛 다공성 지층·상아 비누·검은 리브 홈·노란 작업등·원본 포밍 프리미티브 조합으로 재구성한다.
- 외부 모델·텍스처·음원·CDN을 사용하지 않는다. 사운드는 `MgfSfx` 합성음만 사용한다.
- `validation/math-selftest.mjs`는 실제 C# 문제 풀 624개와 14,976개 절단 후보를 전수 검사하고, `b3-bot-selftest.mjs`는 무뇌 정책 4종을 각 200판 측정한다.
- `validation/pointer-playthrough.mjs`는 정답 훅 없이 실제 Chrome pointer로 연습, 첫 오답 복구 완주, 무실수 완주, 여분 비누 0 게임오버를 재현한다.
