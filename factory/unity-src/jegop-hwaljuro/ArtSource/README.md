# Art source

The shipped WebGL scene is built from Unity low-poly primitives and the shared MGF shaders. The title, thumbnail, and square key art were generated by the factory art stage; only `public/g/jegop-hwaljuro/assets/title.png`, `thumb.png`, and `square.png` exist. The runtime deliberately does not request any remote media.

## 1차 수정 시각 기록

- 외부 생성 에셋을 추가하지 않았다. 계단식 정비 에이프런, 소금 단구, 이동 정비차, 정비 로봇 `토리`, 폐유리 장애물은 모두 코드 프리미티브와 MGF 공용 셰이더로 만들었다.
- 큰 유백색 둥근 카드 중심 UI를 격납고 스텐실·상태 레일·활주로 표식 형태의 직선형 계기판으로 바꿨다.
- 정답은 활주로 구간 도킹·로봇 반응·글라이더 이륙으로, 오답은 다음 문제에도 남아 실제 드래그 경로를 막는 폐유리로 구분했다. 정답 화면 흔들림은 사용하지 않는다.

## 2차 수정 시각 기록

- 외부 생성 에셋 없이 코드 프리미티브만 사용했다. 밝은 평면 사막을 수직 소금 결정 단면·황동 갠트리·어두운 레일 바닥이 있는 야간 정비 격납고로 바꿨다.
- 청유리·유백색 부품을 불투명 테라코타 각인 타일과 황동 클램프로 교체했다. 정답은 청색 광로 점등이 아니라 두 타일이 레일에서 한 활주로 조각으로 잠기고 글라이더 바퀴가 그 조각을 밟은 뒤 이륙하는 물리 사건이다.
- 정답 경로에는 화면 흔들림을 사용하지 않는다. 흔들림은 오답에서만 유지한다.
