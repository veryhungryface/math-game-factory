# 세모 소나기 아트 인수인계

- `public/g/semo-sonagi/assets/title.png`: 아트 단계가 만든 1024×1536 타이틀 키 아트. 최종 런타임에서는 제품 인상 불일치를 피하려고 표시하지 않고 기록 자산으로만 보존한다.
- `public/g/semo-sonagi/assets/snail-study.png`: 미니어처 달팽이 형태 참고용 원화이며 런타임에는 직접 넣지 않는다. 게임 속 달팽이는 구·캡슐 프리미티브로 새로 조합했다.
- `public/g/semo-sonagi/thumb.png`, `square.png`: 최종 WebGL의 1280×800 실시간 타이틀 캡처를 각각 1200×630과 1080×1080 구도로 잘라 만든다. 생성 이미지가 아니라 실제 게임과 동일한 카메라·재질의 런타임 캡처다.

게임 월드는 높이가 다른 무광 도자 구름섬, 수직 낙수층, 코발트 타일 수문, 거친 직조 삼각 우산과 도자 껍데기 달팽이를 Unity 프리미티브와 코드 메시로 만든 2.5D 디오라마다. 정답 정보는 색·실루엣·애니메이션에 미리 나타나지 않는다.
