# 협곡 사수 — 설계 명세 (2026-09-26, 사용자 직접 지시)

## 사용자 지시 (원문 요지)
> (킹샷 광고 스크린샷 2장 첨부 — `ref/ref-1.png`, `ref/ref-2.png`) **문제만 바꾸면 어느 단원에도 쓸 수 있게** 이런 게임을 만들어 줘.
> **유니티·블렌더·코덱스 다 써서** 작업해 줘. **최대한 비슷하게, 타격감 있게.** 우선 단원은 **중2**.

## 레퍼런스에서 가져올 것 (메커닉·화면 문법만 — 킹샷의 이름·캐릭터·에셋·UI 아트는 가져오지 않는다)
- 약 55° 내려다보는 세로 화면. 짙은 초록 고원(내 진영)과 그것을 감아 도는 **황토색 협곡 길**, 어두운 절벽 단면, 로우폴리 나무.
- 오른쪽 위 **적 관문 2곳**에서 **빨간 병사 떼**(수백 명)가 강물처럼 쏟아져 길을 따라 흘러온다.
- 내 **병영**(교차한 칼 문양 오두막)에서 **파란 병사**가 줄지어 나와 협곡 목에서 빨간 떼와 **정면충돌** — 불꽃·흰 연기·금빛 파편,
  밀려나며 쓰러지는 병사, 겹겹이 쌓이는 전선.
- 돌탑 위 **석궁 포탑**이 볼트를 연사하고, 맞은 자리에 섬광·파편.
- 초록 땅 위 **점선 테두리 건설 패드**(「250 🪙」 같은 비용 표시). **왕(주인공)** 이 걸어가서 서 있으면 건설된다.
- 타격감: 히트 플래시, 넉백, 파편·연기 파티클, 짧은 화면 흔들림, 큰 처치 때 0.05초 히트스톱, 처치 수·코인 튀어나옴, 합성 효과음.

## 수학 결합 — 「답을 고르는 행위 = 왕이 건설 패드로 걸어가는 것」
- 웨이브마다 상단 배너에 문제 1개(분수는 **세로 분수**로 조판 — 평문 `1/6` 금지).
- 고원 위 건설 패드 3~4개에 **보기**가 새겨진다(비용 표시 자리에 보기 값). 왕을 끌어(드래그) 패드 위에 세우면 테두리가
  0.8초 동안 차오른 뒤 확정된다(실수 방지 · 마음 바꿀 여지).
  - **정답**: 그 패드에 석궁 포탑이 솟거나(레벨업), 병영이 대량 출격하거나, 화살비가 쏟아진다 — 정답 = 전투에서 이기는 힘.
    빨리 맞힐수록 코인 보너스.
  - **오답**: 패드가 금 가며 부서지고 코인 손실, 빨간 떼가 잠깐 격앙(속도↑). 배너에 정답과 한 줄 풀이(`explain`)를 1.5초.
- 빨간 떼는 쉬지 않고 전진한다 → 시간 압박이 곧 긴장. 성문 HP 가 0이면 **패배**. 문제 10개(웨이브 10)를 버티면 승리이되,
  **첫 시도 정답률 70% 미만이면 승리 연출 없음**(「버티기만 한 판」과 「알고 이긴 판」을 가른다).
- 공장 하드 불변 4(하단 n지선다 금지)와의 관계: 문제 팩을 갈아 끼우는 범용 구조라 보기 선택은 남지만, **버튼이 아니라
  맵 위 패드로 몸을 옮기는 공간 조작**이고 선택 결과가 곧 전황(포탑·병력)이 된다. 사용자 지시에 따른 의도적 예외 —
  meta 의 `risks` 에 적는다.

## 문제 팩 = 파일 교체만으로 단원 교체 (핵심 요구)
- 팩은 **빌드 밖** `public/g/hyeopgok-sasu/packs/<pack_id>.json` 에 둔다. 게임은 부팅 때 `packs/index.json`(팩 목록)을 읽고,
  URL `?pack=<pack_id>` 또는 타이틀의 팩 선택으로 고른다(`UnityWebRequest`, 상대경로). **Unity 재빌드 없이** JSON 만 추가하면 새 단원이 된다.
- 스키마:
  ```json
  { "pack_id": "m2s2-u7", "title": "확률", "school": "middle", "grade": 2, "semester": 2,
    "unit_id": "m2s2-u7", "standards": ["[9수04-06]"],
    "items": [ { "id": "p001", "prompt": "…", "choices": ["…","…","…","…"], "answer": "…",
                 "answerNumeric": 0.1666, "format": "frac|int|text", "explain": "…",
                 "unitConcept": "…", "distractor_tags": ["…"] } ] }
  ```
  `prompt`·`choices` 안의 분수는 `{frac:1/6}` 같은 토큰으로 쓰고 게임이 세로 분수로 그린다. 팩당 **고유 문항 120개 이상**.
- 초기 팩 2종(중2 2학기): **`m2s2-u7` 확률(기본)**, **`m2s2-u6` 경우의 수**. 팩은 손으로 쓰지 말고
  `ArtSource/packs/gen-<pack>.mjs` 생성기(정수·유리수 정확 연산)로 만들고 `verify-packs.mjs` 로 전수 검증한다:
  정답 ∈ 보기, 보기 중복 없음, 정답 유일, 오답은 오개념 역산(`curriculum/2022-middle-math.json` 의 해당 단원 misconceptions),
  `expression_traps` 준수 — 두 개를 던지면 「서로 다른」, 뽑기엔 「임의로」+「(단, 공의 모양과 크기는 모두 같다.)」,
  비복원 추출 금지(복원만), 「또는」은 겹치지 않는 사건만. 확률은 기약분수. **√ 금지**.
- `packs/README.md`: 선생님이 새 단원 팩을 추가하는 방법(스키마·예시·검증 명령). 초등 단원도 같은 스키마로 가능하게.
- `IMgfGame.ProblemBankJson()` 은 **현재 로드된 팩**의 문항을 그대로 푸시한다(QA 표본 = 실제 출제 문항).

## 기술
- Unity 트랙 계약 그대로(`docs/unity-track.md`, `factory/prompts/30-build-unity.md`). 소스 `factory/unity-src/hyeopgok-sasu/`.
- **Blender**: 병사(파란/빨간 — 같은 메시, 인스턴스 색), 왕, 석궁 포탑(돌탑+석궁), 병영, 성문, 적 관문, 나무·바위, 절벽·협곡 지형을
  **bpy 스크립트**(`ArtSource/blender/*.py`, `Blender -b --python`)로 모델링해 FBX 로 `Resources/HyeopgokSasu/` 에 내보낸다.
  Blender MCP 가 연결돼 있으면 써도 되지만 재현 가능한 스크립트가 정본이다. 로우폴리·플랫 셰이딩·레퍼런스의 채도.
- 떼 렌더: **GPU 인스턴싱**(`Graphics.RenderMeshInstanced`/`DrawMeshInstanced`) + 경로 스플라인 흐름장 + 간단한 분리력.
  빨강 300~600, 파랑 50~150 을 모바일 60fps 로. 매 프레임 할당 금지, 파티클은 풀링. QA fps·15초 저하 게이트를 넘어야 한다.
- 이미지 생성(codex 내장)은 타이틀·표지(thumb 1200×630, square 1080×1080)에만 — 게임 화면 자체는 실시간 3D.
- 산출 gzip 12MB 미만(팩 JSON 포함).
