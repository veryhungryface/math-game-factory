# 문제 팩 전수 검증

판정: **pass**

- 문항 400개, 보기 0개, 오답 도출 1200개 전수 확인.
- 독립 표본공간 21871개를 직접 열거해 정답을 정수 교차곱으로 대조.
- 분수 입력 0쌍(분모 0 포함)의 exact_parts/reduced 정오 경계를 전수 대조.
- 모든 붓기 패드 max=60, 고정 예산 amount=60/fraction=120, 소지량120·웨이브 최소140 코인. 첫 문항은 두 팩 모두 amount=2.
- 오류 0건. 정답 누락·중복·동치 보기·오답 우연 정답·표현 함정·교육과정 범위·기약분수·보기 위치 균형을 확인.
- 생성기 공통 모듈을 가져오지 않는 독립 검증기. 예상 정답 필드는 검증 대상일 뿐 계산 입력으로 쓰지 않음.
