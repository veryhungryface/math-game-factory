# 협곡 사수 v3 — 재설계 (2026-09-27 19:30, 사용자 지시)

## 사용자 원문
> 문제 글자가 작아. 그리고 접히기가 되면 안 돼. 전체와 부분으로 답 받는 거 불편하다. 타 단원으로 확장에도 걸림돌이 될 듯해
> **4지선다로 가자.** **코인을 모으는 건 설치된 공격 타워를 업그레이드하는 데 쓰이고, 문제를 맞추는 건 코인을 더 늘리거나
> 확률적으로 새로운 공격 타워 받기.**

## 1. 문제판 — 크게, 항상 전부
- 상단 두루마리 배너는 **접힘·「더 읽기」 폐지**. 발문 전체가 항상 보인다(최장 ~190자 → 390 폭에서 최대 5~6줄).
- 글자: **390 세로에서 본문 20px 이상, 1280 에서 28px 이상**(현재보다 확실히 크게). 배너 높이는 발문 길이에 맞춰 늘어나고,
  카메라·패드 배치가 그 아래 남은 영역에 맞춰진다(배너가 패드·전선을 가리면 안 된다 — 측정 게이트 유지).
- 분수는 세로 분수, 수학 기호 폰트(MgfKR-Bold) 유지.

## 2. 답 입력 — 4지선다 (지상 패드)
- 문제가 뜨면 고원에 **보기 패드 4개**(보기 글자·세로 분수를 패드에 크게). **패드를 탭하면 왕이 그 패드로 달려가 도착 즉시 확정**
  (왕을 직접 끌어 패드에 세워도 된다). 확정 전 0.4초 링만 — 긴 대기 없음.
- 두 패드(전체/부분) 붓기·amount 붓기 **폐지**. 팩은 모두 `choice` 4지선다(스키마 v3, 아래).
- 오답: 패드 균열 + **정답 패드가 빛나며 정답·한 줄 풀이를 1.5초 자동 표시**(버튼 눌러야 보이는 방식 금지).

## 3. 경제 — 코인은 타워 업그레이드, 정답은 보상
- **코인은 전투로만 번다**: 처치 → 코인이 땅에 떨어짐 → 왕이 근처를 지나가면 흡수 → 등에 쌓임(킹샷 루프 그대로).
- **코인의 용도 = 설치된 공격 타워 업그레이드**: 각 타워 옆에 킹샷식 **업그레이드 패드**(점선 사각 + 비용 「30 🪙」). 왕이 서 있으면
  코인이 부어지며 비용 숫자가 줄고 0이 되면 레벨업(외형 단계 변화 + 연출). Lv1→2→3, 비용 증가.
- **정답 보상** — 정답 순간 보물상자 연출이 열리며 둘 중 하나:
  - **코인 보너스**(예: +20~40, 빨리 맞힐수록 큼), 또는
  - **확률적으로 새 공격 타워**(예: 30~35% — 석궁탑 / 대포탑 / 마법탑(범위) 중 하나)가 빈 타워 부지에 떨어져 세워진다.
    연속 정답이면 타워 확률 상승(예: 연속 3회째 보장) — 「한 문제 더」 동기.
- 오답: 보상 없음 + 적 떼 잠깐 격앙. 성문 HP 0이면 패배, 10문제 완주 + 첫 시도 7개 이상이면 승리(기존 유지).
- 판정 계약: 문항 정오와 보상 추첨은 **분리**(보상 난수는 정오 판정에 영향 없음). `__GAME_TEST__` 는 그대로(answerCorrect 는
  실제 패드 탭 경로).

## 4. 문제 팩 스키마 v3 (모든 단원 공통)
- 모든 문항 `answer_mode: "choice"`, `choices` 정확히 4개, `answer` ∈ choices, **값이 같은 보기 동시 금지**(분수는 기약화 비교),
  오답 3개는 **실제 오개념 역산**(`distractor_tags`), 정답 위치 균등. `explain` 한 줄. 분수는 `{frac:a/b}`.
- 확률 답은 **기약분수**로 보기 구성(교과서 관례). 「약분하지 말고/않아도 된다」 문구 제거.
- v1·v2 팩(amount/fraction_parts)이 들어와도 죽지 않게 — 로더가 `choice` 가 아니면 그 문항을 건너뛰고 경고(팩 전체가 choice 가
  아니면 팩 선택 화면에서 비활성). 신규 팩 작성은 choice 만.

## 5. 유지

성능 게이트(드로콜 ≤150·fps·15초·gzip<12MB·할당 0).
