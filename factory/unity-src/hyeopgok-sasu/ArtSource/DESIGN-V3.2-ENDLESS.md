# 협곡 사수 v3.2 — 끝없는 방어 + 맵 진행 (2026-09-27 23:00, 사용자 지시)

## 사용자 원문
> 게임이 죽을 때까지 해야지. 문제 개수 차면 지켰다고 끝내니까 시시하다. 아니면 다른 맵에서 플레이를 하게 해 주든가.

## 1. 종료 조건
- **성문 HP 0 = 유일한 게임 오버.** 「10문제 완주 = 승리」 폐지.
- 결과 화면: 버틴 문제 수, 도달 스테이지·맵, 격파 수, 첫 시도 정답률, 최고 기록(localStorage, try/catch), 「다시 도전」.
  (공장 무뇌 게이트: 무입력·무작위는 몇 스테이지 안에 성문이 무너져야 한다 — 봇으로 측정)

## 2. 스테이지와 맵 진행
- **1 스테이지 = 문제 10개.** 10번째 뒤 **보스 웨이브**(거인 부대·기수). 버티면 「지역 수복!」 연출 → 다음 맵으로 이동(카메라 이동/페이드 1.5초).
- 맵 3종(순환):
  1. **초원 협곡**(현재 맵).
  2. **사막 강 다리** — 모래 팔레트, 사암 절벽, 선인장·고사목, 강 위 나무다리 병목(킹샷 플레이어블 광고의 강·다리 레퍼런스).
  3. **설원 요새** — 눈 덮인 바위·침엽수 눈모자, 얼음 강, 차가운 조명.
  3 이후 1로 돌아가되 **난이도 계수 상승**(적 수·속도·거인 비율·보스 HP ×1.25/루프).
- 맵마다 길 모양을 다르게(U자 / S자 / 두 갈래 합류) — 같은 게임을 다른 공간에서 하는 느낌.
- **이월 규칙**: 맵을 넘어가면 타워는 새 맵의 부지에 다시 짓는다(코인·타워 초기화). 대신 스테이지 클리어 보상으로 **영구 강화 1개 선택**(3장 중 1: 「타워 공격력 +15%」「코인 흡수 반경 +30%」「성문 최대 HP +20」 등) — 판 안에서 누적. 「한 판 더」 동기.
- 성문 HP 는 스테이지 사이에 일부 회복(+30%).

## 3. 문제 난이도 곡선
- 스테이지가 오를수록 팩의 difficulty 1→4 비중 상승(스테이지1: 1~2 위주, 스테이지3+: 3~4 포함). 같은 판에서 문항 중복 최소화(팩 300+ 문항 셔플 소진 후 재셔플).
- 연속 정답 보정(타워 보장)은 유지.

## 4. 유지·게이트
4지선다 지상 패드, 코인 = 타워 업그레이드, 정답 = 보물상자(코인·확률 타워), 큰 문제판(접힘 없음), 측정 게이트 (a)~(g) + 새 맵 2종에서도 (a)(b)(c)(f)(g) pass, QA 치명 0, 드로콜 ≤150, fps·15초 유지, **gzip < 12MB**(새 맵은 기존 메시 재사용·팔레트 재틴트·Blender 스크립트 지형 변형으로 가볍게. 넘치면 텍스처 압축·중복 에셋 정리로 확보).
`__GAME_TEST__`: getState 에 stage·map·loop 추가, answerCorrect 는 실제 패드 탭 경로 유지, sampleProblems 는 팩 문항 그대로.

## 5. 타워 업그레이드 손맛 (사용자 추가 지시: 「지금도 타워 업그레이드되는 맛이 안 느껴짐」)
업그레이드는 이 게임에서 코인의 유일한 용도다 — **가장 기분 좋은 순간**이어야 한다(킹샷의 코인 → 패드 → 건물 솟음 루프).
- **붓는 순간**: 왕 등의 코인 탑에서 코인이 한 닢씩 포물선으로 패드에 날아가며(짤랑 음정이 한 닢마다 상승) 비용 숫자가 크게 카운트다운,
  패드 테두리가 금빛으로 차오른다.
- **완성 순간(0.8~1.2초 시퀀스)**: 짧은 히트스톱 → 흰 청사진 실루엣이 아래에서 위로 차오름 → 새 레벨 모델이 **튀어오르며 스케일
  오버슈트(1.0→1.25→1.0)** → 흙먼지 링 + 금빛 빛기둥 + 파편 → 카메라 살짝 펀치 줌 → 팡파르 → 「석궁탑 Lv2!」 배너와
  **스탯 변화 팝업「공격력 12 → 20 · 연사 ×2」**.
- **레벨별 외형이 한눈에 다르다**(작은 장식 차이 금지): Lv1 목조 망루 → Lv2 석재 탑 + 파란 천 → Lv3 성가퀴 요새 + 금테·깃발·
  발광 룬. 크기도 레벨마다 +20%.
- **레벨이 전투에서 보인다**: 석궁 Lv2 쌍발·Lv3 부채꼴 3연발(흰 궤적), 대포 Lv2 폭발 반경↑·Lv3 연쇄 폭발, 마법 Lv2 연쇄 번개 2타·
  Lv3 4타. 맞은 적 수만큼 피해 숫자가 크게 뜬다. 업그레이드 직후 3초간 사거리 링이 빛난다.
- 다음 레벨 비용 패드가 곧바로 다시 나타나 「더 모아서 또 올리고 싶다」를 만든다(Lv3 이후 「MAX」 왕관 표식).
