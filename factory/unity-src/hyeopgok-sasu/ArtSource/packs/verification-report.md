판정: **pass**

- 독립 표본공간 28836개를 직접 열거해 정답을 정수 교차곱으로 대조.
- 분수 입력 1514447쌍(분모 0 포함)의 exact_parts/equivalent/reduced 정오 경계를 전수 대조.

- 생성기 공통 모듈을 가져오지 않는 독립 검증기. 예상 정답 필드는 검증 대상일 뿐 계산 입력으로 쓰지 않음.
