## 독립 검산 `check-m2s2-geo.mjs`

생성기 모듈을 import 하지 않는다. 정답은 **학생이 보는 발문 텍스트에서 수치를 다시 파싱**해 다른 경로로 재계산하고, proofs 원장은 문항 종류 식별에만 쓴다.

- 각도: 연립 조건(내각의 합·이등변 밑각·외심 이등변삼각형 세 개 분해·평행사변형 대각/이웃각)을 만족하는 정수 해를 전수 탐색해 **유일해**인지 확인.
- 사각형 선택형: 좌표 0~6 격자의 볼록 사각형 **523,072개**를 전부 만들어 조건문(∥, ⊥, 길이, 각 상등·보각, 대각선 교점 O)을 문자열에서 해석·판정. 「평행사변형이 되는 조건」「정사각형이 되는 조건」「포함 관계」「대각선 성질」 주장 452건을 반례 탐색으로 결정.
- 닮음·평행선·무게중심: 유리수 정확 좌표로 실제 삼각형·사다리꼴을 놓고 비·길이·넓이(신발끈 공식, 반평면 절단 넓이)를 측정. SAS 겹친 삼각형은 닮음 대신 **스튜어트 정리**로 CD를 교차 계산. 직각삼각형 닮음은 좌표 직교 조건·피타고라스 경로로 재계산.
- 피타고라스: a²+b²=c² 정수 탐색, 판별 보기는 정렬 후 최장변 기준 + 삼각형 성립 확인.
- 분수: 패드 전 영역 0~60 × 0~60(분모 0 포함) **1,849,337쌍**의 정오 판정을 오라클과 대조.
- u7: 발문에서 공·카드·주사위·동전 표본공간을 직접 열거(26,181 결과), accept 정책을 독립 재판정(아래).
- **변이 자가검사 `--selftest`**: 정답 +1(1,990/1,990 검출), choice 정답 교체(264/264), accept 모드 교체(496/496), 발문 첫 수치 +1(1,935/1,938 검출). 미검출 3건은 바꾼 수가 정답에 영향이 없는 정상 사례(MQ={frac:1/2}BC 는 AD와 무관 2건, 주사위 곱 2→3 모두 경우 2가지 1건)로 수동 확인.

## m2s2-u7 변경 요약 (review-v2-2 high 대응)

- **accept 정책**: exact_parts 는 발문이 「모든 경우의 수와 그중 사건이 일어나는 경우의 수를 세어 약분하지 말고 나타내시오」로 세는 방법을 지시하고 **자연스러운 동등가능 표본공간이 유일할 때만** 쓴다. 대안 공간 판정 = 사건/여사건 크기 같음, 색 개수 같음, 카드 나머지류(k | 장수), 주사위 한 개씩의 홀짝·3으로 나눈 나머지 분할. 검산기는 이보다 넓게(모든 법 m, 주사위 큰/작은 눈 분할 추가) 독립 탐색해 exact_parts 문항에 대안 공간이 하나도 없음을 확인.
- **exact_parts → equivalent 87문항**: 복원 추출 38(두 번 모두 19·적어도 한 번 19 — p×q 풀이를 교과서 방식으로 인정), 카드 배수 23, 색 3종 9, 공 2색(빨강=파랑) 8, 카드 「또는」 6, 주사위 3(두 눈의 곱이 2의 배수·3의 배수·9의 배수 — 홀짝이나 3으로 나눈 나머지로 나눈 동등가능 공간이 존재). 발문은 「확률을 분수로 구하시오. 약분하지 않아도 된다.」, 라벨 「분자」「분모」, 정답값 보존(1/4·9/36 모두 정답).
- 결과 분포: exact_parts 351→**264**, equivalent 0→**87**, reduced 56(그대로). 정답값 변경 0건, 문항 수·순서·id·오답 도출 원장 동일.
- **발문 주머니 전수 보강**: 공이 나오는 모든 문항(공 1색·여사건·3색·복원 추출·개수 역산)을 「…가 들어 있는 주머니에서 공 한 개를 임의로 꺼낼 때」로 통일. 복원 추출은 「꺼내 확인한 후 다시 넣고 또 한 개를 꺼낼 때」.
- **explain 을 붓는 양과 같은 셈으로**: exact_parts/equivalent 설명은 「모든 경우 36가지 중 9가지이므로 {frac:9/36}={frac:1/4}」처럼 센 양을 먼저, 복원 추출은 「6×6=36가지 중 3×3=9가지 … 이는 {frac:3/6}×{frac:3/6}의 값과 같습니다」로 두 풀이를 모두 인정.
- 생성기는 common.mjs 의 `writePack`(index.json 을 덮어씀)을 더 이상 쓰지 않고 파일 내 `writeU7Pack` 으로 u7 팩·proofs 만 쓴다. common.mjs 는 수정하지 않았다.
