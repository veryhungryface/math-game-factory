# 협곡 사수 — 2단계: 코인 경제 = 수학 입력 (2026-09-27, 사용자 지시 「1→2」)

## 목표
킹샷의 정체성인 **「처치 → 코인이 땅에 떨어짐 → 왕이 모아 등에 쌓음 → 패드에 부어 숫자가 줄면 건물이 선다」** 루프를
**그대로 수학 입력 장치**로 만든다. 보기 4개 패드를 고르는 방식(지상 4지선다 — 검수 medium 「수학이 동사가 아님」)을
기본에서 내리고, **「얼마를 붓는가」가 답**이 되게 한다. 동시에 「문제 팩만 바꾸면 어느 단원이든」 범용성은 유지한다.

## 핵심 규칙: 붓는 양 = 답
- 코인은 전투(처치·석궁 명중)로만 번다. 땅에 떨어진 코인은 왕이 가까이 가면 빨려 와 **등에 쌓인다**(최대치 있음).
- 문제 배너가 뜨면 고원에 **답 패드**가 선다. 왕이 패드 위에 서 있는 동안 코인이 한 닢씩 부어지고(길게 서 있을수록 빨라짐,
  탭하면 한 닢), 패드 숫자판이 **부은 양**을 보여 준다. 패드에서 **걸어 나오면 그 양으로 확정**.
- 정답 → 부은 코인이 그대로 **건물 투자**가 된다(석궁탑·병영 레벨업, 투자량이 클수록 큰 보상). 오답 → 부은 코인은 **잃는다**
  (패드 균열·돌 부스러기), 정답과 한 줄 풀이 표시. 모자라서 못 부으면 → 싸워서 더 벌어 와야 한다(= 전투와 수학의 순환).
- 넘치게 부었다가 되돌릴 수 없다(쏟은 물) → 「대충 붓고 보자」가 비싸다. 확정 전 0.6초 「이 양으로?」 링이 차오르는 동안
  다시 올라서면 취소하고 더 부을 수는 있다(덜어 내기는 불가).

## 범용 팩 스키마 v2 (v1 과 호환)
각 문항에 `answer_mode` 를 추가한다. 없으면 v1 처럼 `choice`.
- **`amount`** — 답이 자연수(0 포함)인 문항. `answer: 12`, `max: 40`(패드 숫자판 상한). 경우의 수·수의 연산·도형 개수 등
  **거의 모든 단원의 정수 답 문항**이 여기에 들어간다.
- **`fraction_parts`** — 답이 분수인 문항(확률 등). 패드 **두 개**: 「모든 경우의 수」 패드와 「사건이 일어나는 경우의 수」
  패드(라벨은 팩이 정함 — 분수 단원이면 「분모」「분자」). 두 양을 각각 붓고, 확정되면 두 패드 사이에 **세로 분수**가 조립된다.
  `answer: {num: 6, den: 36}`, `accept: "exact_parts"`(교과서 방법대로 센 수 그대로) 또는 `"equivalent"`(값만 같으면 정답,
  기약분수 요구 문항은 `"reduced"`). 확률 팩은 기본 `exact_parts` — 「모든 경우의 수를 세고, 사건의 경우의 수를 센다」가 곧
  교과서 확률 정의라 **세는 행위 자체가 수학**이 된다.
- **`choice`** — 수로 답할 수 없는 개념 문항(용어·성질). v1 패드 선택 그대로. 팩 전체의 30% 이하 권장.
- `amount`·`fraction_parts` 문항은 비용이 곧 답이라 **답이 큰 문항은 비싸다** → 팩 생성기는 `max` 를 적절히(보통 ≤ 60) 두고,
  웨이브 설계가 「그 문항을 풀 만큼 코인을 벌 수 있는가」를 보장한다(첫 문항은 작은 수).

## 기존 팩 이관
- `m2s2-u6` 경우의 수 → 대부분 `amount`. `m2s2-u7` 확률 → 대부분 `fraction_parts`(exact_parts) + 확률의 성질(0≤p≤1, 여사건)
  일부는 `fraction_parts`(reduced) 또는 `choice`. 생성기·검증기(`ArtSource/packs/`) 갱신, 800문항 전수 재검증.
- `packs/README.md` 에 `answer_mode` 3종과 예시를 추가(선생님이 다른 단원 팩을 만들 때의 가이드).

## 게이트
- 무뇌 봇: 무작위 양 붓기(균등 0~max), 항상 전부 붓기, 항상 1닢, 무입력, 「패드에 오래 서 있기」 — 첫 시도 정답률이 우연 수준
  (1/(max+1), 두 패드면 곱) 이하.
- `__GAME_TEST__`: `answerCorrect()` 는 실제 붓기 경로로 정답량을 붓고 걸어 나오기, `sampleProblems` 는 팩 문항 그대로
  (`answer`/`answerNumeric` 은 v1 호환 필드도 채움 — `fraction_parts` 면 기약분수 문자열).
- 첫 10초: 첫 문항은 `amount` 소수(예: 「동전 한 개를 던질 때 모든 경우의 수」 → 2닢). 첫 처치 코인이 등에 쌓이는 장면 → 유령
  손가락이 패드로 안내 → 2닢 붓고 걸어 나오면 석궁탑이 솟는다.
