# 협곡 사수 — 킹샷급 아트 바이블 (2026-09-27, 사용자: 「킹샷급 디자인 기대한다」)

근거: `references/case-studies/kingshot-analysis.md` §2(수치), 킹샷 프레임 `scratchpad/kingshot-ref/`(참고만 — 복제 금지).
이 문서의 수치는 **목표값**이다. 「비슷하게」가 아니라 이 값에 맞춘다. 판정은 아래 루브릭으로 독립 판정관이 한다.

## A. 카메라 · 구도
- 원근 투영, 세로 FOV **32°**, 피치 **55°**(정수리 금지), 왕을 느슨하게 추적(데드존), 문제 전환·건설 완료 때 0.6초 줌아웃.
- 세로 390×844 기준 병사 높이 = 화면 높이의 **1.3~1.6%**(떼가 질감으로 읽힘). 왕은 병사의 **2.2배**, 화면 하단 1/3~중앙.
- 화면 가장자리에 맵 끝이 **절대 보이지 않는다** — 바깥 링: 암석 덩어리 + 숲 + 옅은 청록 안개(거리 페이드).
- 1280 가로: 같은 세계를 더 넓게(추가 암석·숲·적 요새 일부), UI 는 가장자리에 붙인다.

## B. 조명 · 음영 (킹샷 덩어리감의 핵심)
- 태양 1개: 고도 50°, 방위 좌상단, 색 `#FFF3DE`, 소프트 섀도(PCF), 그림자 색은 검정 대신 **청록 그늘** — 앰비언트를
  하늘 `#BFE6E0` / 지면 `#3E7F66` 그라디언트로.
- **Blender 에서 AO 를 정점색으로 굽는다**(지형·절벽·건물·소품·나무): 건물 기단·절벽 발치·나무 밑·목책 아래가 부드럽게 어두워야 한다.
  런타임 SSAO 금지(성능). 구운 AO × 기본색으로 셰이더에서 곱한다.
- 절벽: 윗면 따뜻한 복숭아 `#E9C9B0`(사암 계열) 또는 풀 모서리, 옆면 차가운 남청 `#263945`~회청 `#838894` — **면마다 온도 차**.
- 접지 그림자: 모든 건물·나무·왕·거인 밑에 부드러운 원형 블롭(알파 0.35).
- 후처리: 약한 비네트만(가능하면), 블룸 금지(성능) — 섬광은 가산 쿼드로.

## C. 팔레트 (hex 고정)
풀 밝은 `#2DAA74` / 그늘 `#208F61`·`#0D7461` · 흙길 `#C8B59C`(가장자리 흐림, 중심선 약간 밝게) · 협곡 단면 `#17252C`·`#263945`
· 적 병사 `#D0060C` 본체 / `#8C1A20` 그늘 / `#F83247` 하이라이트 · 아군 `#0C73D5` / `#0658C7` · 적 영역 `#B64B54`~`#E8847A`
· 코인 `#F2B705` / `#DD9A1E` · 패드 짙은 초록 반투명 `#0E5E44`(α0.7) + **굵은 흰 점선 둥근 사각** · 전나무 `#2E6D2A`~`#1F5A4A`.

## D. 지형 · 소품 밀도
- 바깥 링과 고원 가장자리: **둥근 각진 암석 덩어리**(크기 3단계, 면 분할이 보이는 로우폴리, 박스 금지), 전나무·활엽수 군집(3~9그루 무리).
- 풀밭: 저주파 명도 얼룩(±5%), 풀 다발·흰/노란 들꽃·자갈(인스턴싱). 흙길은 가장자리 페이드 + 두 줄 바퀴 결.
- 건물: 지붕 널판·기와가 한 장씩 읽히는 조형, 석재 벽돌 틈, 진영색 천(파랑/빨강) 휘장·깃발, 기단 흙 원판.
- 소품: 목책(윗단 진영색 칠), 나무통·상자·자루, 횃불, 우물, 통나무 더미 — 고원 위 빈 풀밭이 넓게 남지 않게.

## E. 캐릭터 · VFX
- 병사 2~2.5등신, 투구가 몸의 절반(빨강 둥근 투구 / 파랑 각진 투구+방패). 행군 바운스, 공격 기울기, 사망 흰 플래시→소멸.
- 타격 흰~하늘 4갈래 별 + 광선, 볼트 흰 궤적(0.1초), 흰~연분홍 연기 뭉치 + 금빛 파편, 코인은 **바닥에 누워 쌓인다**.
- HP 바(피격 개체·건물·목책만), 「-5」 흰 숫자 팝업, 건설 흰 청사진 + 초록 원형 오라.

## F. UI — 「화면 공간 UI 는 최소, 월드 UI 가 주력」
- 서체: 둥글고 굵은 산세리프 + **짙은 외곽선**(TMP outline 0.2~0.3), 문서체 금지.
- 오른쪽 위 **알약형 코인 카운터**(진회색 반투명 + 흰 굵은 숫자 + 코인 아이콘). 성문 HP·진행(3/10)·정답 수도 알약.
- **문제는 상단 게임 배너 하나**(둥근 리본/현판, 최대 3줄, 390 폭에서 본문 17px 이상, 1280 에서 22px 이상). 안내 막대·설명
  상자 금지 — 조작 안내는 **월드 공간**(패드 위 화살표·유령 손·「멈춰 서서 붓기」 말풍선)으로.
- 패드 라벨은 패드 **위 떠 있는 알약**(겹침 금지), 숫자판은 패드 위 큰 외곽선 숫자.

## G. 성능 · 규격 (게이트 — 어기면 실격)
드로콜 ≤ 150, 인스턴싱·고정 풀, 매 프레임 할당 0, 모바일·1280 fps 게이트와 15초 유지 게이트, 게임 폴더 gzip < 12MB
(구운 AO 는 정점색이라 텍스처 추가 거의 0).
