## 팩과 입력

- `amount`: 부은 코인 수를 답으로 사용한다. `fraction_parts`: 분모/모든 경우와 분자/사건 경우를 각각 붓고 세로 분수로 확정한다. 라벨은 팩에서 받는다.
- `exact_parts`, `equivalent`, `reduced`는 두 정수·정수 교차곱·최대공약수로 판정한다. `answerNumeric`은 QA 호환용이다.
- `choice`와 `answer_mode` 없는 v1 팩만 기존 4패드 선택을 유지한다. 메타데이터의 예외 범위를 이 문항들로 좁혔다.
- 최종 팩 **844문항**: 경우의 수 `amount` 400, 확률 `amount` 21 / `fraction_parts` 407(`exact_parts` 351, `reduced` 56) / `choice` 16(확률 팩의 3.60%). 팩 모두 max 60이며 최대 정답 투자량은 경우의 수 56 / 확률 94다.
- `packs/verification-report.json`: 표본 사건 28,836개, 오개념 도출 2,532개, 분수 정수 입력 쌍 1,514,447개 전수 검산 **오류 0**. `packs/schema-report.json`의 v1·0 입력·동치·거부 fixture **13/13 통과**.
- 게임 로더와 정적 검증기는 같은 고정 경제 프로필(소지 120·처치당 1·최소 공급 기준 140), 패드 상한 1~60, 입력 모드별 예산 60/120을 확인한다. 경제 필드는 임의의 스폰 지시가 아니며 지원하지 않는 값은 거절한다. 명시 예산 0과 생략을 구별하며, 분수 답·경제 숫자는 정수로만 읽는다. v1의 경제 설정 생략은 허용한다.
- 런타임 팩 회귀 **8/8 통과**. Unity가 누락된 `economy`를 0값 객체로 만드는 동작 때문에 발생한 v1 거부를 발견해 실제 JSON 속성 유무로 정규화했다. 경제 없는 v1 허용과 경제 없는 v2 거부를 함께 검사한다.
- 공유 킷의 정규화가 추가 필드를 제거하므로 게임 전용 `Plugins/WebGL/HyeopgokBank.jslib`가 실제 팩의 모드·라벨·두 정수 답을 기존 표본 필드와 합친다. 표본 개수와 추출은 기존 킷에 맡기고, 팩 교체 때 자료를 갱신한다. `answer` 문자열·`answerNumeric`·`choices` 호환 필드도 유지한다.

## 봇과 증거

`Editor/HyeopgokBotSelfTest.cs`는 프로덕션 `HyeopgokRules.Start → Move → Tick`을 사용한다. 무작위 양·전부·1닢·무입력·오래 서기 각 200판과 정답/첫 오답 회복 대조군을 고정 시드로 실행한다. 첫 작은 amount 문항과 이후 문항의 원시 결과를 분리하되 전체 집계도 보존한다.

재화는 정답과 무관한 최대 보유량의 전투 수입 fixture다. 이 모델 검증은 실제 처치·드롭·흡수·브라우저 포인터·전투 피해 검증을 대신하지 않는다. 각 문항의 정수 입력 영역과 별도로, 모드·max별 모든 입력(기본 amount 61개 / fraction 3,721개)이 실제 이동·붓기·이탈 경로에서 정확한 양으로 확정되는지 검사한다. 유한 무작위 원시표가 기대값을 넘으면 그대로 남기며 전수 기대값으로 덮지 않는다.

실행 결과(`validation/phase2/bot-results.json`): 전체 원시 우연 게이트와 균등 입력 전수 게이트 모두 통과, 모델 오류 0.

- 확률 팩: 무작위 양 **13/1,213 = 1.072%**(기준 1.141%), 전부·1닢 각각 **10/1,210 = 0.826%**(기준 1.141%), 오래 서기 **10/41 = 24.390%**(실제 확정은 choice만, 기준 25%), 무입력 0.
- 경우의 수 팩: 무작위 양 **19/1,219 = 1.559%**(기준 1.639%), 전부·1닢·무입력·오래 서기 0.
- 두 팩의 정답 대조군과 첫 오답 회복은 각각 **200/200 승리**. 844문항 정답 동선·타임아웃 경계, v1 기본 choice, 3가지 분수 수용 방식 통과.
- **61개 amount + 3,721개 fraction 실제 이동/붓기/이탈 입력**의 운반 불일치 0. 이 입력 경로와 문항별 정수 판정을 연결한 **1,540,192개 전체 입력 영역** 불일치 0. 첫 문항만·이후 문항만의 원시 집계도 보고서에 보존했다. **첫 튜토리얼만의 무작위 양은 두 팩 모두 4/200=2.00%로 1/61=1.639%보다 높다**. 전체·본문 원시 게이트는 통과하지만 이 구간의 유한 표본 초과도 숨기지 않는다.
