# 협곡 사수 — 오리지널 3D 모델 기록

## 2026-09-27 킹샷 격차 1단계

Blender 5.2.1 LTS의 `bpy`로 직접 만든 장난감 중세 모델이다. 레퍼런스는 화면 문법·색 관계·구조물 종류만 참고했고 이미지·캐릭터·메시를 추출하지 않았다. 텍스처·외부 에셋·유료 모델 없음. 왕은 흰 측량 투구와 단일 황동 핀, 병영·관문은 마름모 나침표 표식으로 독자 실루엣을 갖는다.

### 재생성

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python factory/unity-src/hyeopgok-sasu/ArtSource/blender/build_models.py
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python factory/unity-src/hyeopgok-sasu/ArtSource/blender/render_phase1_models.py
```

`build_models.py`가 `phase1_models.py`를 읽어 35개 FBX, `model-manifest.json`, `hyeopgok-assets.blend`, 월드 프리뷰를 재생성한다. `-- --no-render`를 붙이면 프리뷰 렌더만 생략한다. `render_phase1_models.py`의 `-- --existing`은 FBX를 다시 쓰지 않고 저장된 blend로 `phase1-models.png`만 만든다. 이 렌더는 모델 검토 자료이며 실제 게임 전투 캡처를 대신하지 않는다.

### 임포트·렌더 계약

- `Resources.Load<GameObject>("HyeopgokSasu/Models/<id>")`; 기존 ID를 유지한다.
- 단일 메시·단일 서브메시·단일 정점색 재질·플랫 노멀. UV·텍스처·본·스킨·애니메이션 없음.
- +Y 위, +Z 정면, 1m 단위, 발 원점 y=0. FBX -Z forward / Y up, bake axis 변환. 게임 전용 임포터가 기존 Z 반사·와인딩 계약을 처리한다.
- COLOR는 sRGB. alpha=0은 팀 색×RGB, alpha=1은 고유색이며 투명도가 아니다. 기존 병사와 신규 궁수는 팀 마스크, 거인·보스·건물은 고유색이다.
- `tower_base_l1/l2/l3`는 모두 `crossbow`를 localY 1.62에 얹는다. 기존 `tower_base`/`barracks`/`castle_gate`는 2단계 alias다. `tower`는 2단계 탑과 석궁을 합친 메시다.
- 모든 건물 정면은 +Z. `enemy_watchtower` 상판 y=1.72. 거인 HP 위치 권장 y=2.14, 보스 y=2.95.

### 반영한 시각 요소

1. 풀 #2daa74·그늘 #1a8a62, 길 #c8b59c, 코발트 #0c6fd3, 적 명암 #d0060c/#8c1a20 기반으로 정점 팔레트를 바꿨다. 청록 소나무·하늘 쪽 파랑·회갈 길로 형광 황록 인상을 낮췄다.
2. 지형은 9개의 먼 사암 절벽(따뜻한 캡/차가운 측면)을 추가해 맵 경계를 가린다. 게임 카메라와 숲 링은 World가 제어한다.
4. 석궁탑은 목제 네 다리+가새·사다리 → 석재+코발트 천 → 팔각 성가퀴+금속 마감. 병영은 짚/널판/코발트 슬레이트와 굴뚝·현관으로, 성문은 목책/석문/쌍지붕 성곽으로 3단계 성장한다. 청사진은 런타임 머티리얼로 처리한다.
5. 아처는 후드·활·당긴 시위·화살통, 거인은 3배 체격과 밝은 칼, 보스는 뿔 투구·커다란 철퇴로 구분된다. 블룸 없이도 읽히는 밝은 칼 중심선을 정점색으로 넣었다.
6. 길 중심/갓길을 5개의 좁은 색 구간으로 전환하고 작은 칩을 남겼다. 알파 데칼 수준의 실제 블러는 아니며 원래 협곡 높이 차는 유지한다.
7. 적 관문은 붉은 슬레이트 지붕과 열린 아치, 적 망루는 목재 가새와 붉은 마름모 휘장을 쓴다.
8·10. 목책 정상/손상 메시, 나무통·상자·그루터기·우물·경종을 제공한다. 손상 HP·불꽃은 런타임이 담당한다.
11. U자 길의 x(-1.35,1.35), z<-6.3 구간과 외곽 턱을 열었다. 논리 이동 높이 .25·경로 control points는 유지하며 World가 나무다리/하천을 놓는다.

### Blender MCP 확인과 수정

localhost:9876의 열린 기존 협곡 씬을 `get_scene_info`로 먼저 확인했다. 소스 실행 후 `get_viewport_screenshot`으로 3단계 건물·유닛·소품을 직접 보았다. 첫 뷰포트에서 오래된 교차 칼 관문이 보이는 원인을 추적해, 숨겨진 원본 오브젝트가 `select_all/delete`에서 빠지던 재실행 버그를 고쳤다. 전체 데이터 오브젝트를 명시적으로 제거하고 사용하지 않는 메시·재질을 정리한다. 두 번째 MCP 캡처에서 열린 붉은 지붕 관문과 마름모 문장이 확인됐다. 헤드리스 `Blender -b` 재생성 종료 코드 0, 별도 모델 시트 렌더 직접 확인.
