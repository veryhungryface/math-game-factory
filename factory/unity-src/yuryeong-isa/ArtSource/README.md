# 유령 이사 아트 출처

- 게임 월드, 집유령, 건물, 창문, 커튼, 굴뚝, 골목은 Unity 프리미티브와 `MgfLook` 재질로 런타임 생성한다.
- 팔레트: 테라코타 `#D66045`, 살구 `#FFCB9B`, 상아 `#FFF7DD`, 흑연 `#26323F`, 벽돌 `#8D392C`.
- `public/g/yuryeong-isa/thumb.png`, `square.png`, `assets/title.png`는 공장 아트 단계의 생성물이다. 게임 빌드는 외부 네트워크나 해당 이미지의 원격 주소를 참조하지 않는다.
- 최종 표지는 제공된 필수 이미지를 보존한다. 실제 런타임은 같은 연립주택 단면을 프리미티브로 재구성한다.
