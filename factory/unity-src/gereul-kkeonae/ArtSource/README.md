# 게를 꺼내 — 아트 출처

- `public/g/gereul-kkeonae/assets/title.png`: 초기 아트 단계의 2.5D 코발트 산호 안. 1차 검수에서 `ssak-geonjyeo`와 수중 암반·게 군집 물성이 같은 계열임이 확인돼 런타임에서 사용하지 않는 폐안 참고물로만 보존한다.
- `public/g/gereul-kkeonae/assets/cord-fiber.png`: 아트 단계 생성 상아색 꼬임줄 텍스처. `Resources/GereulKkeonae/cord-fiber.png`로 복사해 도자 줄통과 줄 재질에 사용하며, 로드 실패 시 상아색 `MgfLook.Lit` 재질로 폴백한다.
- `thumb.png`와 `square.png`: `validation/capture-runtime-covers.mjs`가 최종 Unity 타이틀 세계를 각각 1200×630, 1080×1080으로 직접 캡처한 표지다. 하단 조작 UI가 잘린 채 보이지 않도록 더 높은 안전 렌더에서 로고·세계 영역만 규격대로 잘랐다.
- 1차 수정 시각 재설계: 수중 배경을 완전히 제거하고, 노을빛 건식 조간대의 목재 갑판·철제 크레인·금속 도르래·긴 섬유 다발·절단 장력 다리를 Unity 프리미티브로 구성했다. 둥근 게 군집 대신 각진 작업게 한 마리만 남기고, 정답 사건은 도르래가 당겨져 처진 다리가 칸별로 펼쳐지는 물리 사건으로 바꿨다.
- 2차 수정 시각 재설계: `kkul-doduk`과 겹치던 따뜻한 저폴리 산업 랙·광택 부품·절단 후 장치 개방/생물 이동 축을 제거했다. 코드로 만든 무광 남색 직조 천·반원 장자 후프·분필 격자·자홍 실·고정핀 무늬 조각으로 항로 도면을 새로 구성했다. 정답 사건은 대응 변이 포개져 증거선이 잠기고 구조망 조각이 정렬되는 사건으로 바꾸었다. 게는 제자리에서 집게만 반응한다. 추가 생성 에셋은 없으며 형태·재질·연출은 모두 `GereulKkeonaeView.cs`의 Unity 프리미티브로 제작했다.
- 3차 수정 시각 재설계: `ppittul-daemun`과 겹친 어두운 자주 직조/극장, 천·실·봉제 부품, 상단 사각 명패를 제거했다. 밝은 지상 조간대의 젖은 돌·반투명 물결·산호 아치, 유광 도자 눈금통·구조 부표·입체 그물 타일로 교체했다. 제목은 패널이 아니라 세계 안 산호 아치와 조개 글자에 놓인다. 정답 사건은 봉제선 잠금이 아니라 그물이 입체로 뒤집히고 유일한 구조게가 반대편 바위까지 활강하며 물결 고리와 도자 타일이 연쇄 반응하는 탈출 사건이다. 정답 화면 흔들림은 사용하지 않는다. 추가 생성 에셋은 없고 전부 `GereulKkeonaeView.cs`의 Unity 프리미티브와 킷 재질로 제작했다.
- 외부 CDN·상표·기존 캐릭터 자산 없음. 모든 새 작업장 오브젝트와 캐릭터는 Unity 코드로 제작했다.

## 검증 기록

- `validation/pointer-playthrough.mjs`: 답 훅 없이 실제 포인터로 정상 8/8, 첫 오답 뒤 재단 회복 8/8, 서로 다른 독립 두 번째 판 8/8을 완주한다.
- `validation/b3-pointer-selftest.mjs`: 고정·순환·무작위 각 200판의 첫 연결 600건을 줄 뽑기→절단→연결 실제 포인터로 제출하고, 무입력 200판의 진도 0을 확인한다.
- `validation/fix3-regression.mjs`: 실제 타이틀 탭, 무효 탭 피드백, 눈금 직접 선택, 두 연습 30초 이내 완주, 820×1180 태블릿 판형을 확인한다.
- 검증 JSON의 `artifactHashSha256`는 파일명과 파일 내용을 함께 해시하며 최종 WebGL 산출물끼리 같아야 한다.
