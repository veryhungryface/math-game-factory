# 구슬 새총 아트·구현 기록

- 정체성: 살구빛 도자 구슬 계수소
- 런타임 배경: 외부 이미지 없이 Unity 프리미티브와 절차적 UI 텍스처로 제작한 2.5D 디오라마
- 팔레트: 살구 `#D58463`, 크림 `#F6D8A9`, 청록 `#275B69`, 보라 `#7854AF`, 남색 `#202F43`
- 초안 생성 참고 에셋 `assets/hero.png`, `title.png`는 식물 연못 콘셉트라 최종 표지·런타임에서 사용하지 않는다. 최종 `thumb.png`·`square.png`는 실제 WebGL 타이틀을 직접 캡처한다.
- 생성 프롬프트와 파일 출처: `factory/work/chosen.json`의 `art_direction.assets_needed`, `factory/work/art.json`
- 1차 수정 재설계: `sil-taneun-geomi`와 겹친 식물 디오라마·식물 개방 사건을 제거하고, 테라초 작업대·도자 발사기·회전 계수탑·영구 계수띠로 교체했다.
- 피드백 사건: 정답은 스프링 압축 복원→도자 구슬 호→계수탑 여섯 박자 회전→상대도수 계수띠 조립. 오답은 발사기 주저앉음→안전볼트 소모→오차 표본함 기록.
- 정답 경로에는 화면 흔들림을 쓰지 않고, 오답에만 짧은 카메라 흔들림을 쓴다.
