# 구슬 새총 아트·구현 기록

- 정체성: 황록 수련 연못의 살아 있는 구슬 새총
- 런타임 배경: 외부 이미지 없이 Unity 프리미티브와 절차적 UI 텍스처로 제작한 2.5D 디오라마
- 팔레트: `#CDD34B`, `#49613D`, `#7854AF`, `#F3EEDC`, `#263A2C`
- 생성 참고 에셋: `public/g/guseul-saechong/assets/hero.png`, `title.png`; 런타임은 배경 정책을 지키기 위해 직접 참조하지 않는다.
- 생성 프롬프트와 파일 출처: `factory/work/chosen.json`의 `art_direction.assets_needed`, `factory/work/art.json`
- 피드백 사건: 정답은 식물 탄성 복원→도자 구슬 호→씨방 여섯 박자→잎길·상대도수 기록. 오답은 처짐→안전잎 소모→검은 실패 조개.
- 정답 경로에는 화면 흔들림을 쓰지 않고, 오답에만 짧은 카메라 흔들림을 쓴다.
