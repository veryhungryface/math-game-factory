# 원 찍어 v3 — 2단계 재설계 (2026-09-26, 사용자 피드백 2차)

## 사용자 지적
> 「접기 파트로 넘어가서부터 이해가 안 가.」

## 진단 (배포본 2단계 진입 직후 캡처로 확인)
1. 해금 순간 판이 **텅 빈다**(삼각형 없음). 「필름 집게가 풀린다 · 이제 거리선은 없다」 글만 뜬다. 접을 **필름이 눈에 안 보인다**.
2. 규칙 설명이 글 한 줄(「꼭짓점을 끌어 다른 꼭짓점에 포개면 → 두 꼭짓점에서 거리가 같은 주름」)뿐이다. 시범 동작이 없다.
3. **1단계(거리)와 2단계(접기) 사이에 개념의 다리가 없다.** 「접힌 선이 왜 거리가 같은 점들인가」를 보여 주지 않는다.
   교과서 용어 **수직이등분선·각의 이등분선**이 한 번도 나오지 않고 「주름」이라고만 부른다.
4. 하단 「주름 1·2·3」 칸이 점만 찍혀 있어 의미가 없다. 삼각형 꼭짓점이 판 가장자리에 걸려 잘리는 경우가 있다.

## 사용자 결정: 「작도로 교체 + 다리 단계」 — 접기는 선이 생기는 **연출로만** 남긴다

## 새 흐름: 1단계(거리) → 다리 단계(자취) → 2단계(작도)

### 1단계 — 그대로 유지 (v2)
거리선·수선 실시간, 두 개 같으면 초록, 셋 같으면 빨강. 해금 조건 v2 와 같음.

### 다리 단계 — 「거리가 같은 점들은 한 줄로 선다」 (외심·내심 각 1판, 해금 직후)
- **외심 다리**: 삼각형에서 **A·B 두 꼭짓점만 강조**(C 는 흐리게). 과제: 「A, B에서 거리가 같은 점을 3개 찾아 찍어라」.
  PA·PB 두 선만 실시간 표시. PA=PB(초록)인 격자점에서 「점 찍기」 → 초록 발자국이 남는다(같은 점 중복 불가).
  3개가 모이면 발자국을 관통하는 직선이 그려지며 **「변 AB의 수직이등분선」** 라벨 + 중점 같은 길이 눈금 + 직각 표시,
  그리고 문장: **「A, B에서 거리가 같은 점은 모두 AB의 수직이등분선 위에 있다」**. 이어서 「그러면 세 꼭짓점에서 거리가 같은
  외심은? → 세 변의 수직이등분선이 만나는 점」 한 줄로 2단계를 예고.
- **내심 다리**: 두 변 AB·AC 만 강조. 과제: 「두 변 AB, AC에서 거리가 같은 점을 3개 찾아 찍어라」. 두 수선만 표시.
  3개가 모이면 **「∠A의 이등분선」** 라벨 + 같은 각 호 2개, 문장 **「두 변에서 거리가 같은 점은 그 각의 이등분선 위에 있다」**.
  예고: 「내심은 세 내각의 이등분선이 만나는 점」.
- 생성기는 해당 이등분선 위에 **판 안의 격자점이 4개 이상** 있는 삼각형만 고른다(정수 판정 유지). 잘못 찍으면(PA≠PB)
  발자국이 안 남고 두 길이가 흔들리며 다름을 보여 준다(목숨 차감 없음 — 학습 단계).

### 2단계 — 작도로 찾기 (거리선 없음)
- 조작: **변을 탭하면 그 변의 수직이등분선**이, **꼭짓점(각 안쪽)을 탭하면 그 각의 이등분선**이 그려진다
  (중점 눈금·직각 표시 / 같은 각 호 포함, 선은 판 끝까지). 선이 생길 때 **짧은 접기 연출**(필름이 A를 B에 포갰다 펴지며
  주름이 남는 0.6~0.8초, 입력 차단 없음)은 넣어도 된다 — 조작은 탭이다.
- 모든 선에 **교과서 이름 라벨**: 「AB의 수직이등분선」, 「∠B의 이등분선」.
- 선 2개가 만나면 교점 표식, 핀은 교점으로 스냅 → 「핀 박기」. 선은 판당 최대 3개. 3번째 선이 같은 점을 지나면
  「세 변의 수직이등분선은 한 점에서 만난다」/「세 내각의 이등분선은 한 점에서 만난다」 보너스.
- **수학 판단 = 어느 작도를 고르느냐.** 외심 문제에 각의 이등분선을 그어 만든 교점(=내심)에 박으면 오답 → 1단계 거리선이
  1초 되살아나 PA·PB·PC가 다름을 보여 준다. 섞어 그은 교점도 같은 방식.
- 온보딩: 2단계 첫 외심·첫 내심 판에서 **유령 손가락이 변(또는 꼭짓점)을 탭하는 시범**을 1회 재생하고, 배너에
  교과서 성질을 그대로 쓴다 — 「외심 = 세 변의 수직이등분선의 교점」, 「내심 = 세 내각의 이등분선의 교점」.
- 하단 계기판: 그은 선 목록(「AB의 수직이등분선 ✓」)과 남은 선 수. 의미 없는 점 칸 금지.

### 전환·배치
- 해금 순간에도 **다음 삼각형을 즉시 보여 준다**(빈 판 금지). 해금 카드: 「1단계 통과 — 이제 거리선 없이, 성질로 찾는다」.
- 삼각형 꼭짓점과 라벨이 판 가장자리에서 최소 1칸 떨어지게 배치(잘림 금지).

## 검증 요구
- 다리 단계: 발자국 3개가 모이면 항상 해당 이등분선 위에 있음(정수 증명), 생성 삼각형 전부 격자점 ≥4.
- 2단계 무뇌 봇: 무작위 탭(변·꼭짓점·빈 곳) / 항상 변만 / 항상 꼭짓점만 / 무입력 — 첫 시도 정답률과 우연 수준.
  「항상 변만」 봇은 외심에서만 맞고 내심에서 0이어야 한다(외심·내심 문항이 섞여 나오므로 합계가 우연 수준 근처).
- 첫 플레이 하네스·QA 치명 0, 모바일/1280 스크린샷을 직접 확인(2단계 화면 포함 — `__GAME_TEST__.answerCorrect` 반복으로 진입 가능).
