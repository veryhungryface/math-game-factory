# 달팽이 퍼레이드 아트 소스 기록

- `public/g/dalpaengi-parade/assets/hero.png`: GPT 이미지 생성. 유백색 에나멜 몸, 투명 라즈베리 레진 껍데기, 황동 태엽 키를 가진 오리지널 자동인형 달팽이의 형태·재질 참고용이다. 런타임은 이 이미지를 평면 스프라이트로 쓰지 않고 Unity 프리미티브로 다시 조형했다.
- `public/g/dalpaengi-parade/assets/enamel_material_reference.png`: GPT 이미지 생성. 자홍 에나멜·유백 에나멜·투명 레진·황동 재질 참고용이다.
- `public/g/dalpaengi-parade/assets/title.png`: GPT 이미지 생성 세로 키 아트. 런타임 타이틀은 먹빛 공허의 회전 궤도와 중앙 태엽 키를 실시간 3D로 구성하므로 로딩 실패나 정적 이미지 의존이 없다.
- `public/g/dalpaengi-parade/thumb.png`, `square.png`: 아트 단계 생성 표지. 최종 검증 뒤 런타임 타이틀 캡처와 재질·주인공·카메라가 일치하는지 대조한다.

상표나 기존 캐릭터를 참조하지 않았다. 배경 일러스트는 런타임에 사용하지 않는다.
