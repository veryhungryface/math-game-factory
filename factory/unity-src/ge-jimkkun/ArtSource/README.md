# 게 짐꾼 아트 소스 기록

- 1차 검수 뒤 청록 수중·말랑한 생물 계열을 폐기하고, 게임 세계·황동 게 토큰·목제 지도판·종이 지도·인덱스 휠을 Unity 프리미티브와 런타임 UI 메시로 직접 구성했다.
- 초기 `assets/hero.png`·`assets/title.png`와 생성 표지는 런타임에서 사용하지 않는다. 최초 생성 프롬프트의 출처는 `factory/work/chosen.json`에 남아 있다.
- `public/g/ge-jimkkun/thumb.png`, `square.png`: 수정된 실제 WebGL 타이틀 장면을 각각 1200×630·1080×1080 뷰포트에서 직접 캡처한다. 별도 생성 아트나 다른 게임 에셋을 합성하지 않는다.
- 외부 상표·기존 캐릭터·원격 런타임 에셋은 사용하지 않았다.
