# 게 짐꾼 아트 소스 기록

- 1차 검수 뒤 청록 수중·말랑한 생물 계열을 폐기했으나, 목제 작업대·상아 판재·황동 부품이 게시작 `hyeonak-nemo`와 같은 계열이라는 2차 검수 high가 남았다.
- 2차 수정은 수평 작업대와 금속 부품을 다시 폐기하고, 짙은 남보라 책 표지에서 산호·민트색 얇은 종이 면이 일어나는 팝업 항로책 극장으로 바꿨다. 주재료는 채색 종이·먹선·노란 실·접철부이며, 게도 금속 토큰이 아니라 각진 종이 접기 캐릭터다.
- 정답 사건은 빛 흔적 뒤 장부가 이동하는 연출이 아니라 세 꼭짓점의 실이 동시에 당겨져 가운데 지도 한 장이 V자 입체 항로로 실제 접혀 일어나는 사건이다. 정답 화면 흔들림은 사용하지 않는다.
- 초기 `assets/hero.png`·`assets/title.png`와 생성 표지는 런타임에서 사용하지 않는다. 최초 생성 프롬프트의 출처는 `factory/work/chosen.json`에 남아 있다.
- `public/g/ge-jimkkun/thumb.png`, `square.png`: 2차 수정된 실제 WebGL 타이틀 장면을 각각 1200×630·1080×1080 뷰포트에서 직접 캡처한다. 별도 생성 아트나 다른 게임 에셋을 합성하지 않는다.
- 외부 상표·기존 캐릭터·원격 런타임 에셋은 사용하지 않았다.

## 3차 수정 — 디자인 계열 재분화

- 최신 검수에서 `neoguri-oncheon`과 중앙 팝업북 디오라마·채색 종이 물성·솟아오르는 팝업 정답 사건이 모두 겹친다는 high를 받았다.
- 팝업북과 종이 면을 전부 폐기하고, 수직 현무암 조수갑문·깊은 남청 수로·도색 부표·굵은 계류 밧줄로 세계와 재질 축을 바꿨다.
- 정답 사건은 상승/접힘이 아니라 세 장력선이 실제 예인선에 걸리고 선체가 수로를 왼쪽에서 오른쪽으로 횡단하는 이동 사건이다. 수학 드래그·정수 판정·오답 매듭 규칙은 유지했다.
- 3차 `thumb.png`·`square.png`도 최종 WebGL 타이틀 장면을 다시 직접 캡처한다. 생성 이미지나 타 게임 에셋은 사용하지 않는다.
