# 컷라인 아트 소스

게임 내부는 `chosen.json`의 background policy에 따라 외부 배경 이미지를 쓰지 않고 Unity 프리미티브와 절차적 메시로 만든 실시간 2.5D 옥상 디오라마다.

공유 이미지 `thumb.png`, `square.png`, `assets/title.png`는 이번 회차의 아트 에이전트가 생성했으며 원 프롬프트와 산출 기록은 `factory/work-lanes/20261008-013556-L3/art.json`에 있다. Unity 빌드에서는 존재하지 않는 추가 파일을 참조하지 않는다.
