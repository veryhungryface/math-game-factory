# Art source

The shipped Unity scene is a code-built 2.5D night silkscreen pattern lab. A cream pattern-book
sheet sits on a navy ink table, surrounded by angular screen frames, squeegees, ink cans, crop marks
and vermilion/cyan/yellow print plates. Answers assemble as flat cut-paper outfits in place on a
30-cell print grid; there are no plush creatures or processional character rows. The generated PNG
assets in `public/g/mungsil-fashion-show/assets/` are retained as early concept provenance only and
are not used by the WebGL scene.

Palette and form source: `factory/work-lanes/20261009-013916-L3/chosen.json` and `art.json`.
Round-3 redesign source: `Scripts/MungsilView.cs`. It changes palette, form language, backdrop and
feedback choreography to the silkscreen pattern-book identity, replaces the centered rounded title
banner with an offset angular print label, and preserves the 1-to-30 registration-line drag and the
1-to-6 practice demonstration. Pointer evidence and its artifact hash live under `validation/`.
