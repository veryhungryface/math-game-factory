# 싹 건져 — 아트 출처

- 런타임 장면은 외부 이미지 없이 Unity 절단 암반 메시, 각진 갑각 메시, `MgfLook` 재질로 만든 층리 암반 조수 수조다.
- 초기 생성 참고 이미지는 실제 게임과 오인되지 않도록 `unused-generated/`에만 보존하며 런타임·공유 표지에서 사용하지 않는다.
- 공유 이미지 `public/g/ssak-geonjyeo/thumb.png`(1200×630)와 `square.png`(1080×1080)는 2차 수정 WebGL 타이틀의 실제 GPU 캡처에서 잘라 만들었다.
- 2회 실입력 및 정답·오답 화면 증거는 `validation/two-run-real-pointer/`에 있다. 상표·기존 캐릭터는 사용하지 않았다.
