# 달팽이 극장 — 아트 출처와 런타임 구현

- 아트 단계 기록: `factory/work/art.json`, `art-hero.json`, `art-title.json`, `art-thumb.json`, `art-square.json`.
- 생성 원본(초기/1차 수정 참고용): `public/g/dalpaengi-geukjang/assets/hero.png`, `assets/title.png`, `concept/fix1-thumb-source.png`, `concept/fix1-square-source.png`.
- 런타임은 생성 이미지를 배경 빌보드로 쓰지 않는다. `Scripts/DalpaengiView.cs`가 밝은 민트 하늘, 분홍 껍데기 성장층, 이끼 언덕, 접힌 잎 객석, 천 현수막과 달팽이 관객을 Unity 프리미티브와 절차적 메시로 만든다. 따라서 생성 이미지 로드 실패나 외부 네트워크 요청이 없다.
- `hero.png`는 달팽이 비율·재질 참고, `title.png`는 세로 구도 참고다. 실제 캐릭터는 통통한 몸통·납작한 껍데기·더듬이로 재구성했고 특정 상표나 기존 캐릭터를 복제하지 않았다.
- 효과음은 첫 사용자 입력 뒤 `MgfSfx`가 만드는 코드 합성음만 사용한다. 정답은 계산한 수만큼 꽃잎 커튼 개방→달팽이 관객 입장→껍데기 타악→공연별 꽃등 누적으로, 오답은 빈자리·꽃종 금·오답 전용 카메라 흔들림으로 구분한다. 정답 경로에는 화면 흔들림이 없다.
- 3차 수정 팔레트: shell rose `#E89A91`, petal blush `#F7C7B5`, leaf green `#6FA45B`, young leaf `#B8D976`, paper ivory `#FFF5D8`.
