# 팝콘 핀볼 아트 기록

- 아트 에이전트 산출물: `public/g/popcorn-pinball/assets/title.png`, `thumb.png`, `square.png`
- 런타임 타이틀 텍스처는 위 `title.png`를 `Resources/PopcornPinball/title.png`에 복제해 사용한다.
- 생성 프롬프트와 크기·출처 기록은 `factory/work/art.json`, `art-title.json`, `art-thumb.json`, `art-square.json`에 있다.
- 런타임 세계는 외부 모델 없이 Unity 프리미티브와 절차적 UI 스프라이트로 만든다.
