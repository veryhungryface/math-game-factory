# 석류 코어 아트 출처

- `public/g/seongnyu-core/assets/title.png`: 아트 단계 생성 키 아트 원본. 회화형 원화와 런타임 재질 충돌 때문에 사용하지 않는다. 타이틀은 실제 Unity의 거대 석류 내부·반투명 과육막·유리 모세관·액체 코어와 같은 조명으로 렌더한다.
- `public/g/seongnyu-core/assets/germ-model-reference.png`: 물방울형 몸통·검은 씨앗 눈·잎팔을 가진 오리지널 씨눈 생물 모델링 참고.
- `public/g/seongnyu-core/thumb.png`, `square.png`: 3차 수정 후 `validation/capture-covers.mjs`로 실제 Unity 타이틀을 각각 1200×630, 1080×1080에서 다시 캡처한다.

외부 상표·기존 캐릭터·원격 에셋은 사용하지 않는다. 런타임은 코드 생성 메시와 킷 재질만 사용한다. 3차 수정은 새 외부 에셋 없이 기획 원안의 유리 모세관·반투명 씨방막·과즙 코어 구조를 코드 생성으로 구현했다.
