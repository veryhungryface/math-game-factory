# 석류 코어 아트 출처

- `public/g/seongnyu-core/assets/title.png`: 아트 단계 생성 키 아트 원본. 회화형 원화와 런타임 재질 충돌 때문에 사용하지 않는다. 타이틀은 실제 Unity의 밝은 과수원·무광 과피·천 로제트와 같은 조명으로 렌더한다.
- `public/g/seongnyu-core/assets/germ-model-reference.png`: 물방울형 몸통·검은 씨앗 눈·잎팔을 가진 오리지널 씨눈 생물 모델링 참고.
- `public/g/seongnyu-core/thumb.png`, `square.png`: 2차 수정 후 `validation/capture-covers.mjs`로 실제 Unity 타이틀을 각각 1200×630, 1080×1080에서 캡처한다.

외부 상표·기존 캐릭터·원격 에셋은 사용하지 않는다. 런타임은 코드 생성 메시와 킷 재질만 사용한다. 2차 수정의 과수원·도자·천 로제트도 생성 이미지나 타 게임 에셋을 쓰지 않았다.
