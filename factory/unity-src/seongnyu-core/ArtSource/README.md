# 석류 코어 아트 출처

- `public/g/seongnyu-core/assets/title.png`: 아트 단계 생성 키 아트. 거대한 석류 단면, 유백색 모세관, 씨눈 생물. 런타임 제목 화면은 같은 구도를 Unity 프리미티브로 재구성한다.
- `public/g/seongnyu-core/assets/germ-model-reference.png`: 물방울형 몸통·검은 씨앗 눈·잎팔을 가진 오리지널 씨눈 생물 모델링 참고.
- `public/g/seongnyu-core/thumb.png`, `square.png`: 아트 단계 생성 표지. 최종 런타임 검증 뒤 필요하면 실제 게임 캡처로 갱신한다.

외부 상표·기존 캐릭터·원격 에셋은 사용하지 않는다. 런타임은 코드 생성 메시와 킷 재질만 사용한다.
