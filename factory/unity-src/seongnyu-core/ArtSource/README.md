# 석류 코어 아트 출처

- `public/g/seongnyu-core/assets/title.png`: 아트 단계 생성 키 아트 원본. 1차 검수에서 회화형 원화와 인게임 재질 충돌이 확인되어 런타임에서는 사용하지 않는다. 타이틀은 실제 Unity 무광 석재·도자 인레이 모델과 같은 조명으로 렌더한다.
- `public/g/seongnyu-core/assets/germ-model-reference.png`: 물방울형 몸통·검은 씨앗 눈·잎팔을 가진 오리지널 씨눈 생물 모델링 참고.
- `public/g/seongnyu-core/thumb.png`, `square.png`: 1차 수정 후 실제 Unity 타이틀 캡처로 갱신한다.

외부 상표·기존 캐릭터·원격 에셋은 사용하지 않는다. 런타임은 코드 생성 메시와 킷 재질만 사용한다.
