# 연못 점프 아트 기록

- 기획 정체성의 핵심인 `자두색 청개구리의 연꽃 징검못`과 대응점 도약은 유지한다.
- 1차 수정에서 게시작 `sil-taneun-geomi`와 겹치던 밝은 라일락 파스텔·크림 꽃잎 패널·꽃 개화 문법을 제거했다. 배경은 비 오는 심야의 청록 갈대 수로, 표식은 구리/녹청 부표, 정답 사건은 세 잎이 맞물려 굽은 물결 길을 여는 장면으로 재구성했다.
- 런타임은 외부 배경 이미지를 쓰지 않고 Unity 프리미티브와 절차적 잎 메시로 반사 수면, 층진 둑, 갈대, 수로 표지, 잠자리, 개구리를 만든다.
- `public/g/yeonmot-jeompeu/assets/hero.png`는 아트 단계가 만든 모델링 참고 원화다. 런타임 캐릭터는 상표나 기존 캐릭터 특징 없이 구·타원 프리미티브로 새로 만들었다.
- 아트 단계 생성 프롬프트와 산출 기록은 `factory/work-lanes/20261017-040537-L2/art.json`에 있다.
- 런타임 팔레트: 수면 `#12343E`, 깊은 물 `#071A24`, 잎 `#487C69`, 개구리 `#9B5574`, 구리 표식 `#D77A4B`, 녹청 신호 `#72B7A6`, 야간 패널 `#16303A`.
- 새 이미지·영상·모델 생성은 하지 않았다. 위 수정은 런타임 재질·절차적 메시·UI 배치만 사용한다.
