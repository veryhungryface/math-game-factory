# 연 띄워 — 아트 출처와 1차 수정 기록

- `hero-reference.png`: 이번 회차 아트 단계가 생성한 흑칠 대각선 살대 카트리지 레퍼런스. 게임의 카트리지 재질·주홍 매듭 색 참고용이며 런타임에는 직접 참조하지 않는다.
- `Resources/YeonTtwiwo/title.png`: 최초 빌드의 타이틀 키 아트 사본. 1차 수정부터는 코드에서 읽지 않는 보존 원본이다.
- `public/g/yeon-ttwiwo/thumb.png`, `square.png`: 1차 수정 WebGL 런타임의 같은 종이바람 공방 타이틀을 각각 1200×630, 1080×1080으로 직접 캡처한다.

생성 프롬프트의 정본은 `factory/work-lanes/20261012-014923-L2/art.json`에 있다. 상표나 기존 캐릭터를 참조하지 않았다.

1차 수정에서는 검수의 디자인 계열 중복 지적을 해결하기 위해 생성 회화형 폭풍 옥상과 유광 흑철 물성을 런타임에서 제거했다. 현재 타이틀과 플레이는 모두 `YeonTtwiwoView.cs`가 만드는 밝은 낮의 미니어처 종이바람 공방이며, 무광 한지·대나무·실패·종이 조각·작은 종이바람새를 Unity 프리미티브와 코드 머티리얼로 구성한다. 바람새는 대기 중 떠 있고 정답에는 위로 뛰며 오답에는 물러난다. 새 생성 에셋이나 외부 출처는 없다.
