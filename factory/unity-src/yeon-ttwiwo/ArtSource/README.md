# 연 띄워 — 아트 출처와 수정 기록

- `hero-reference.png`: 이번 회차 아트 단계가 생성한 흑칠 대각선 살대 카트리지 레퍼런스. 게임의 카트리지 재질·주홍 매듭 색 참고용이며 런타임에는 직접 참조하지 않는다.
- `Resources/YeonTtwiwo/title.png`: 최초 빌드의 타이틀 키 아트 사본. 1차 수정부터는 코드에서 읽지 않는 보존 원본이다.
- `public/g/yeon-ttwiwo/thumb.png`, `square.png`: WebGL 런타임 타이틀을 각각 1200×630, 1080×1080으로 직접 캡처한다.

생성 프롬프트의 정본은 `factory/work-lanes/20261012-014923-L2/art.json`에 있다. 상표나 기존 캐릭터를 참조하지 않았다.

2차 수정에서는 밝은 종이 공방이 게시작 `neoguri-oncheon`과 같은 공예 디오라마 계열이라는 최신 검수 결과에 따라 `chosen.json`의 원안인 흑칠 연 관측옥상으로 복원했다. 타이틀과 플레이는 모두 `YeonTtwiwoView.cs`가 만드는 같은 쿼터뷰 월드이며, 젖은 흑칠 기와·수직 바람탑·주홍 장력줄·진주빛 연막·층진 먹구름을 Unity 프리미티브와 코드 머티리얼로 구성한다. 캐릭터 대신 장력 풍향계가 정답에 튀어 오르고 오답에 물러난다. 새 생성 에셋이나 외부 출처는 없다.

3차 수정에서는 연습의 한 원호를 90° 한 번으로 잠그고, BO:DO 비에 맞춰 살대의 O 홈을 옮겼다. `ArtSource/validation/playthrough-selftest.mjs`는 수정 전 오답을 만들던 180° 긴 원호를 그대로 재생해 실전 진입을 확인하고, 최종 WebGL의 360문항 표기·실제 포인터 두 판·퇴화 오답·세 가로 판형·무뇌 정책을 함께 검증한다. 새 생성 에셋이나 외부 출처는 추가하지 않았다.
