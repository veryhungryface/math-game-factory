# 종이새 출격 아트 기록

- 2차 수정 정체성: 호박색 조명이 스미는 먹빛 측면식 종이 기계 풍동. 둥근 조준 관문 대신 날카로운 장력막, 금속 리브, 봉제선과 접힌 탭을 Unity 코드 메시로 구성한다.
- 정답 사건: 종이새가 세 원형 관문을 통과하는 연출을 폐기했다. 학생이 만든 날개 각을 유지한 새가 중앙 장력막을 가로질러 빛나는 봉제선을 잇고, 세 개의 대칭 접힘 장력이 차례로 펴진다.
- 결과 화면: 플레이 풍동을 감추고 독립 먹빛 성적판에 총 출격·첫 출격·외각 첫 출격을 세 행으로 분리한다.
- 런타임 텍스처: `public/g/jongisae-chulgyeok/assets/paper-fiber.png`에서 복사한 512×512 수제 종이 섬유 텍스처. 생성 프롬프트는 “Seamless fine handmade paper fiber texture, evenly lit, subtle grain only, no lettering, no objects, no baked lighting”.
- 카탈로그 원화: `thumb.png`, `square.png`, `assets/title.png`는 2026-10-16 art 단계의 내장 이미지 생성 결과다. 런타임 배경으로 쓰지 않으며, 코드 메시 장면과 같은 팔레트·종이 재질의 표지로만 사용한다.
- 외부 상표·기존 캐릭터·원격 에셋은 사용하지 않는다.
