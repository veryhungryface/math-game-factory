# 자두 집게 아트 출처

- 배경 정책: 최종 런타임은 이미지 배경을 쓰지 않고 Unity 프리미티브로 라일락 수관, 자두, 가지, 잎 미끄럼틀, 수레, 집게벌레를 구성한다.
- `public/g/jadu-jipge/assets/beetle-detail.png`: 내장 이미지 생성 도구. 둥근 씨앗형 몸, 여섯 다리, 독립 법랑 신축팔의 idle/holding/disappointed 포즈 시트.
- `public/g/jadu-jipge/assets/title.png`: 내장 이미지 생성 도구. 세로 타이틀 구도 연구용이며 런타임 배경에는 사용하지 않는다.
- `public/g/jadu-jipge/thumb.png`, `square.png`: 내장 이미지 생성 도구의 구도 연구 원화에서 규격 리사이즈·최적화한 표지.
- 원작 캐릭터·상표를 참조하지 않은 게임 전용 생물이며, 런타임 모델은 C# 프리미티브 조합으로 새로 구성했다.

## 1차 수정의 시각 분화

- 새 이미지 자산은 만들지 않았다. 기존 수관 정체성을 유지하면서 런타임 구성을 C#으로 다시 잡았다.
- `sil-taneun-geomi`와 겹치던 평평한 파스텔 매트를 제거하고, 화면 깊이를 관통하는 수직 줄기·비스듬한 작업 가지·층층의 수관으로 바꿨다.
- 말랑한 도구 하나만 놓인 인상을 줄이기 위해 집게 뒤에 1~12 고정 법랑 계측 레일, 매 눈금 숫자, 연습 목표 고리를 추가했다.
- 중앙 대형 타이틀 패널은 우측 상단 가지에 매단 작은 법랑 표지로 줄여 게임 세계와 빛나는 자두가 화면을 먼저 차지하게 했다.

## 2차 수정의 시각·상호작용 분화

- 새 이미지 자산은 만들지 않았다. 런타임과 표지의 물성 차이를 없애기 위해 최종 표지는 수정된 Unity 타이틀을 직접 캡처한다.
- 배경을 라일락 구체 수관에서 어두운 녹청 수관 절개 무대로 바꾸고, 겹친 동심 목질 단면·가늘고 방향성 있는 잎·깊은 가지로 세계 축을 분리했다.
- 조작부는 큰 보라 판 손잡이 대신 작은 황동 손잡이와 가는 상아 법랑 텔레스코프 레일로 바꿨다. 가로 화면 값은 좌·우 안전 존 콜아웃과 리더선, 세로 화면 값은 하단 한 줄 요약으로 표시한다.
- 정답 사건은 벌레가 길을 타는 이동 대신 삼각 수확망이 닫히고 자두 무게로 카운터웨이트 수레가 내려가게 했다. 벌레는 짧게 기울어 반응만 한다.
