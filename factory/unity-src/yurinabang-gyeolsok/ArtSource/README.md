- 팔레트: `#152237 #202A36 #315A8D #43B9B0 #D85C4A #D79A51 #E6D8BE`.
- 런타임은 식물·직물·생물·반투명 유리를 쓰지 않는다. 불투명 도자 셀, 건메탈 기둥, 구리 버스바, 경질 에나멜 자석 셔틀을 Unity 프리미티브와 절차형 UI로 만든다.
- 정답 사건은 생물이 연결 경로를 지나 개구부를 여는 장면이 아니라, 세 결속핀이 차례로 맞물리고 삼각 상감 문양이 각인되는 기계 사건이다.
- `title.png`, `glass-pattern.png`와 초기 `moth-reference.png`는 1차 밤온실 안의 생성 기록으로만 보존하며 현재 런타임에는 표시하지 않는다.

## 피드백 재질

- 정답: 학생이 만든 세 자석 레일이 청록→구리→주홍 순서로 잠기고, 결속핀이 맞물린 뒤 불투명 도자판에 상감 문양이 생긴다. 점수는 카운트업하며 정답 화면 흔들림은 없다.
- 오답: 화면 적색 플래시 없이 도자 균열과 실제 깨진 비·끼인각 설명을 남긴다. 카메라 흔들림은 오답에만 사용한다.
- 대기: 24개 자석 셔틀의 짧은 레일 왕복, 층별 계전 셀, 과부하 띠, 레버 맥동이 지속된다.
