## 설계 요지
- 기하 모델·판정·오개념 매핑: `Scripts/YuriRules.cs` 머리 주석.
- 12장 덱: 1~4 평행사변형(길이 숫자) · 5 다리(숫자 걷힘·캘리퍼) · 6 직사각형(절반은 교각 90° = 포함 관계) · 7~12 섞음
  {직사각형+길이 다름 치우기(M2) · 마름모 구성(회전) · 잠긴 쪼개기 A(M1/ㄱ) · 치우기 B(연 M4/등변사다리꼴 M3/정사각형+길이 다름) · 잠긴 쪼개기 B(ㄷ/ㄹ/M1) · 정사각형 구성 또는 넓이 주문}.
- 치우기 정답 2장 = 잠긴 쪼개기 정답 2장 → 「항상 위」「항상 아래」 연타가 우연 수준에 묶인다.

## 계획서 대비 축소(루프는 전부 구현, 도구만 줄임)
- 각도기 도구 우물 없음 → 교각은 티켓에 `∠AOB = ○°` 로 상시 표시(길이 숫자만 2단계부터 걷는다).
- 캘리퍼는 「막대를 톡 치면 1.6초 잰다」로 단순화(길게 누르기 3단계 없음). 일일 시드 3장 없음.
- 알려진 우회: 「잠긴 장 → 위, 구성 장 → 아래」 전략은 12장을 강제로 모두 받게 하면 24.8%(우연 16.8%)지만,
  실제 판 규칙에서는 첫 5장(구성)에서 예비 장을 다 잃어 첫 시도 정답률 0%다(bot-results.md 2 / 2-b).
