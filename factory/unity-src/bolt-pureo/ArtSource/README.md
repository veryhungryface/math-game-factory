# 볼트 풀어 — 아트 출처

- 세계: 비가 갠 뒤의 밝은 수직 조류정원. 청록·산호 도자 삼각판, 채색 목재 격자, 둥근 새집과 상주 새들이 층마다 움직인다.
- 팔레트: `#97D3D6`, `#56BEAE`, `#F48B69`, `#DD9A4E`, `#FFF6D6`
- 런타임 장면은 Unity 프리미티브와 절차적 삼각 프리즘·빗줄기·정원 소품으로 제작했다. 금속성은 볼트의 작은 강조에만 쓰고 주재료는 무광 도자와 채색 목재다.
- 기존 생성 표지는 런타임과 다른 회화 밀도 때문에 사용하지 않는다. 최종 `thumb.png`·`square.png`는 WebGL 타이틀 장면을 직접 캡처해 같은 카메라·삼각판·모스·조명을 공유한다.
