## 시리즈 템플릿 패턴

- **"OO 디펜스" 계열** (킹네모 디펜스, 비교 디펜스): 정답=공격/파괴, 하트제 목숨, 실시간 랭킹. 문제 유형만 바뀌는 동일 골격.
- **"OO 채점킹" 계열** (비교 채점킹, 나눗셈 채점킹): 학생이 "채점자"가 되어 ⭕/✗를 매기는 메타인지형 포맷. 학급대항전(학교 등록+시즌제 랭킹)과 개인 모바일(1분 타임어택+콤보)의 두 변형이 있음. 오답 페널티는 항상 "국소 정지"(해당 칸/전체 3~5초)로 전체 흐름을 안 끊는 게 공통.
- **"학급대항전" 시즌제 랭킹**: 학교 등록 → 주간 시즌(목요일 리셋) → 명예의 전당. 전자칠판+학급 단위 경쟁을 코어 게임과 분리된 메타 레이어로 얹는 패턴, 여러 게임에 재사용 가능한 인프라로 보임.
- **모바일(sm) vs 와이드(wide) 태그 분리**: 같은 킹수학 브랜드 안에서 "전자칠판용(wide, QR로 개인기기 연동)"과 "개인 모바일용(sm)"을 별도 URL/UI로 명확히 분리 운영.

### 1. 확률킹 (5-2-6 가능성)
`https://kingsmath.com/kinghr?v=1774708376`

- **루프**: 참여 인원(1~4인) 선택 → 게임 시작 → 라운드마다 A/B 두 확률 상황(구슬 뽑기, 동전, 주사위 합, 가위바위보 등)이 제시되고, 화면 중앙의 A-B 막대 위를 바늘이 계속 좌우로 왕복 → 플레이어는 STOP 버튼으로 원하는 타이밍에 바늘을 멈춤 → **정지한 순간에야** A/B 각각의 확률(%)이 공개되고, 바늘이 더 높은 확률 쪽에 멈췄으면 정답 → 전체는 약 60초 카운트다운 타이머 안에서 여러 라운드가 자동으로 이어짐.
- **문제 생성**: 확률 소재(구슬 개수·색 비율, 동전, 주사위 합, 가위바위보)가 매 라운드 랜덤. 숫자(%)는 정답 확인 전엔 절대 보이지 않음 — "계산 후 선택"이 아니라 "감으로 비교 후 사후 검증"하는 구조.
- **오답 관용**: 오답이어도 하트/목숨 감소 없이 다음 라운드로 즉시 진행. 페널티 텍스트 자체가 없는 완전 저압박형.
- **전자칠판 장치**: 1~4인 동시 참여 버튼, 상단 "승리 확률" 진행바로 누적 성과를 시각화.
- **설계 포인트(참고용)**: 확률 비교를 수식이 아니라 "타이밍 반응 + 사후 공개 검증"으로 게임화한 게 핵심. 5-2-6 게임을 만들 때 정답을 먼저 안 보여주고 "선택 → 공개"의 순서를 지키면 확률 단원 특유의 "직관 대 실제" 긴장감을 얻을 수 있음.

### 2. 하이앤로우 확률킹 (5-2-6 가능성)
`https://kingsmath.com/king_bell/?v=1780885309`

- **루프**: 캐릭터(여우 "여욱") 대사 인트로(스킵 가능) → 참여 인원(1~6명)·총 판수(2~15판) 설정 → 모험 시작 → 매 라운드 기준 카드(1~9 숫자, 중복 없이 소진되는 카드풀)가 공개 → 플레이어는 보유 "벨"(가상화폐) 중 베팅액(100~600벨)을 고르고 다음 카드가 기준보다 HIGH(초과)인지 LOW(미만)인지 예측 → 초 단위 카운트다운(관찰상 30초 안팎) 안에 결정, 시간 종료 시 자동 공개·정산.
- **문제 생성**: "나온 숫자는 안 나온다"(비복원 추출) — 뽑힌 카드는 카드풀에서 제거되어 라운드가 진행될수록 실제 확률이 계속 바뀜(카드 카운팅 요소). 초등 5-2-6 수준(확실하다/반반이다 같은 정성적 언어)보다 심화된 개념이지만 "확률이 사건마다 변한다"는 걸 손으로 체감시키는 예시로 유용.
- **오답 관용**: 예측 실패 시 베팅한 벨(가상화폐)만큼 손실 — 목숨이 아니라 재화 손실형이라 다음 라운드도 계속 진행 가능(파산 시 처리는 미확인).
- **전자칠판 장치**: 1~6명 동시 참여(각자 벨 잔고 개별 관리), 판수(2~15판)를 교사가 수업 시간에 맞춰 설정.
- **설계 포인트**: 가상화폐 베팅으로 "확률 높은 쪽 선택 = 유리함"이라는 기대값 감각을 게임화. 다만 비복원추출 구조는 초등 수준을 넘어서므로, 우리 게임에 차용한다면 카드 소진 없이 "매 라운드 새 스피너/새 카드 1장" 정도로 단순화하는 편이 5-2-6 성취기준에 더 맞음.

### 3. 킹방울 입체도형 잇기 (6-2-3 공간과 입체 / 6-2-6)
`https://kingsmath.com/king3d?v=1775116554`

- **루프**: 주제 선택(각기둥·각뿔 / 원기둥·원뿔·구 / 모두) → 2인 팀전(강아지팀 vs 고양이팀) 시작 → 화면이 좌우로 분할되어 팀별 보드 제공, 각 보드에 **이름표 방울**(예: "사각기둥")과 **와이어프레임 그림 방울**(숨은 점선으로 그려진 겨냥도)이 무작위 배치 → 방울을 드래그해서 짝(이름↔그림)을 연결하면 즉시 정오 판정 → 짝이 없는 상태로 남으면 방울이 자동으로 터지고 새 방울로 재생성.
- **문제 생성**: 도형 세트가 주제 선택에 따라 필터링(각기둥·각뿔 계열 vs 원기둥·원뿔·구 계열), 방울 배치는 매 판 랜덤.
- **오답 관용**: 잘못된 매칭 시도는 점수 미가산으로만 처리되고 "매칭 불가! 방울 재생성" 안내로 무한 재시도 허용 — 하트/목숨 시스템 자체가 없음.
- **전자칠판 장치**: 좌우 분할 2팀 동시 플레이(팀별 점수 카운터), 전체 라운드 카운트다운 타이머(관찰상 57초~).
- **설계 포인트**: "이름 ↔ 겨냥도(와이어프레임) 매칭"이라는 매우 단순한 포맷이 공간감각 단원에 그대로 적용됨. "숨겨진 점선을 보고 이름 맞추기"라는 문구가 겨냥도 해석 능력을 직접 겨냥한 것도 인상적. **우리 공장에 아직 없는 6-2-3(공간과 입체) 게임을 만들 때, "이름-도형 매칭 + 팀 대결 + 실패 시 무패널티 재생성"이라는 골격을 거의 그대로 재사용 가능**한 가장 이식성 높은 사례.

### 4. 원킹 (6-2-5 원의 둘레와 넓이)
`https://kingsmath.com/kingo/?v=1774708375`

- **루프**: 게임설명("1/4원을 힌트로 보고 나머지 3/4를 한 붓으로 그려 완벽한 원을 만드세요") → 승부 시작 → 2인 동시 대결(좌우 분할, VS 아이콘) → 각자 화면에 1/4호(노랑/청록 색)가 힌트로 주어짐 → 마우스/터치 프리핸드 드래그로 나머지 원주를 그려 완성 → "다 했어요!" 클릭 시 채점, 그리기 실수 시 Undo(↺) 1회 제공, 완료 후 "대기 중..."으로 상대 완료를 기다림.
- **채점 방식(직접 확인)**: 실제로 드래그해 원을 그려보니, 제출 후 **회색 기준원(정답 가이드라인)이 겹쳐서 표시**되고 내가 그린 궤적과 비교됨 — 크기·모양·닫힘 여부(양 끝이 이어졌는지)를 기준으로 정밀도를 채점하는 구조 확인.
- **오답 관용**: Undo 1회 이후엔 그대로 채점(감점은 "선이 짧거나 안 닫히면") — 생명 시스템 없이 단판 승부(재도전 압박).
- **전자칠판 장치**: 상단 카운트다운(20초대), VS 아이콘 2인 실시간 대결, 완료 후 상대 대기 상태 명시.
- **설계 포인트**: "원의 넓이/둘레 계산"이 아니라 **원의 형태 감각(중심에서 둘레까지 거리가 일정함)을 손으로 그리게 하는** 완전히 다른 접근. 6-2-5 게임을 계산 문제 위주로 설계하더라도, 이런 "원의 성질을 체감시키는" 미니 라운드를 보조로 섞을 가치가 있음. 아래 넓이 비교 야호킹과 함께 "정밀 계산"보다 "감각/추정"에 방점을 둔 게 공통 특징.

### 5. 컷킹 (6-2-4 비례배분)
`https://kingsmath.com/kingcut?v=1774708378`

- **루프**: 게임설명("미션에 맞춰 도형을 드래그해서 자르세요", 단판 승부, Undo 1회) → 승부 시작 → 2인 대결(좌우 동일 모양의 도형 — 오각형·원 등 — 과 미션 텍스트가 라운드마다 표시) → 도형 위에 프리핸드 드래그로 절단선을 그어 요구된 넓이 비율을 맞춘 뒤 "다 했어요!" 클릭.
- **문제 생성**: 미션 표기가 라운드마다 **백분율("60% 남기기")과 분수("1/5 제거")를 섞어서** 제시 — 같은 게임 안에서 소수/분수/백분율의 등가성을 오가며 다룸. 도형 종류도 매 라운드 바뀜(오각형→원 등).
- **오답 관용**: Undo 1회만 허용 후 단판 채점(정확도 %로 점수화되는 구조, 실측 클릭으로는 절단선이 도형 경계 밖에서 시작하면 인식되지 않아 재시도 없이 다음 라운드로 넘어가는 것도 확인 — 즉 "자르기 자체를 실패"하면 그 라운드는 그냥 스킵됨).
- **전자칠판 장치**: 상단 카운트다운, VS 아이콘 2인 동시 대결.
- **설계 포인트**: "도형 넓이의 일정 비율을 잘라내기"라는 과제를 프리핸드 드래그라는 신체 활동으로 전환한 사례. 분수 피자킹과 함께 "비례배분을 시각적 절단/배치로 체감시키는" 시리즈로 묶이며, 계산 없이 눈대중으로 비율을 맞추게 하는 난이도 설계가 특징.

### 6. 분수 피자킹 (6-2-4 비례배분)
`https://kingsmath.com/kingpizza?v=1782460835`

- **루프**: 피자 종류(흑/백/킹/퀸)와 인원(2인/4인) 선택 → 시작하면 원판 피자가 **12등분된 부채꼴**로 고정 표시 → 상단 "주문서"에 토핑별 필요 비율이 서로 다른 분모의 분수로 제시(예: 양파 5/12, 소고기 1/6, 토마토 5/12) → 하단 토핑 아이콘(토마토/치즈/양파/버섯/베이컨/소고기) 중 하나를 선택해 활성화한 뒤, 피자 조각(웨지)을 하나씩 클릭해 토핑을 채움 → 필요한 조각 수(분자를 분모 12 기준으로 환산)만큼 채우면 해당 주문 항목이 자동 완료되고 새 주문서로 즉시 갱신(무한 라운드형) → "배달" 버튼으로 제출, "초기화"로 언제든 리셋 가능.
- **실측 확인**: 토마토를 선택해 웨지 2칸을 클릭하니 실시간으로 빨간 토핑이 채워졌고, 주문서 항목이 자동으로 다음 세트(새 분수 조합)로 교체됨을 확인 — 정오 판정이 아니라 **목표 조각 수 달성 시 자동 완료**되는 구조.
- **문제 생성**: 주문서의 분수가 매번 랜덤(분모 2/3/4/6/12 등 12의 약수로 다양화)이며, 관찰된 세트들의 분자 합이 항상 분모 12 전체(피자 한 판)를 채우도록 구성.
- **오답 관용**: 명시적 오답 페널티 없음. "초기화" 버튼이 항상 열려 있어 실수해도 자유롭게 다시 채울 수 있는 완전 저압박형.
- **전자칠판 장치**: 좌우 2인(또는 4인) 동시 진행, VS 아이콘.
- **설계 포인트**: **12등분 고정 원판**이 서로 다른 분모(2, 3, 4, 6, 12)의 분수를 모두 "몇 조각인지"로 즉시 환산해서 보여주는 것이 핵심 — 계산 없이 시각·촉각으로 통분(공통분모 찾기)의 원리를 체득시킴. 컷킹(자유 절단, 정밀도 승부·Undo 1회)보다 이 "고정 격자 위에 분수만큼 채우기 + 자유 초기화" 쪽이 저압박 설계에 더 적합 — **비례배분 단원 게임을 만든다면 이 포맷이 우선 참고 대상**.

## C. 미제작 단원(가능성 · 공간과 입체 · 원) 선행 사례 요약

### 5-2-6 평균과 가능성 (우리는 6회차에 폐기되어 현재 없음)
후보: 확률킹, 하이앤로우 확률킹, 메모리킹(간접)

- **공통 패턴**: 셋 다 "확률을 수식으로 계산해서 답하기"가 아니라 **다른 행동(타이밍 STOP, 베팅, 기억 게임)에 확률적 소재를 얹는** 방식. 정답률·손익만 남기고 계산 과정을 강요하지 않음 — 저학년/저압박 지향인 5-2-6 성취기준과 잘 맞음.
- **확률킹**: "선택 먼저, 확률 공개는 나중" 구조가 가장 깔끔한 참고 모델. 우리 게임 설계 시 그대로 차용 가능(예: 회전판 두 개 중 어디가 더 유리한지 감으로 고르고 STOP → 사후 % 공개).
- **하이앤로우 확률킹**: 비복원추출(카드 소진)로 표본공간이 변하는 심화 버전 — 우리 게임엔 그대로 쓰기보다 "매 라운드 독립시행"으로 단순화해서 참고.
- **메모리킹**: 가능성 태그가 붙어 있지만 실제로는 기억력 게임(카드 위치 암기)이라 확률 학습과의 직접 연결은 약함 — 커리큘럼 태그가 게임 메커니즘보다 넓게 걸려있는 사례로만 참고(설정 화면의 세분화된 난이도 옵션은 UX 참고 가치 있음).
- **시사점**: 우리가 5-2-6 게임을 새로 만든다면 "① 두 확률적 상황을 나란히 제시 → ② 계산 없이 직관으로 선택(또는 반응속도 게임화) → ③ 선택 후에만 실제 확률을 공개해 검증"이라는 3단계 구조가 초등 눈높이에 가장 잘 맞는 패턴으로 보임.

### 6-2-3 공간과 입체 (아직 없음)
후보: 킹방울 입체도형 잇기

- 각기둥·각뿔·원기둥·원뿔·구를 **이름표 ↔ 겨냥도(와이어프레임) 매칭**으로 다룸. "숨은 점선을 보고 이름 맞추기"라는 문구가 겨냥도 해석 능력을 직접 겨냥.
- 2팀 대결(팀별 보드 분리) + 오답 시 무패널티 재생성이라는 골격이 단순하면서도 전자칠판 학급 대결에 바로 쓸 수 있는 형태.
- **시사점**: 이 단원 게임을 만들 때 이 매칭 포맷을 기본 골격으로 삼고, 난이도 단계로 "이름→겨냥도"뿐 아니라 "전개도→입체", "실제 사진(원기둥 모양 물건)→이름" 같은 변형을 추가하면 킹방울보다 확장성 있는 버전이 될 수 있음.

### 6-2-5 원의 둘레와 넓이 (아직 없음)
후보: 원킹, 넓이 비교 야호킹 모바일

- **원킹**은 "원의 둘레/넓이 계산"이 아니라 **원의 형태 감각을 손으로 그려서 체감**시키는 완전히 다른 접근(1/4 힌트 보고 3/4 완성, 기준원과 겹쳐 정밀도 채점). 계산 문제 이전에 "원이란 무엇인가(중심에서 둘레까지 거리 일정)"를 몸으로 익히는 보조 라운드로 참고 가치 큼.
- **넓이 비교 야호킹**은 반대로 **정밀 계산 없이 직관적 크기 비교**(더 넓은 도형 빠르게 터치)로 원의 넓이를 다룸. 난이도 2단계(쉬움=삼각/사각, 어려움=복합/원)로 원을 "다른 도형과 함께 넓이 감각을 기르는 대상"으로만 취급.
- **시사점**: 두 게임 모두 6-2-5의 실제 학습 목표인 "공식(반지름×반지름×3.14 등)을 이용한 계산"을 직접 다루지 않음 — 즉 킹수학 생태계에도 "원의 둘레·넓이 공식 적용" 게임은 이 그룹 안에 없는 것으로 보이며(1차 조사 43개 목록·나머지 3-2/6-2 그룹도 확인 필요), 우리가 만들 6-2-5 게임은 이 두 게임처럼 "감각/형태" 미니게임과 "공식 계산" 문제풀이를 함께 갖추는 하이브리드로 차별화할 여지가 있음.
