## (a) 플랫폼 구조

### 한 줄 요약

킹수학은 **로그인 없는 전자칠판 게임 허브**다. 게임이 콘텐츠이고, **학급 단위 주간 대항전 → 명예의 전당 → 지역 자부심**이 동기 엔진이다. 개인 계정이 아니라 **학교+학년+반**이 플레이어다.

### 허브 (`/`)

| 레이어 | 역할 |
|---|---|
| 카탈로그 | `/add/games-data-ko-nb.js` + 제작자 샤드 5개 (`Tmfhdls`, `bjh4042`, `chichiboo`, `simssijjang`, `whgakfwkf`). 홈은 한국어 전용 파일, 트렌드보드는 16개국 타이틀 파일 `games-data-nb.js`. |
| 분류 | 2단 카테고리 + 교육과정(학년-단원 `curriculum: ["4-1-2"]`) + 교과 태그(`kingkr/en/sc/so/art/cea/class/pe`, `music`, `Puzzles`, `arcade`). 기기 태그 `wide` / `sm` / `computer`. |
| 수업 도구 | 실시간 검색, 랜덤 게임, **번호 뽑기(raffle)** — 게임에 다녀와도 기록 유지. |
| 노출 | BEST 40 스트립(`/rankdata/`), 학급대항전 배너, 제작자 스포트라이트(명장킹). |
| 추적 | GA4 `G-5YW0T2C109`, 클릭은 `logActivity` → Supabase. |

슬로건이 포지션을 고정한다: **무광고·무가입·무설치·무료**, “옆 반, 옆 학교와 함께”, 교육청 차단 시 `킹수학.com`.

### 동기를 만드는 3단 루프

```
[수업 중 한 판] → [우리 반 최고기록이 게임별 TOP 100]
        ↓ 매주 목요일 12:00 시즌 종료
[게임별 1위 학급] → 명예의 전당 + 인증서 PDF
        ↓ 금/은/동 메달을 학급별로 합산
[전체 학급 랭킹] + [시도별 카운트] → “우리 지역/우리 학교”  rival
        ↓ 빈 왕좌·지난주 우승 위젯
[다음 시즌 재도전]  (모든 학급 동일 출발선)
```

**1. 학급대항전 (`/king_vs/`)**

- 허브 필터(`cg=vs`)로 입장. 실제 경기는 `/king_vs/{slug}/`.
- 관측된 15개 슬러그: `ddong, 10, move, tenpang, word, hunter, compare, balloon, emoji, flag, more, bigger1, bigger2, history, kingearth` (수학만이 아님 — 문해력·국기·역사·지구과학 혼재).
- 규칙 샘플(협똥킹): **우리 학급의 이번 시즌 최고 기록**이 랭킹. TOP 100 실시간. 인원/하트 등 공식 규정 고정. 시즌 끝나면 1위만 영구 등재, 나머지 리셋.
- 라이브 API: `GET /king_vs/get_champions.php` → 게임별 1~3위 학급명 배열 (`s: [1위, 2위, 3위]`).
- 지난주 스냅샷: `/king_vs/lastweek_champions.json` (`period_start/end`, `generated_at` = 목 12:00, 게임별 `school` + `score`).
- 점수 파이프: `save_score.php?action=list|history|start|submit`.
- 홈 우하단 위젯: 1페이지는 **전체 학급 랭킹**(전 게임 금>은>동 합산, 공동 순위, 노출 순서 셔플로 편향 방지), 이후 페이지는 게임별 🥇🥈🥉. 5초 캐러셀. CTA: **「비어있는 왕좌 👑 지금 도전!」**. 주석: `매주 목요일 12:00 시즌 종료`.
- 홈 좌하단 위젯: 지난주 우승 학급 목록 → `/honor/`.

**2. 명예의 전당 (`/honor/`)**

- 이중 아카이브.
  - **주간 학교대항전** (최신 위): 2026-07-23 / 07-30 / 08-06 주차. 게임마다 우승 학급 + `certificate.php?school=&game=&icon=&start=&end=` 인증서.
  - **월간 랭킹전** (구 KLK): 2026년 5·6·7월, 학급 1~10위 명단(게임 링크 없음).
- `map.php` — 전국 우승 지도.
- 푸터에 `honor-admin.php` 숨김 링크. 정적 HTML + 아코디언 JS.

**3. 인기 트렌드 (`/rankdata/?v=0712`)**

- 대항전(누가 이겼나)과 직교하는 **교사 선택 신호**: 무엇이 교실에서 실제로 켜지나.
- 섹션: Overall / Board & Tablet / Smartphone / Computer, 각각 **24h + weekly**.
- Weekly Combined Analysis (카테고리·검색).
- 기기 태그(`wide`/`sm`/`computer`)와 맞춰 전자칠판·폰·PC 레퍼토리를 나눈다. 홈 BEST 40의 목적지.

이 세 화면이 역할을 나눈다. rankdata는 **선생님의 FOMO**(지금 뜨는 게임), king_vs는 **반의 승부욕**(이번 주 왕좌), honor는 **영구 기념**(우리 반이 이겼다). 개인 레벨업이 아니라 **반 정체성**을 건다.

### 학교 등록 · 지역 랭킹

**등록 (개인 계정 없음)**

협똥킹 로비 기준:

1. `학교 이름을 검색하세요...` 자동완성.
2. 1차: 나이스 공개 API `open.neis.go.kr/hub/schoolInfo` (`SCHUL_KND_SC_NM=초등학교`). 시도명을 서울/경기/강원 등으로 축약.
3. 2차 백업: 로컬 `school.txt` 목록.
4. 학년 `<select>` + 반 번호 `<input>`.
5. 배지(`selected-school-badge`)로 확정, `localStorage`에 유지.
6. 식별자 = `시도 + 시군구 + 학교 + N학년 M반`. 학생 닉네임은 대항전 본기록에 안 탄다.

허브 위젯은 폭이 좁아 `경남 거창군 거창초 4학년 3반` → **`경남 거창초 4-3`**. 학년-반은 ellipsis하지 않음(반  rival의 핵심 정보).

**지역 랭킹**

| 소스 | 내용 (2026-08-19 스냅샷) |
|---|---|
| `/klk7/region_ranking.js` | `[{rank:1, 강원특별자치도, count:57}, {rank:2, 경기도, count:43}]` |
| `/klk7/123.js` | 구 월간 KLK 전국 TOP10 텍스트. 1~5·8~10위가 강원(철원 동송초 6-5 등), 6~7위 경기. |
| honor `map.php` | 우승 학급 지리 시각화. |

`klk7`은 옛 월간전 스냅샷 경로로 보인다. 현재 라이브 루프는 `king_vs/*.php|json`. 강원 편중은 구 시즌 잔상 + 현직 교사(강원 기반) 네트워크가 겹친 결과로 읽는 게 맞다. 주간전은 이미 부산·전남·충청으로 퍼졌다.

지역 count는 “우리 시도가 몇 반이나 나왔나”라는 **집단 점수**다. 개인 MMR이 아니라 교육청/지역 자존심을 건드린다.

### 다국어

- `hreflang` 16종: `ko, en, zh, ja, es, fr, ru, id, vi, th, pt-br, hi, bn, tr, de, it` + `x-default`.
- `/?lang=xx`. 홈 HTML 자체가 언어별로 갈린다(ko 52.7KB / en 26.9KB, MD5 상이, 타이틀·OG 번역).
- 플로팅 언어 버튼 + flagcdn + 검색 가능한 언어 모달.
- 게임 레코드: `title: {ko,en,...}` 객체, `koOnly: true`면 외국어 UI에서 숨김(문해력킹, 대시보드, 일부 아케이드).
- 트렌드보드도 동일 언어 스위처(`ksmLang*`). 대항전 페이지는 한/영 타이틀 병기(예: `협똥킹 학급대항전 | Shit Dodge King Class`).
- 실질 트래픽 중심은 한국어 교실. 다국어는 ** titling/SEO/해외 전자칠판 복제**용 껍질이고, 학교 등록·나이스·인증서는 한국 초등 전용.

### 기술 스케치

정적 프론트(바닐라 JS + Pretendard + Font Awesome) + PHP 랭킹/인증서. 게임은 도메인이 갈린다: `kingsmath.com` 서브경로, Cloudflare Pages, Vercel, GitHub Pages, Netlify, Workers. 캐시버스터 `?v=unix`. 전자칠판 전제는 `wide`, 폰은 `sm`.

## (b) 수학 게임에 이식 가능한 디자인 장치 5개

1. **플레이 결과가 학급 운영 산출물이 된다 (넘버러시)**  
   60초 미니게임의 순위가 곧 **발표 순서·팀 나누기**다. 수학 한 판이 끝난 뒤 “점수순으로 모둠/칠판 나올 사람”이 자동 생성되면, 선생님은 게임을 보상과 수업 절차에 동시에 쓴다. 대항전 점수와 별개인 **교실 유틸리티 레이어**.

2. **6자리 학급 코드로 즉시 집합 (아트온)**  
   나이스 학교검색은 주간 공식전에 맞고, 한 시간 수업에는 무겁다. 교사가 세션을 열고 코드/QR만 보여 주면 같은 판에 붙는다. 수학 멀티(칠판 본게임 + 학생 기기 컨트롤러/제출)에 바로 붙일 수 있다.

3. **우리 고장 맵 + 등급별 시간공격 (경남/부산 택배의 민족)**  
   영수증(목표) → 실제 시군구 지도 터치 → 알뜰/한집/번쩍 제한시간과 힌트 수 → 별점 승급. 수학 이식: 수직선·좌표평면·한국 지도·단원 맵을 보드로 쓰고, 난이도를 **배달 등급**처럼 교실 용어로 부른다. 지역 콘텐츠는 대항전의 지역 랭킹과 맞물린다.

4. **교과 개념이 조작 키가 된다 (물 탐험대 상태변화 런)**  
   점프만이 아니라 물/얼음/수증기 **상태 전환이 코어 액션**. 수학이면 분수↔소수↔퍼센트, 약수↔배수, 단위 환산이 버튼/변신이어야 한다. “문제를 풀고 뛰어가는” 스킨이 아니라 **조작 = 개념**.

5. **전자칠판 마주보기 n판 세트전 (2026 자석 월드컵)**  
   화면을 가로로 쪼개 양쪽으로 앉힌다. 단판/3판2선/5판3선, 팀명(국가) 커스텀, 세트·타이머 HUD. 킹수학 `wide` 게임의 본전은 개인 스마트폰이 아니라 **반 전체가 보는 칠판 대전**. 구구단·비교·십 만들기 대항전에 세트 구조와 좌우 대치를 올리면 쉬는 시간 한 판이 스포츠가 된다.

보너스(이미 플랫폼과 잘 붙는 것): 칸채움의 **오늘 퍼즐+인쇄+연속일수**, 레이저 폭탄의 **10분 공식전 vs 연습 / 닉네임 HOF**, 타이핑버스의 **스트릭 프리즈**, 리듬앤플레이의 **게임 모드 vs 학습 모드**.
