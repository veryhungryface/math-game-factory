# 킹수학 2차 조사 그룹3 (16개)

## 깊게 본 5개

### 쌓기나무킹 (5-2-5/6-2-3, wide — 우리 미제작 단원: 공간과 입체)
- 루프: 등축 3D 큐브 더미(회색 격자 바닥, three.js류)가 뜬다 → "화면을 터치하여 돌려보세요"(회전 가능, 헤드리스 캡처엔 안 잡힘) → 1~20 숫자 그리드에서 정답(총 개수) 탭 → 60초, 1~4인 동시 플레이.
- 문제 생성: 스킨(테마)별로 다른 큐브 배치 세트를 순환 제공하는 듯("강아지" 테마 라벨).
- 오답/관용: 정답 범위가 딱 1~20으로 캡핑돼 있어 큰 구조물은 애초에 안 나옴 — 즉시성/속도 게임이지 "보이지 않는 뒤쪽 블록 추론" 같은 공간추론 오개념(숨은 블록, 투영도)은 다루지 않음. 단순 관찰-집계.
- 시사점(미제작 단원 설계): 저쪽은 "회전 가능한 3D 뷰 + 개수 세기"뿐, 위/앞/옆에서 본 모양(투영도) 매칭이나 숨겨진 블록 추론 문제는 없다. 우리가 만들면 이 갭(투영도 역추론, 숨은 블록 최소/최대 개수)을 파고들 여지가 큼.

### 원입체 캐치킹 (6-2-6, wide — 우리 미제작 단원: 원기둥·원뿔·구)
- 루프: 목표 입체(원기둥/원뿔/구 등)를 미리 안내 → 각자 화면에 무작위로 뜨는 도형들 중 목표와 일치하는 것만 빠르게 터치 → 3라운드, 6인 대결 랭킹.
- 문제 생성: 반응속도형 "기억하고 빨리 찾기" — whack-a-mole과 동일 계열(이상이하 두더지킹과 같은 엔진 패밀리로 추정, 카운트다운 UI가 동일).
- 오답/관용: 도형 인식(모양 변별)만 다루고, 전개도·구성요소(밑면/옆면/모선)·부피 개념은 전혀 안 건드림. "회전체" 개념(직사각형을 돌리면 원기둥 등)도 없음 — 순수 시각 매칭.
- 시사점: 원기둥·원뿔·구 단원에서 "회전체 만들기(평면도형을 축 중심으로 회전)"나 "전개도 재구성" 쪽은 킹수학이 전혀 안 건드리는 빈 공간. 우리가 그 쪽을 조작형 게임으로 채우면 차별화됨.

### 이상이하 두더지킹 학급대항전 (5-2-1 — 우리 「어림 대시」와 겹침)
- 루프: 10x3(30칸) 두더지 그리드에서 10초마다 미션("이상→이하→초과→미만→이상.미만→초과.이하" 순환, 소리 안내)이 바뀌고, 조건에 맞는 숫자가 적힌 두더지만 멀티터치로 잡음. 60초 단일 판.
- 오답/관용: "미션의 기준 숫자를 가진 두더지는 반드시 올라온다(초과·미만이면 오답 처리)"는 규칙으로 경계값 함정을 강제 배치. 정답 +10, 오답 -5.
- 게임화 레이어: 학교/학급 단위 전국 랭킹(TOP100), 명예의 전당, 주 1회(목 12시) 시즌 리셋 — 개인전이 아니라 "우리 반 vs 전국"으로 프레이밍.
- 우리 게임(어림 대시) 대조: 어림 대시는 수직선 위 회피 러너(공간·연속량 위 위치 판단, ●/○=발판/낭떠러지로 포함·불포함을 물리 법칙화)인 반면, 두더지킹은 이산적 숫자 집합에서 "분류/골라내기"(집합 판별) 방식. 같은 오개념(이상·이하·초과·미만 경계)을 서로 다른 인지 조작(연속 위치 판단 vs 이산 분류)으로 학습시킴 — 우리 쪽이 수직선의 연속성/경계 개념을 더 직접 체화시키는 설계이고, 저쪽은 반응속도·분류 훈련에 가까움. 정면 경쟁이라기보다 상호보완적.

### 약분킹! 풍선 터트리기 / 통분킹 (분수 기초 조작)
- 약분킹: 하단에 제시된 "약분 미션 분수"와 크기가 같은 분수가 적힌 풍선을 찾아 터뜨림(난이도 쉬움/어려움, 1~4인, 시간 지날수록 풍선 가속). 학생이 직접 약분 계산을 수행하는 게 아니라 "크기 판별(같은 크기 인식)"만 함 — 절차(공약수로 나누기)는 채점 로직 뒤에 숨어있고 눈에 안 보임.
- 통분킹: 좌우 두 열에 뜬 분수 중 "크기가 같은" 쌍을 드래그 선으로 연결(5쌍 연결 시 다음 세트), 3연속 정답 콤보 보너스. 역시 순수 매칭/판별형이고 공통분모 만드는 절차 자체는 게임 조작에 없음.
- 공통 패턴: 두 게임 다 "크기 비교 인식"에 특화되고 조작 절차(약분: 공약수 나누기, 통분: 공배수 찾기)는 게임 메커닉으로 표현되지 않음 — 우리가 만들면 절차를 조작 동사로 체화시키는 쪽(예: 분자/분모를 직접 스와이프해서 나누기)이 차별점이 될 수 있음.

## 나머지 11개 (빠르게)

- **킹네모 디펜스 모바일**(5-2-4/6-2-1/2, sm): 하단 물리 키보드로 숫자·연산기호(+,-,×,÷) 입력해 몬스터 막는 타이핑 디펜스. 오답 시 키보드 3초 정지 페널티. 특기: 정답 형식이 "숫자 또는 연산기호 1개"라 매우 단순한 즉답형.
- **야르킹 땅따먹기**(wide, "전자칠판 전용 팀 배틀" 명시): 보라팀 vs 핑크팀 영역쟁탈전, 카드에 적힌 식(3+5, 9×7 등)을 상대팀이 계산해서 뺏음, 동시 정답 시 한번에 뒤집힘, 노란 보너스 카드로 주변 8칸 강탈. 특기: 전자칠판 전용이라고 앱 자체가 라벨링돼있음 — 모바일판 없음.
- **월드컵 축구킹 모바일**(sm): 닉네임+국가 선택, 1분간 10골(연산 맞히기로 슛), 글로벌 랭킹(국기 표시, 쉬움/어려움 분리 TOP50). 특기: 국가 대항 프레이밍 + 개인 글로벌 랭킹.
- **구구단킹 풍선 터트리기**(wide): 1~99 숫자가 양쪽에 랜덤 등장, 구구단 정답(곱셈표에 있는 수)인 것만 터치, 아닌 걸 누르면 감점, 1분 제한. "양쪽 같게/다르게" 옵션으로 난이도 조절.
- **구구단을 외자킹 모바일**(sm): "한 번 넣은 정답은 수정 불가, 빠르고 정확하게" — 타자 속도형 구구단 답 입력 게임. 오타 즉시 확정이라 정확도 압박이 큼.
- **둘레 비교 야호킹 모바일**(6-2-5, sm): 두 도형 중 "더 긴 둘레"를 빨리 터치. 쉬움(같은 도형 크기 비교)/어려움(다른 도형 비교) 분리.
- **숫자 야구킹**(5-2-6, wide): 1~9 서로 다른 숫자 3개 맞히기 스트라이크/볼(Mastermind류), 3·6회차에 힌트 공개, 3스트라이크 시 즉시 홈런승. 1~4인, 30/60/무제한 타이머 옵션.
- **컷킹 모바일**(6-2-4, sm): 60초 동안 "정확한 비율로" 화면을 잘라내는 게임(비 개념을 절단 비율로 시각화). 명예의 전당 TOP100.
- **비교 채점킹**(5-2-1, wide): 컨셉이 특이 — 학생이 "선생님"이 되어 자연수/소수/분수 비교 시험지를 채점(정답=동그라미, 오답=빗금). 자리별(일/십/백/천의 자리, 소수 첫째~셋째 자리), 가분수/대분수/분수·소수 비교 등 12개 세부 유형 선택 가능. 특기: 유일하게 "정답을 맞히기"가 아니라 "남의 오답을 찾아내는" 메타인지형 게임 — 오개념 자체를 채점 대상으로 노출시킴.
- **메모리킹 모바일**(5-2-6, sm): 9개 카드를 10초간 암기 후 빨리 찾기(카드 매칭/기억력), 틀리면 +5초 페널티. 순수 기억력 게임에 숫자/데이터 카드를 얹은 형태.
- **원킹 모바일**(6-2-5/6, sm): 10초 안에 손가락으로 "완벽한 원"을 한 번에 그리는 드로잉 정확도 게임(96.2점 식 점수). 원의 성질(둘레·넓이) 계산이 아니라 순수 모터스킬 게임.

## 모바일/칠판 이원화 패턴 결론

같은 게임(구구단, 축구킹, 비교 등)이 wide(전자칠판)판과 sm(모바일)판으로 나뉠 때, **wide판은 "동시에 여러 명이 한 화면을 보는 팀/학급 대항전"(멀티터치, 팀 색상, 영역쟁탈), sm판은 "각자 폰으로 접속하는 개인전 + 실시간 글로벌/학교 랭킹"(닉네임 입력, 국가/학교 선택, TOP50~100 리더보드)**으로 역할이 갈린다. 즉 동일 문제 생성 로직을 두 개의 다른 소셜 레이어(교실 즉시 경쟁 vs 개인 랭킹 게임화)에 얹어 재사용하는 구조다. 우리 공장은 현재 이 이원화 없이 단일 게임 산출물만 내는데, "같은 커리큘럼 로직 + 다른 소셜/경쟁 레이어" 재사용은 참고할 만한 배포 전략이다.
