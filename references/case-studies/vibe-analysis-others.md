# Vibe 게임 11종 분석 (수학 외 과목)

접속: 11/11 성공. 모바일 세로 접속 시 8개가 "가로 모드로 돌려주세요" 게이트에 걸림 → 844×390 가로 뷰포트로 재접속해 정상 진입. 3개(picasso-atelier, cosmo-space, forest)는 1차 스크린샷 타임아웃(무거운 캔버스 렌더링) → protocolTimeout 확장 + DPR 낮춰 재시도로 해결.

## 1. zombiegame — "The Genius: Virus Game"
- 과목: 과학(감염병 단원) / 형식: 교사 진행형 학급 놀이(멀티플레이 파티게임), 개인 문제풀이 게임 아님
- 루프: 교사가 진행 → 학생들이 참여하는 감염병 시뮬레이션. 실제 문제풀이보다 "학급 놀이" 프레임
- 이식 장치: 어두운 실험실 배경 + 생쥐 과학자 마스코트 + 귀여운 바이러스 캐릭터로 무서울 수 있는 소재를 순화. 인트로가 "SCIENCE CLASS STORY INTRO" 라벨 + 건너뛰기 버튼 있는 시네마틱 슬라이드(대사가 한 줄씩 페이드인, "감염병.. 감염병이 뭐지?" 식 캐릭터 독백)로 시작 — 단원 도입부 내러티브 훅으로 이식 가능
- 비주얼: 다크 톤 일러스트, 첫 화면은 심플한 타이틀+CTA, 인트로는 풀스크린 무드 일러스트

## 2. breadg — "풍요와 기근" (Genius 학급 놀이)
- 과목: 사회(경제, 자원 분배) / 형식: 교사 제어판 + 학생용 중계 화면(팝업) 이원 구성의 교실 아케이드
- 루프: "CLASSROOM ARCADE" 라벨 아래 풍요/기근 두 지역 자원 배분 시뮬레이션. 미션 인트로가 6슬라이드 스토리("불시착 → 두 땅 → 생존해야 한다")로 전개
- 이식 장치: 듀얼 스크린(교사 제어 + 학생 표시) 구조는 우리 공장과 무관하지만, "MISSION INTRO (SLIDE 1/6)" 형태로 단계 번호를 노출하는 슬라이드 카운터는 지루한 도입부에 진행감을 줌
- 비주얼: 이모지 기반 아이콘(🌾🍞🏜️) 활용한 미니멀 톤, 클래식 아케이드풍 타이틀

## 3. jurygame — "배심원 게임" (Genius 학급 놀이)
- 과목: 사회(민주주의, 시민 참여) / 형식: 교사 제어판(TEACHER CONTROL PANEL & PRESENTATION HUD) 중심 학급 놀이
- 루프: 재판/배심원 역할극 시뮬레이션 추정. 인트로가 레트로 RPG풍 — macOS 창틀(빨/노/초 dot) + 흑금 색감 + "INTRO STORY CRAWL" 텍스트가 스타워즈 크롤 스타일로 위로 흘러가며 "책 펼쳐보기 (1단계 시작)" 골드 버튼으로 마무리
- 이식 장치: **레트로 RPG 프레이밍(창틀 장식 + 크롤 텍스트 + "책을 펼친다"는 은유의 CTA 문구)**은 지루할 수 있는 사회 개념(민주주의) 도입을 게임처럼 느끼게 함 — 수학 단원 도입에도 그대로 이식 가능

## 4. plogging — "플로깅 어드벤처: 지구를 지켜라!"
- 과목: 환경/과학(줍깅, 환경보호) / 형식: 개인 플레이 어드벤처
- 루프: 지구 마스코트가 직접 말을 거는 대사창("지구: 얘들아, 나를 도와줘! 플로깅 어드벤처에 함께해줘!")으로 시작 → 스테이지 선택 → 플레이 → 도감(컬렉션) 수집
- 이식 장치: **마스코트가 1인칭으로 위기/부탁을 직접 호소하는 대사 연출**은 "왜 이 문제를 풀어야 하는지"를 감정적으로 설득하는 데 매우 효과적 — 수학 게임 도입부에 그대로 이식 가능. 스테이지 선택/도감 보기가 홈 화면에 상시 노출되어 재방문 동기 부여
- 비주얼: 밝은 파스텔 동화풍, 별점(⭐) 카운터가 좌상단 상시 노출

## 5. hangeul-guardians — "한글 수호대: 전통마을 모험"
- 과목: 국어(한글, 자모) / 형식: 개인 플레이 어드벤처
- 루프: 전통마을 배경 + 소년 주인공 + 훈장 할아버지 사부 캐릭터가 타이틀 화면에 함께 등장. "모험 시작" → 5개 노드로 구성된 마을 지도(문자 숲 → 한글 연구소 → 수호대 장터 → 보고서 공방 → 한글사랑 축제)를 순서대로 진행, 잠긴 스테이지는 자물쇠 아이콘
- 이식 장치: **월드맵형 스테이지 선택(순차 잠금 해제 + 경로선 연결 + 하단 정보카드에 "1단계 · [핵심 질문]" + 대표미션 요약 + 입장하기 버튼)** — 이 패턴이 art-gallery, fair-school에서도 반복 등장(아래 참고), 초등 수학 단원별 스테이지 구조로 그대로 이식 가능. 사부/멘토 캐릭터가 학습 파트너로 상시 동행
- 비주얼: 고퀄리티 동양풍 일러스트, 자모 블록(가나다 큐브)이 배경 소품으로 배치되어 과목 정체성을 은근히 드러냄

## 6. wordquest — "워드퀘스트: WordQuest"
- 과목: 영어 어휘 / 형식: 개인 플레이, 5단계 퀴즈 여정 + 사용자 정의 단어팩 생성 기능
- 루프: 10단계 온보딩 마법사(진행 dot 인디케이터 "2/10") → 캐릭터 선택(4종, 각기 아이콘/별칭) + 보상 테마 선택(별빛/마법/모험 테마 카드) → 선택 시 골드 테두리+체크뱃지로 즉시 피드백, "선택 완료" 버튼이 회색→골드로 활성화
- 이식 장치: **온보딩을 진행률이 보이는 다단계 마법사로 설계하고, 캐릭터/보상 테마 선택을 초반에 배치해 "내 것"이라는 소유감을 부여**하는 구조. 선택 즉시 시각 피드백(체크+하이라이트+버튼 활성화)은 UX 신뢰도를 높이는 디테일. 사용자가 직접 단어팩(=문제셋)을 만들 수 있는 기능은 교사/학생 커스터마이징 사례로 참고할 만함
- 비주얼: 파스텔 판타지풍, 강아지 동반 캐릭터가 배경에 등장(디테일 채움)

## 7. art-gallery — "명화 탐험관"
- 과목: 미술(명화 감상) / 형식: 개인 플레이, 8개 활동 모드 허브
- 루프: 타이틀에서 "탐험 시작하기" 진입 시 하단 탭바에 8개 모드 노출(감상관/작품 알아보기/퀴즈 챌린지/비교실/분석실/복원실/재해석 스튜디오/나의 갤러리) → 클릭 시 하늘섬(플로팅 아일랜드) 월드맵으로 전환, 8개 노드가 순차 잠금 해제, 좌상단에 "탐험 정보" 패널(진행도 0/8, 진행도 %, 별 개수, 다음 활동 안내)
- 이식 장치: **하나의 주제를 여러 활동 유형(감상/퀴즈/비교/분석/복원/재해석/컬렉션)으로 쪼개 반복 플레이의 지루함을 회피**하는 구조 — 수학도 "문제풀이"만이 아니라 "오답 분석실", "내가 만든 문제 스튜디오" 같은 변주 모드로 확장 가능. 진행도 패널을 접고 펼 수 있게(접기▲) 만들어 화면을 덜 어지럽힘
- 비주얼: 매우 높은 완성도의 하늘섬 배경, 실제 명화(반 고흐 별이 빛나는 밤, 모네 등) 썸네일을 장식으로 미리 노출해 기대감 형성

## 8. fair-school — "공정한 규칙을 찾아라"
- 과목: 사회(공정성, 규칙) / 형식: 개인 플레이, 5단계 미션 월드맵
- 루프: "우리의 미션" 버튼으로 진입 → 실사풍 학교 캠퍼스 일러스트 위에 5개 미션 노드(이상한 점수 경기장/공정 탐정단/분류 연구소/존중 말하기 훈련소/학교 개선 본부)가 경로선으로 연결, 잠금 상태 명확히 표시, 배지함(획득 배지) 상단 노출
- 이식 장치: hangeul-guardians·art-gallery와 동일한 **월드맵+순차잠금+배지함** 패턴이 3번째로 확인됨 — 서로 다른 제작자(추정)가 독립적으로 수렴한 패턴이라는 점에서 신뢰도 높은 검증된 UX. 미션명이 전부 "은유적 별명"(예: 이상한 점수 경기장=공정하지 않은 채점 기준을 다루는 미션 추정)으로 지어져 있어 학습 목표를 직접 노출하지 않고 호기심을 유발
- 비주얼: 실사에 가까운 3D풍 학교 배경, 아이소메트릭 시점

## 9. picasso-atelier — "롤링 피카소 아틀리에"
- 과목: 미술(피카소 화풍 따라 그리기) / 형식: 개인 플레이(실제 드로잉은 종이에 직접)
- 루프: 타이틀에서 "이 앱은 그림을 대신 그려 주지 않아요. 작품은 도화지에 직접 완성해요!"라고 스코프를 정직하게 먼저 고지. "작품 감상" 모드에서는 하늘이/지우/민서/윤우/서연/준호 등 이름 붙은 가상 급우들의 샘플 작품을 갤러리로 보여주고 "각 작품을 클릭하면 친구가 표현 전략을 들려줘요"라는 피어-내레이션 기능 제공
- 이식 장치: **① 앱이 할 수 없는 것을 첫 화면에서 솔직히 고지해 기대치를 관리**하는 디자인 — 우리 게임도 "AI가 대신 풀어주지 않아요" 류 문구로 학습 주도성 강조 가능. **② 가상 급우 이름을 붙인 샘플/풀이 갤러리(피어 모델링)** — 수학에서 "다른 친구의 풀이 전략 보기"로 응용 가능. 주사위 모양 마스코트 캐릭터가 안내자 역할
- 비주얼: 색종이/색테이프 콜라주 느낌의 화려한 미술실 배경, 큐비즘 초상화 장식

## 10. cosmo-space — "우주탐험대 코스모: 태양계 탐험 학습 게임"
- 과목: 과학(천문, 태양계) / 형식: 개인 플레이, "탐험대원 선택"부터 시작하는 미션형
- 루프: "밤하늘 관찰 미션"이라는 부제 아래 우주비행사 소년 마스코트 + 로봇 동반자 + 달 캐릭터가 타이틀에 함께 등장. "탐험 시작" / "기록 저장" / "마지막 화면"이 나란히 노출되어 이어하기가 쉬움
- 이식 장치: 타이틀 화면에 저장/이어하기 버튼을 시작 버튼과 대등하게 배치해 **세션 재개를 마찰 없이 지원**하는 구조. 마스코트를 1개가 아니라 2~3개(주인공+동반 로봇+환경 캐릭터)로 겹쳐 배치해 화면에 생동감을 더함
- 비주얼: 우주 배경 + 달 표면 기지, 고품질 캐릭터 일러스트

## 11. forest — "넘버 트레일: 수의 모험" (수학 게임, 유일)
- 과목: **수학** — 제목상 "수와 연산" 계열로 추정(트레일=경로를 따라가는 탐험형 구조)
- 단원 추정: 캐릭터 클래스 설명 문구로 추정 가능 — 숲 모험가(호기심/기본 탐색), 마법사(수의 비밀을 읽는), 초원 요정(부드러운 길잡이), 기사(단단한 의지), **연금술사("숫자를 조합하는...")**, 별빛 탐험가(먼 우주를 향한 탐험). "연금술사=숫자 조합"이라는 문구는 사칙연산(특히 덧셈/곱셈)을 캐릭터 테마로 감싼 것으로 추정
- 문제 생성/오답 설계/관용도: **확인 불가** — 캐릭터 생성 화면(닉네임 입력 + 6종 클래스 선택 카드)까지는 도달했으나, 캔버스 렌더링 게임이라 DOM 클릭이 불가능해(버튼이 전부 canvas 픽셀) 좌표 클릭으로 재시도했음에도 실제 카드 선택이 UI에 반영되지 않아 스테이지/문제 화면까지 진입하지 못함(4분 예산 내 3회 재시도 후 중단)
- 이식 장치(관찰된 것만): **캐릭터 "클래스"에 스토리 플레이버를 입혀 학습 스킬 유형을 은유적으로 구분**하는 아이디어는 독창적 — 예: 우리 공장에서도 "더하기 마법사", "도형 탐정" 처럼 단원별로 캐릭터/클래스를 매핑해 같은 UI라도 다른 정체성을 부여할 수 있음. 짙은 우주/보석 톤 타이틀 배경 + "모험 시작"/"게임 방법" 2버튼 구성은 심플하고 명확
- 비주얼: 보라/남색 우주풍 판타지, 뗏목처럼 떠있는 섬들이 배경에 산개

## 수학 공장에 이식할 만한 장치 TOP 7

1. **월드맵형 스테이지 선택** — 순차 잠금 해제 + 경로선 연결 + 진행도 패널(0/N, %, 별개수) + 노드 클릭 시 하단 정보카드("N단계 · 핵심 질문" + 대표 미션 + 입장 버튼). hangeul-guardians / art-gallery / fair-school 3개 게임에서 독립적으로 수렴한 검증된 패턴 → 단원별 스테이지 화면에 최우선 적용 권장.
2. **마스코트의 1인칭 호소형 인트로 대사** — "지구: 얘들아, 나를 도와줘!" 식으로 캐릭터가 직접 위기를 설명하며 참여를 요청. 왜 이 문제를 풀어야 하는지에 대한 감정적 동기 부여.
3. **캐릭터/보상 테마 선택 온보딩 + 즉시 시각 피드백** — 선택 시 골드 테두리+체크뱃지+CTA 버튼 활성화(회색→강조색)로 소유감과 확신을 동시에 줌.
4. **하나의 주제를 다중 활동 모드로 쪼개기** — 감상/퀴즈/비교/분석/복원/재해석/컬렉션처럼, "문제풀이"만 반복하지 않고 오답노트·내문제만들기·친구풀이보기 같은 변주 모드를 추가해 루프 피로도 감소.
5. **정직한 스코프 고지** — "이 앱은 그림을 대신 그려주지 않아요" 식으로 첫 화면에서 앱의 한계/역할을 명시해 기대치 관리(AI가 풀어주지 않는다는 점을 수학 게임에도 명시 가능).
6. **레트로/시네마틱 인트로 프레이밍** — 창틀 장식, 스타워즈 크롤, 슬라이드 카운터(1/6) 등으로 단조로운 개념 도입부를 게임처럼 연출.
7. **저장/이어하기를 시작 버튼과 대등하게 노출** — 세션 재개 마찰을 줄여 반복 방문을 유도.
