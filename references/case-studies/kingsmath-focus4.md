## A. 깊게 본 5개

### A1. 소수점 이동킹 — `https://kingsmath.com/kingmove?v=1774708375`

- **단원 태그:** 5-2-4, 6-2-2 (소수 ×10^n / ÷10^n). 우리 「소수 스매시」(5-2-4 소수의 곱셈)와 단원 겹침.
- **구조:** 인트로 오버레이(문제 유형 / 챌린지 10라운드 vs 서바이벌 / 1~6인) → 카운트다운 3 → 큰 문제창 + 플레이어별 숫자 디스플레이 + ◀ / 제출 / ▶.
- **루프:** `nextTurn()` → `generateProblem(diff)` → 3초 카운트 → 30초 타이머(서바이벌은 `max(5, 30-(round-1)*2)`로 줄어듦) → 전원 제출 또는 시간 종료 `finishRound()` → 3초 정답 공개 → 다음 라운드.
- **문제 생성:** 유형 7종 — 소수 확대(×10/100/1000/10000), 소수 축소(×0.1/0.01/0.001/0.0001), 자연수 확대/축소, 각 mix, 전체 mix. 소수는 소수점 1~3자리 강제(`raw/10^dp`), 곱 후 `ans∈[0.0001,10000]`. `base * mul`을 `toPrecision(15)` + `parseFloat`로 계산.
- **조작:** 소수점을 좌우로 옮기는 것이 곧 답. `shift` 클램프 ±6. 시작 숫자는 문제의 `base`, 오른쪽(+1)이 ×10, 왼쪽(−1)이 ÷10.
- **오답·관용:** **관용 없음.** `playerVal === correctAnsVal` 완전일치. 챌린지는 오답해도 다음 라운드(점수만 0), 서바이벌은 오답 즉시 탈락. 오답 시 왜 틀린지(몇 칸 밀렸는지) 설명 없음. 정답은 상단에 초록 숫자만 띄움.
- **수학 이슈:** 정수쌍이 아니라 `parseFloat`/`toPrecision(15)` 비교. 교육과정 「소수점 위치를 옮기면 10배」와 조작은 잘 맞지만, 「(소수)×(소수)」 자릿수 합·0.1×는 10으로 나누기와 같다는 스매시 쪽 오개념은 안 다룸.
- **우리 대비 요점:** 스매시는 *곱셈 결과의 크기 판단(커진다/작아진다/정답 방울)* 이 동사. 이동킹은 *같은 수에 ×10^n 했을 때 소수점을 몇 칸 옮길지* 가 동사. 겹치는 문장은 「0.1을 곱하는 것과 10으로 나누기」 한 조각뿐. 교실 전자칠판 배틀 vs 1인 아케이드.

### A2. 전개도킹 — `https://kingsmath.com/kingnet/?v=1775782560`

- **단원 태그:** 5-2-5, 6-2-3. 우리 「네모공장」(5-2-5 직육면체와 정육면체)과 겹침. 6-2-3은 우리 카탈로그상 「소수의 나눗셈」이 아니라 출판사에 따라 쌓기나무/원기둥 쪽 — 실제 게임은 순수 직육면체 전개도.
- **구조:** 언어 모달 → 튜토리얼(규칙 6줄) → 화면을 좌우 2분할. 가운데 목표 직육면체 겨냥도 SVG(가로/세로/높이 cm). 각 플레이어 20×20 격자(1칸=1cm). 1분 타이머.
- **루프:** 목표 치수 `w,d,h ∈ {1..5}` 1회 고정 → 드래그로 면 최대 6장 그리기 → 맞닿은 변에 점선 힌지 자동 표시 → 제출 → three.js로 접기 애니메이션 → 성공이면 완료 시각 기록, 실패면 2초 에러 후 2D로 복귀. 둘 다 성공하거나 60초 종료 시 결과.
- **문제 생성:** 절차적 치수만. 전개도 모양 카탈로그 없음. 정육면체(w=d=h)는 약 4% 확률로만 나옴. 「접히지 않는 전개도」를 문제로 내지는 않음 — 학생이 직접 그리고 접혀야 통과.
- **판정 순서:** (1) 면 정확히 6장 (2) 면 크기 다중집합이 목표 `{w×d, w×d, w×h, w×h, d×h, d×h}`와 일치 (3) 힌지 그래프로 연결 (4) 접은 뒤 면 중심 거리 `< 0.2`면 겹침 실패. 틀린 전개도도 3D로 접어 보여 준 뒤 에러 키(`errDesc2~5`)를 띄움.
- **오답·관용:** 목숨 없음. 실패해도 다시 그릴 수 있음(잠금 2초). 시간 초과만 최종 실패. 오답 피드백은 원인 한 줄(개수/크기/연결/겹침). 「정사각형 6개면 무조건 정육면체」 같은 트랩 전개도는 없음.
- **수학 이슈:** 겹침 판정이 월드좌표 유클리드 거리 0.2 — 부동소수점/스케일에 민감. 힌지는 변이 완전히 일치할 때만(부분 맞닿음 불가). 마주 보는 면·전개도 11종 카탈로그는 다루지 않음.
- **우리 대비 요점:** 네모공장은 전개도/겨냥도/치수카드 3종을 *같은 상자인지 짝짓기*(인식). 전개도킹은 치수를 보고 *전개도를 직접 생산*. 우리는 트랩 전개도·실선/점선 겨냥도 오개념을 공략하고, 킹수학은 「6면을 이어 붙여 접히게 만들기」 운동 감각. 상호 보완 — 복제 가치는 낮고, 「그려서 접기」가 빠진 구멍은 크다.

- **단원 태그:** 5-2-6 (우리 카탈로그 「평균과 가능성」). **실제 게임은 가능성이 아니다.** 합이 5의 배수일 때 종을 치는 벨 게임. SEO 타이틀도 「5의 배수 왕」.

### A5. 나눗셈 몫 어림킹 — `https://kingsmath.com/kingdiv/?v=1778211934`

- **단원 태그:** 6-2-1, 6-2-2 (분수÷ / 소수÷  pretags). 실제 내용은 **자연수·소수 나눗셈의 한 자리 몫(1~9)을 빨리 누르기**. 우리 「어림 대시」(5-2-1 올림/버림/반올림)와는 다른 「몫 어림」.
- **구조:** 난이도 8단계 / 문제 수 4·8·10·12 / 제한 5·8·11초·무제한 / 1~6인. 넘패드 1~9만 (0 없음, 두 자리 몫 없음).
- **루프:** 카운트다운 단어(나눗셈 몫 / 몫을 / 누르세요 / 시작!) → 식 `D ÷ d` 색 코딩(피제수 파랑, 제수 초록) → 한 사람당 숫자 1개만 입력하면 블랙아웃 → 전원 입력 또는 시간 종료 → 4초간 `D÷d=q ... r` 과 검산 `d×q+r=D` 표시 → 다음 라운드.
- **문제 생성:** 몫 `q = rand(1..9)` 를 먼저 뽑고 `D = d*q + r` 역산.
  - 1: 한두자리÷한자리 나머지0 (`d=2..9`)
  - 2: 나머지 있음 (`r=1..d-1`)
  - 3~4: 몇십÷몇십 (`d=10,20,..90`)
  - 5~6: 두세자리÷두자리 (`d=11..99`, 10의 배수 제외)
  - 7~8: 소수 한 자리 (`d,D`를 /10). 8단계는 나머지도 소수.
- **오답·관용:** **「어림」인데 관용 0.** `input === q.toString()` 완전일치. 나머지가 있는 문제는 사실 버림 몫(floor)인데, 학생은 정확히 그 한 자리를 맞춰야 한다. ±1 허용 없음. 점수 `500 + (5000-ms)/10`.
- **수학 이슈:** 소수 단계는 `Number((int/10).toFixed(1))` — 표시용 반올림. 몫이 항상 1~9라 교과서 「몫이 두 자리인 소수 나눗셈」과 범위가 다름. 「어림하여 몫을 짐작」 전략(나누는 수를 10의 배수로 바꾸기 등)은 UI에 안 보이고, 그냥 암산 레이스.
- **우리 대비 요점:** 어림 대시는 자리 어림+구간(이상/이하). 이 게임은 나눗셈 몫의 자릿수 감각. 6-2 소수÷ 미제작 시 「한 자리 몫을 먼저 짐작」은 살릴 만하지만, 관용(가까운 몫)과 어림 전략 힌트가 빠지면 그냥 암산 배틀이 된다.

## 우리 소수·전개도 게임과의 대조 결론 3개

1. **소수는 단원이 겹쳐도 동사가 다르다.** 이동킹은 「같은 수에 ×10^n / ×1/10^n 했을 때 소수점을 몇 칸 옮길지」가 조작이고, 「소수 스매시」는 「곱한 결과가 커지는지·정답 방울인지」를 그어 판단한다. 스매시가 겨냥하는 오개념(곱하면 항상 커진다, 소수점 자릿수를 한쪽에만 쓴다)은 이동킹에 없고, 이동킹의 「1/1000」분수 배율 표기·좌우 시프트는 스매시에 없다. 스매시를 갈아엎을 이유가 없고, 후속 **소수 나눗셈(6-2-3)** 을 만들 때 소수점 이동 조작만 빌려오면 된다.

2. **전개도는 인식 vs 생산으로 서로 빈칸이다.** 「네모공장」은 전개도·겨냥도·치수 3종을 같은 상자로 짝 짓고 트랩 전개도·실선/점선 오개념을 공략한다. 전개도킹은 치수(스크린샷 3×3×2 cm)를 보고 20×20 격자에 6면을 **직접 그려 접히게** 만든다. 접기 실패를 3D로 보여 주는 피드백은 우리가 못 가진 부분이고, 전개도킹은 11종 전개도 카탈로그·숨은 모서리 점선·「정사각형 6개=정육면체」 트랩이 없다. 복제하지 말고, 다음 입체 게임에 「그려서 접기」 한 조각을 넣으면 된다.

3. **킹수학 셸(전자칠판 다인 배틀 + 완전일치)은 공장 계약과 충돌한다.** 깊게 본 5개 중 4개는 기본 다인 레이스이고, 「어림」킹조차 ±1 관용이 없다(36÷6 → 키 하나). 5땡킹은 5-2-6으로 태깅돼 있지만 가능성은 한 줄도 없고 5의 배수 벨 게임이다. 수신킹은 비례 문항 목록(151~154단계)만 쓸 만하고 1단계가 `4+1`인 드릴이다. 소수·전개도 모두 **1인 아케이드 + 오답 관용 + 조작=수학** 을 유지하고, 가져올 것은 배틀 UI가 아니라 (a) 소수점 시프트, (b) 전개도 접기 피드백, (c) 비례식·비례배분 문항 스펙 세 조각이다.
