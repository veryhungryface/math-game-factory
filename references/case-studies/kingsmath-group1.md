## 1. 한달음 윷놀이 (yutdash.vercel.app)
- **매핑 단원**: 5-2-6 (확률과 통계 관련 추정) / **태그**: wide, sm, Data, Board
- **핵심 루프**: 1~6명이 순서를 정하고 목표 점수(400)까지 윷을 던져 말을 전진시키는 전자칠판용 보드게임. 인원수·순서 선택 화면 → "1번 차례, 목표 400" 진행 화면까지 확인.
- **단원 일치 여부**: 표면적으로 확률(윷 던지기 결과 분포)과 연결 지을 수 있으나, 화면에서 확률 개념을 명시적으로 가르치는 장치(도·개·걸·윷·모 확률표 등)는 보이지 않음. 데이터/통계 단원 매핑은 다소 느슨해 보임 — 전통놀이 자체가 목적이고 수학은 배경일 가능성.
- **전자칠판 맥락**: 최대 6명까지 색상 원으로 구분해 "번갈아" 진행하도록 설계. 큰 글씨, 단순 명료한 다크 네이비 배경 + 파스텔 원형 버튼. 터치 하나로 인원 선택 가능해 교사가 즉석에서 세팅하기 쉬움.
- **문제 생성**: 하드코딩에 가까운 룰 기반 보드게임(윷놀이 자체 규칙), 수학 "문제"가 별도로 없음 — 순수 보드게임 형태.
- **재미/비주얼**: 미니멀한 플랫 디자인. 화려하진 않지만 깔끔. 전통놀이 소재라 친숙함.
- **훔칠 것**: 인원수 선택 → 색상 자동 배정 → "번갈아 진행" UX의 간결함. 서버 없이도 로컬 turn-based 멀티플레이를 완전한 시각적 피드백(현재 차례 강조)으로 처리.
- **우리가 더 잘하는 것**: 모바일 단독 플레이 시 AI 상대/봇 로직, 실제 수학 문제(확률 계산, 예상 vs 실제 비교) 결합 여지가 큼. 이 게임은 수학 학습 요소가 사실상 없음.

## 2. 트로피 탈출킹 (kingsmath.com/king_trophy)
- **매핑 단원**: 2-1-3~6-2-2 등 22개 단원 (전학년 수 영역 총망라) / **태그**: computer, Numbers, arcade
- **핵심 루프**: 픽셀 아케이드 스타일 "슈팅런너" — 정답 숫자를 먹으면서 진행, 트로피 등장 시 획득해 탈출. 난이도 4단계(처음/초급/중급/고급) 선택 가능. 스코어보드에 이름 입력 후 START.
- **단원 일치 여부**: 단원 태그가 22개나 붙어 있는데 실제로는 "숫자 먹기"라는 단일 인터랙션 위에 매 라운드 다른 규칙(배수/약수/자릿값 등)을 얹는 구조로 추정됨 — 하나의 게임 엔진에 커리큘럼 태그를 폭넓게 붙인 형태. 실제 문제 콘텐츠까지는 START 이후 로딩이 느려 확인 못함(진입 화면에서 "정답을 모두 먹으면 트로피가 나와요"까지만 확인).
- **전자칠판 맥락**: SCORE/LV/하트(목숨)/JET/GUN/COMBO 등 전형적 오락실 HUD. GRADE 1-2 배지로 학년 표시. "전체화면" 버튼 제공 — 전자칠판에서 바로 풀스크린 전환 의도가 뚜렷.
- **문제 생성**: 난이도별 사전 설계된 규칙 세트로 보임(하드코딩 가능성 높음), 생성기 여부는 미확인.
- **재미/비주얼**: 도트 폰트 + 네온 그린/골드 배색으로 레트로 아케이드 감성. 하이스코어 등록(8자 이내 이름) 랭킹 시스템 있음.
- **훔칠 것**: 목숨(하트) + 콤보 + JET/GUN 게이지라는 아케이드 자원 시스템을 수학 정답률에 연동한 것. 실수해도 즉시 아웃이 아니라 목숨을 깎는 완충 설계.
- **우리가 더 잘하는 것**: 모바일 세로 터치 최적화(이 게임은 방향키/버튼 기반 PC 아케이드 조작으로 보여 모바일 원터치엔 불리), 문제 생성기로 무한 반복 가능한 콘텐츠.

## 3. 스톱워치 버블킹 학급대항전 (kingsmath.com/king_vs/kingtimebb)
- **매핑 단원**: 2-2-4 (시간/시각) / **태그**: wide, Measurement, vs
- **핵심 루프**: 목표 초(예: 정확히 몇 초)에 최대한 가깝게 스톱워치를 정지시키는 반응 게임. 12개 버블이 상시 유지되며 터진 자리에 새 버블 리스폰, 제한시간 90초, 오차 허용 ±0.5초.
- **단원 일치 여부**: 시간 측정·어림(estimation) 감각과 직접적으로 연결되어 단원 매핑이 매우 타당함.
- **전자칠판 맥락**: 이 게임의 핵심은 "학급대항전" — 학교/학급 이름을 검색해 등록하면 전국 랭킹(TOP100)에 실시간 반영. 시즌제(매주 목요일 종료, 명예의 전당 기록)까지 갖춘 정교한 서버 기반 경쟁 시스템. "여러 명이 동시에 눌러도 됨"이라 명시 — 학급 전체가 화면 앞에 모여 함께 터치하는 것을 전제로 설계.
- **문제 생성**: 목표 시간이 버블마다 달라 보이며(초 단위 무작위 생성 추정), 정답 판정은 서버/클라이언트 로직으로 실시간 처리.
- **재미/비주얼**: 다크 네이비 + 시안/오렌지 그라데이션 CTA 버튼. 랭킹 테이블에 순위 1~3위 메달 이모지, 실시간 카운트다운(시즌 종료까지 D-day 타이머)로 긴장감 조성.
- **훔칠 것**: **학급 단위 경쟁·시즌제·명예의 전당** 구조 자체가 강력한 재방문 유인. 개인전이 아니라 "우리 반 vs 다른 반"으로 목표를 옮기면 학습 동기가 커뮤니티/소속감으로 확장됨. 1인 모바일 공장에서도 "친구 코드로 팀 만들기"나 "주간 리더보드 리셋" 정도는 차용 가능.
- **우리가 더 잘하는 것**: 개인 맞춤 난이도 조절, 오프라인 플레이 가능성(이 게임은 학교 등록·서버 의존도가 높아 네트워크 필수).

## 4. 배수 약수 팩맨킹 (kingsmath.com/kingpacman)
- **매핑 단원**: 5-1-2 (약수와 배수) / **태그**: wide, computer, sm, Numbers, arcade
- **핵심 루프**: 팩맨 미로에서 "지금 잡을 숫자: N의 배수"라는 룰이 매 미션마다 바뀌고, 미로에 흩어진 숫자 중 규칙에 맞는 것만 먹어야 함(안 맞으면 감점/목숨 감소 추정). 10개 미션 클리어가 목표, 실시간 TOP10 랭킹 존재. 모바일 뷰까지 정상 반응형.
- **단원 일치 여부**: 배수/약수 개념과 정확히 일치. 실제 게임에 들어가니 "2의 배수", "3의 배수" 등으로 규칙이 바뀌는 걸 확인 — 단원 학습이 게임 메커니즘 자체에 녹아있음.
- **전자칠판 맥락**: 방향키(PC)/아래 버튼(패드·스마트) 조작 안내가 화면 하단에 항상 표시 — 전자칠판 터치와 키보드 둘 다 지원. 닉네임 8자 입력 후 게임 시작하는 구조로 학생별 기록 관리.
- **문제 생성**: 미션별로 목표 배수/약수 규칙이 절차적으로 바뀌고, 미로 위 숫자 배치도 매번 달라 보임(랜덤 생성 가능성 높음) — 하드코딩보다는 생성기에 가까운 설계.
- **오답 설계**: 규칙에 안 맞는 숫자를 먹으면 하트(목숨) 감소로 추정(하트 3개 UI 확인). 명확한 "규칙 오검증" 방식이라 조작 실수(길을 잘못 가서 원치 않는 숫자를 먹음)와 개념 오류(배수 판별 실패)가 섞일 수 있음 — 순수 개념 평가로는 다소 노이즈.
- **재미/비주얼**: 다크 네이비 + 골드 텍스트, 팩맨 특유의 격자 미로를 잘 재현. 오락실 감성이 트로피 탈출킹보다 완성도 높아 보임(파워아이템 언급 있음 - "규칙에 맞는 숫자 먹기 · 파워 아이템o").
- **훔칠 것**: 미로 이동이라는 "탐색 자체가 재미"인 레이어 위에 숫자 판별을 얹은 구조. 정답을 그냥 클릭하는 게 아니라 "찾아가서 먹는" 행위가 학습 몰입을 늘림. 규칙이 미션마다 바뀌는 점(배수→약수→배수...) 도 반복 학습에 좋음.
- **우리가 더 잘하는 것**: 오답을 개념 오류와 조작 실수로 분리해 피드백하는 정교함, 모바일 터치 전용 조작(이 게임은 방향키 UI가 다소 PC 지향적).

## 5. 분수크래프트 (kkankong32-alt.github.io/Fractioncraft)
- **매핑 단원**: 5-1-5 (분수의 덧셈과 뺄셈 - 통분) / **태그**: wide, sm, Numbers, math
- **핵심 루프**: 마인크래프트 스타일 3D 오픈월드 탐험 게임. "숲길 통문 장치"에 1/2+1/3 같은 분수식의 정답 블록을 설치해 문(게이트)을 열고 진행. 통분/분수판/계산식/균형 4가지 "조각"을 모아 최종 보스(분수 드래곤) 방까지 도전하는 스토리 구조.
- **단원 일치 여부**: 통분·덧셈 개념과 정확히 일치, 오히려 커리큘럼보다 게임 세계관(스토리)이 훨씬 풍부함.
- **전자칠판 맥락**: 캐릭터 선택, "수업 약속"(교실 규칙) 메뉴가 별도로 있어 교사가 수업 전 학급 규칙을 안내하는 용도로 보임. 1인칭 3D 이동이라 전자칠판보다는 개별 기기(모바일/PC) 플레이에 더 적합해 보이지만 sm 태그가 붙어있어 모바일도 지원.
- **문제 생성**: 미확인(초기 미션만 관찰) — 블록 설치형 정답 제시 방식은 확인. 인벤토리에 여러 재료(나무 블록, 돌 블록, 유리 블록 등)가 있어 "탐험하며 발견"하는 수집형 구조.
- **재미/비주얼**: 완성도가 매우 높음 — 실제 마인크래프트 유사 3D 그래픽, 미니맵, 인벤토리 핫바, NPC 대사창까지 갖춤. 7종 중 가장 제작 공수가 커 보임(1인 교사 제작치고 이례적으로 정교).
- **훔칠 것**: "정답을 게임 월드에 물리적으로 배치"하는 방식(정답=블록 설치)과 스토리텔링(NPC 대사, 세계관, 보스전 목표)이 학습을 미션처럼 느끼게 함. 미니맵 + 목표 마커로 방향성을 잃지 않게 하는 UX.
- **우리가 더 잘하는 것**: 이런 3D 오픈월드는 로딩·용량·개발비용이 1인 모바일 공장 기준으로는 비현실적 — 우리는 세션당 30초~2분의 압축된 판정 루프에 집중하는 게 맞다. 다만 "정답 오브젝트를 직접 배치/드래그"하는 인터랙션 아이디어는 2D로 축약해 차용 가능.

## 6. 곱셈과 나눗셈 우주연산 수비대 (throinhoon.github.io/SpaceMultiplication-Division)
- **매핑 단원**: 4-1-3 (곱셈과 나눗셈) / **태그**: wide, sm, Numbers
- **핵심 루프**: 2인(대원1/대원2) 협동/경쟁 보드게임. "주사위 굴려 은하 궤도 이동 → 연산 미션 풀고 정답 입력 → 상대방이 계산기로 검증 → 틀리면 원위치, AI 선생님(내장형)이 도와줌"이라는 4단계 규칙을 임무 브리핑으로 명시.
- **단원 일치 여부**: 곱셈/나눗셈과 정확히 일치.
- **전자칠판 맥락**: **또래 상호검증(peer verification)** 구조가 독특함 — 상대 대원이 "계산기로 검증"해줘야 한다고 명시, 즉 학생끼리 서로 답을 확인하게 만드는 사회적 학습 설계. 팀 구성 시 로켓/UFO/우주인 등 이모지 아바타를 각 대원이 고르게 함. "AI 선생님(내장형)"이 오답 시 개입한다는 문구도 흥미로움(로컬 판정 로직을 의인화).
- **문제 생성**: 주사위 기반 보드 이동 + 연산 미션이 결합된 구조(생성기 추정, 미확인).
- **오답 처리**: "틀리면 원래 위치로 되돌아감" — 명확한 패널티형 되돌리기 룰.
- **재미/비주얼**: 라이트 톤(흰 배경 + 파스텔 카드), 이모지 기반 캐릭터 선택이 산뜻하지만 그래픽 자체는 단순한 편(카드 UI 수준, 실제 보드/우주 비주얼은 게임 진입 전이라 미확인).
- **훔칠 것**: "상대가 검증한다"는 규칙을 문구로 강제 명시해 두 명이 함께 몰입하게 만드는 설계, 아바타 선택으로 개인화를 주는 저비용 장치.
- **우리가 더 잘하는 것**: 1인 플레이가 기본인 우리 공장은 AI 상대(즉시 대전)나 자기 자신과의 시간 경쟁으로 "상호검증"을 대체할 필요 — 이 게임은 물리적으로 2명이 한 화면 앞에 있어야 완전히 작동하는 구조라 온라인/솔로 확장성이 떨어짐.

## 7. 육목킹 (wtc6.lovable.app)
- **매핑 단원**: 없음(커리큘럼 태그 비어있음) / **태그**: wide, computer, sm, Patterns, Data, Board, Puzzles, arcade
- **핵심 루프**: 오목의 변형인 "육목"(6개 연속 배치 승리) 커넥트 보드게임. 3명까지 참여 가능(사람 3명 / AI 1명 / AI 2명 조합), 턴 타이머(30초) 옵션, 턴 순서 커스터마이즈(첫 턴 1개 이후 2개씩 두는 룰) 지원.
- **단원 일치 여부**: 커리큘럼 태그가 비어 있는 게 사실 정직함 — 이 게임은 수학 연산 문제가 전혀 없는 순수 전략 보드게임. "Patterns/Data"로 태그된 건 논리적 패턴 인식을 확률/전략적 사고와 연결 지은 느슨한 매핑으로 보임.
- **전자칠판 맥락**: 다크모드 토글, 최대 3인 동시 플레이(AI 혼합 가능)로 전자칠판 앞 여러 학생이 번갈아 두는 구조에 적합. 색상 선택이 자유롭고, "시작하려면 확인해주세요" 체크리스트(빨간 경고 박스)로 설정 누락을 사전에 막는 꼼꼼한 UX.
- **문제 생성**: 해당 없음(전략 게임 로직).
- **재미/비주얼**: Lovable로 제작된 느낌의 깔끔한 크림톤 카드 UI, 접근성 좋은 드롭다운 기반 설정. 게임판 자체는 미확인(설정 단계에서 색상 미선택 시 진행 차단됨).
- **훔칠 것**: 설정 미비 시 "무엇이 빠졌는지" 항목별로 짚어주는 사전 검증 UX(빨간 체크리스트), 사람/AI 혼합 인원 구성을 토글 3개로 간단히 처리하는 패턴.
- **우리가 더 잘하는 것**: 이 게임처럼 수학이 아예 없는 콘텐츠는 우리 목적(수학 게임 공장)과 무관 — 다만 "전자칠판에서 여러 명이 순서대로 두는" 보드게임 프레임 자체는 향후 수학 퀴즈 버전으로 재해석 가능.

## 인사이트 요약 5개

1. **학급/학교 단위 경쟁 인프라가 가장 강력한 차별화 요소다.** 버블킹의 "학교 등록 → 전국 TOP100 랭킹 → 주간 시즌 → 명예의 전당" 구조는 개인 앱에는 없는 소속감·재방문 동기를 만든다. 1인 공장이라도 최소한 "친구 코드 리더보드"나 "주간 랭킹 리셋" 정도는 저비용으로 흉내 낼 가치가 있다.
2. **또래 상호검증(peer-verification) 규칙이 사회적 학습을 강제한다.** 우주연산 수비대의 "상대가 계산기로 검증해야 함" 문구처럼, 정답 확인 주체를 시스템이 아닌 사람으로 지정하면 몰입도가 올라간다. 솔로 게임에서는 이를 "즉시 리플레이로 스스로 검증" 또는 AI 캐릭터의 리액션으로 대체할 수 있다.
3. **"정답을 찾아가서 상호작용하는" 설계가 클릭형 객관식보다 몰입감이 높다.** 팩맨킹(먹이 찾아 이동), 분수크래프트(블록을 직접 설치)는 정답 선택을 공간적 탐색·조작 행위로 바꿔 게임성을 부여했다. 우리 모바일 게임도 드래그·스와이프·타이밍 등 물리적 인터랙션에 정답 판정을 결합하는 편이 단순 버튼 탭보다 낫다.
4. **커리큘럼 태그와 실제 콘텐츠 간 정합성 편차가 크다.** 트로피 탈출킹은 22개 단원에 태그되어 있지만 게임 메커니즘은 규칙 세트를 교체하는 단일 엔진으로 보이고, 육목킹은 태그 없이 정직하게 "수학 아님"을 인정한다. 우리 공장은 태그를 게임 엔진 유연성이 아니라 실제 문제 생성 로직 기준으로 붙여야 신뢰도가 유지된다.
5. **제작 공수와 완성도 편차가 매우 크다** — 분수크래프트(3D 마인크래프트급)부터 육목킹(설정 화면만 확인해도 알 수 있는 미니 프로젝트)까지 스펙트럼이 넓다. 무료·개인 제작 생태계라 비주얼 퀄리티로 경쟁하는 건 상한이 낮지 않지만, 우리는 "판정 루프의 정확성 + 오답 피드백의 정교함"(개념 오류 vs 조작 실수 구분 등) 같은 콘텐츠 품질 축에서 차별화하는 게 합리적이다 — 이 축에서는 조사한 7개 게임 대부분이 허술했다(예: 팩맨킹의 길찾기 실수와 배수 판별 실수가 뒤섞임).
